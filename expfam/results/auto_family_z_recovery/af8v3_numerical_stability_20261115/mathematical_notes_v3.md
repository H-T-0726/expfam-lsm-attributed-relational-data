# AF8-v3 数理メモ：受理基準を「証明書」型に変える根拠（v3 pilot の前に作成）

この protocol は、AF8-v2 の pilot の数値結果を見た後に作った改訂版である。AF8 の事前登録と同じものとして扱わない。
対象とする量（E2・E・IS）、prior、データ、開始点、IS の draw は v2 と同じである。変えたのは最適化の終わり方と、点を受理する基準だけである。

## 1. v2 の停止原因（FACT、`regression/known_failed_draws_v2.csv`）

v2 で失敗した 9 draw は、v2 の seed から完全に同じ f を再生成した。各セルの失敗数も pilot と一致した。止まった点では次のとおりだった。

| 量 | 値（9 draw の範囲） |
|---|---|
| \|\|g\|\|_∞ | 1.1e-6 〜 9.3e-6 |
| Newton decrement λ²/2 = ½ gᵀH⁻¹g | 4.4e-15 〜 2.5e-13 |
| \|φ\| の 1 ulp | 2.3e-13 または 4.5e-13 |
| 完全な Newton step による φ の変化 | −1 〜 −2 ulp |
| 同じ step による S の変化 | 4.6e-9 〜 7.1e-8 |
| H_ZZ の最小固有値 | 1.55 〜 3.98（正定値） |

**DERIVED:** Armijo は φ(x + αp) ≥ φ(x) + c·α·gᵀp を要求する。予測される増加 λ²/2 が φ の分解能（1 ulp）より小さいと、この判定は丸めで決まる。その結果、step が却下されるか、極小の α だけが受理されて進まない。
したがって、勾配の絶対値に閾値（1e-6）を置く受理は、点が極大のすぐ近くにあってもなくても成否を分ける理由にならない。

**DERIVED:** S = φ(Ẑ) + const − ½ log|H(Ẑ)| のうち、φ の誤差は δZ = H⁻¹g について 2 次（λ²/2）だが、log|H| の誤差は 1 次である：
−½ tr(H⁻¹ ∂H[δZ])。観測された 4e-9 〜 7e-8 は、この 1 次の項である。

**INTERPRETATION（v2 の外側の不安定性）:** S に ε の誤差があると、刻み h の中心差分による勾配には約 ε/h の雑音が入る。
ε ≈ 1e-8、h = 1e-4 なら約 1e-4 であり、v2 で観測した FD 勾配の床（1.6e-5 〜 7e-4）と一致する。
v3 で内側を証明書つきで解くと、同じ 2 セルで FD 勾配は 7e-8 〜 2e-7 になり、刻み幅の違いによるばらつきも 1.5e-7 に下がった（`regression/known_failures_v3_regression.csv`）。

## 2. 内側（Z）と joint（u）の受理：証明書

H = −∇²φ（Cholesky で正定値を確認）、g = ∇φ、p = H⁻¹g とする。

1. **Armijo 段階（v2 と同じ）。** 修正 Newton、却下した試行点は受理しない、負曲率からの脱出、SADDLE の判定。
   ただし λ²/2 ≤ 64 ulp(|φ|) かつ H が正定値になったら、Armijo の比較には情報がないので次の段階へ移る。
2. **polish。** 純粋な Newton step を最大 10 回とる。各 step は、次の条件をすべて満たすときだけ受理する。
   - 試行点が有限である。
   - H が正定値のままである。
   - λ² が厳密に減少する。

   φ の値は比較しない。H が正定値でない領域には入らない。
3. **証明書。** 次の 3 つを満たすときだけ OK とする。
   - (C) H が正定値。
   - (D) λ²/2 ≤ 1e-12。
   - (E) 完全な Newton step をもう 1 回とったときの Laplace 値の変化：|Lap(x+p) − Lap(x)| ≤ 1e-10。ここで Lap = φ − ½ log|H|。

   満たさなければ NOT_CERTIFIED（失敗）とし、値としては使わない。

**勾配の絶対ノルム（A）とスケールを考慮した相対勾配（B）について。** 勾配は記録するが、受理の判定には使わない。
λ² = gᵀH⁻¹g は H で測った勾配の大きさで、座標のスケールに依存しない。そのため B の役割を自然に含み、しかも目的関数の差（nats）に換算できる。

**閾値の根拠。** 1 候補の E2 に許す数値誤差の予算を τ_E2 = 1e-3 とする。これは判定の下限 0.01 の 1/10 である。

- **CERT_LAP = 1e-10。**
  - S の誤差 ε が FD 勾配に与える雑音は ε/h = 1e-6（h = 1e-4）。
  - FD Hessian の各成分に与える雑音は約 4ε/h² = 4e-4（h = 1e-3）。
  - したがって外側の log 行列式の誤差は ≲ K·4e-4/λ_min ≈ 2e-4 で、E2 の誤差は約 1e-4。λ_min ≥ 6 は v2 の最小値 6.28 に基づく。
- **CERT_DEC = 1e-12。** 局所 2 次近似での φ の残りの改善量で、S への寄与は CERT_LAP より小さい。
- **到達可能性（FACT）。** 9 draw では、polish の後に λ²/2 ≈ 1e-28、Laplace の変化 ≤ 4.5e-13（1 ulp）になった。閾値は丸めの床より十分上にある。

**限界。** (C)(D)(E) は、正定値な点での局所 2 次近似に基づく。非凸な問題の大域的な最大性は保証しない。
Z の多峰性は、決定的な cold start と IS の救済の記録（§4）でしか扱っていない。

## 3. 外側（f、K = 3）の受理

- v2 の BFGS 段階（`v2.maximise_T`）は変更しない。その終了状態は記録だけし、受理には使わない。
- その後に、FD 勾配（h = 1e-4）と FD Hessian（h = 1e-3）を使った Newton 段階で受理を判定する。手順は次のとおり。
  1. −T の FD Hessian が正定値でなければ、T_STATIONARY_NOT_MAX とする。
  2. λ_f²/2 > 1e-6 なら、Armijo つきの Newton step をとる。
  3. λ_f²/2 ≤ 1e-6 なら、実際に T(f + H⁻¹g) を評価する。
     - 増加が 1e-6 を超えたら、その点へ移って再判定する。
     - 超えなければ CERT_OK とする。
- OUTER_CERT_DEC = 1e-6 は、f_D での T の残りの改善量で、E2 にそのまま入る。τ_E2 よりずっと小さい。
  内側の証明書による FD 勾配の雑音（~1e-6）が生む見かけの改善量は (1e-6)²/(2·6) ≈ 1e-13 なので、この判定は雑音で決まらない。
- **FD に依存しない照合（S8）。** 主 prior では f_D から Nelder–Mead を走らせる。T(f_D) より τ_E2 を超えて高い T が見つかってはならない。
- **FD 雑音の検査（S9）。** h ∈ {5e-5, 1e-4, 2e-4} の FD 勾配のばらつき s から、見かけの改善量 s²/(2λ_min) を計算する。これが OUTER_CERT_DEC 以下でなければならない。

## 4. IS の draw の扱い

- 提案分布、seed、draw は v2 と同じである（f_D が同じなら draw も完全に同じになる）。
- S は各 draw で cold start（アンカーの Zmode から）して定義する。
- 証明書が得られなかった draw に限り、Z(f_D) から決定的な追加のモード探索を 1 回だけ行う。
  その結果を使うのは、次の 2 つを満たすときだけである。
  - 追加探索の点に証明書が得られた。
  - cold start の最後の φ との差が ≤ 1e-6（同じモードで、失敗は最適化だけによる）。
- それ以外は FAILED とする。重み 0 ではない。
  - 分母は 400 のままで、IS 推定値は無効（NaN）とする。下限は別に記録する。
- 救済したすべての draw について、draw 番号、f、元の状態、勾配、λ²、φ の差、結果を記録する（S4r）。
- 数学的に重みが 0 になる draw は、このモデルでは起こらない。S が定義される f では T が有限だからである。

## 5. E・E2・IS の位置づけ（v2 と同じ）

- E2 ≈ IS は、外側の f 積分の Gaussian 近似を確かめるだけである。Z の Laplace 誤差 ε_Z は検証しない。
  E2 と IS は同じ被積分関数を使い、提案分布の中心も同じである。
- したがって E2 ≈ IS は、(Z, f) を厳密に積分した周辺尤度に近いことの証明にはならない。
- E と E2 の差は 2 つの近似の差であり、どちらが正しいかは判定しない。
