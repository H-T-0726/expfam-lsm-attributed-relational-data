# AF8-v2 数理メモ：E2 を主な近似とすることの確認（v2 の結果を見る前に作成）

対象とする量（AF8 の `mathematical_derivation.md` と同じ。θ_{−j} は固定するので、Bayesian evidence ではない）:

```
M_m = log ∫ p(f|m) [ ∫ p(X, Y_train, Z | f, m, θ_{−j}) dZ ] df
```

## 1. E と E2 は何を近似しているか

| 記号 | 計算の構造 | 近似の誤差が入る場所 |
|---|---|---|
| E2（主） | 内側：各 f で Z を Laplace 近似 → S_m(f)。外側：T = S + log p を f について Laplace 近似（f_D = argmax T のまわり） | (i) 各 f での Z の Laplace 誤差 ε_Z(f)。(ii) 外側の f についての Laplace 誤差 |
| E（診断） | (Z, f) を同時に 1 つの Gaussian で近似する（joint mode のまわり、228 次元） | (Z, f) の同時分布が Gaussian でないことによる誤差。これには −½log\|H_ZZ(f)\| の f 依存のうち 3 次以上の部分が含まれる |
| IS（診断） | 外側の f 積分 ∫exp T(f) df を重点サンプリングで計算（Z は各 f で Laplace） | (i) は E2 と共通。外側の積分だけを数値的に確かめる |

- E2 と IS の差は、外側の f 積分の Laplace 誤差だけを測る。
- E と E2 の差は、2 つの近似の差である。どちらが正確かは、Z の厳密な積分なしには決められない。

## 2. E2 が依存する Z の Laplace 近似の限界

- ε_Z(f) は、Z の事後分布が Gaussian でないことによる誤差である。AF6 の TI では、f = f_L で Δ について中央値 −0.12、最大 0.65 だった。
- E2 は ε_Z(f) を f の関数として外側の積分に取り込むが、ε_Z そのものは補正しない。候補間で ε_Z が違えば、Δ の偏りとして残る。
- S(f) は、Z の mode が一意で H_ZZ が正定値である範囲でだけ定義される。AF8 の pilot で、f = 0 では Z の問題が凹にならない例（rep02 sparse 列 8）があった。
- v2 では、その場合に負曲率の方向へ抜け出して、正定値の極大を探す。見つからなければ S(f) は**定義されない**（数値の失敗であって −∞ ではない）と扱い、試行点として採用しない。
- 外側の Laplace と IS で使う f の範囲で S が定義されない点が出た場合、IS では「失敗した draw」として別に数え、推定値は無効とする。

## 3. 外側の最適化が正当である条件

- Laplace 近似の中心は、T の**局所極大**でなければならない。
  - 勾配がほぼ 0 であること（FD 勾配の無限ノルム < 1e-5）。
  - FD Hessian が**正定値**であること。
- 鞍点や極小は、「有効な極大」として採用しない（状態 `T_STATIONARY_NOT_MAX`）。
- 開始点が異なる有効な極大に収束した場合は、多峰性として記録する。
  - 2 番目の極大が最大の極大から log 20 以内にあれば、1 つの mode の Laplace では足りないので、スコアを判定に使わない（`MULTIMODAL_NONNEGLIGIBLE`）。
  - 開始点を除外して「一致した」と扱うことはしない。

## 4. Hessian と Schur 補行列の整合

- E の joint mode では、包絡線定理から次が成り立つ。

  ```
  −∇²_f max_Z Ψ(Z, f) = H_ff − H_fZ H_ZZ⁻¹ H_Zf
  ```

  これを test_07 で数値的に確かめる。

- E2 の f についての曲率は −∇²_f T = −∇²_f [Ψ(Ẑ(f), f) − ½ log|H_ZZ(Ẑ(f), f)|] で、Schur 補行列に体積項の f についての 2 階微分を加えたものになる。
- したがって、E2 の f の曲率と E の Schur 補行列が一致する必要はない。違いは、−½log|H_ZZ(f)| が f に依存することによる。

## 5. prior の正規化と Jacobian（AF8 から変更なし）

- B：f ~ N(0, (s/a_m) I)。log p は −(K/2) log(2π s) + (K/2) log a_m − a_m‖f‖²/(2s) で、Jacobian の項を含む。
- test_08 で、3 次元の数値積分による正規化と、g 空間の密度との一致を確かめる。

## 6. 近似の差が分布の選択に与える影響

選択は Δ = M_C − M_P の符号で決まる。数値の誤差として、次の 3 つを記録し、判定状態に反映する。

| 誤差の種類 | 記録する量 | 判定への反映 |
|---|---|---|
| 外側の f 積分の誤差 | E2 と IS の差 | 記録する |
| FD の刻み幅への依存 | E2 を h = 5e-4、1e-3、2e-3 で計算した差 | \|Δ\| ≤ max(0.01, 2×刻み幅による変化) なら `UNCERTAIN_NUMERIC` |
| 近似どうしの違い | E と E2 の差 | 記録する（診断） |

- Z の Laplace 誤差（ε_Z）は、この pilot では評価できない。
- E2 を主とするのは、計算の構造（Z を積分した関数を f について積分する）を明確にするためである。正解率に基づく選択ではない。

## 7. E2 を主とすることに数学的な問題があるか

致命的な問題はない。ただし、次の 2 点を限界として明記する。

1. E2 は ε_Z を含むので、「厳密な周辺尤度」ではない。
2. T が多峰的なときには、E2 は定義できない（状態でそう示す）。
