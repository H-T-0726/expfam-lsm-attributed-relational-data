## 2. 停止の原因（`--pilot-diagnose`。既存の pilot セルを決定的に再計算した。新しい fit やデータは使っていない）

### 2.1 IS の draw の失敗（9 セル、各 1 draw、計 9/28,400 draw）

- **FACT:** 再計算した失敗 draw の数は、9 セルすべてで pilot と一致した（`n_failed_rerun = n_failed_pilot = 1`）。
- **FACT:** 9 件すべてで、内側の Newton が `S_NOT_CONVERGED` だった。これはアンカーの Zmode から cold start し、100 回反復したものである。
- **FACT:** 最後の点で、勾配の無限ノルムは 1e-6 から 9e-6 だった。floor で受理するには ≤ 1e-6 が必要で、それをわずかに超えている。
  - 却下された試行は 2,249 から 2,913 回、負曲率からの脱出は 0 回だった。
  - 反復の上限を 2 倍（200 回）にしても、全件 `NOT_CONVERGED` のままだった。
- **FACT:** 同じ f で Z(f_D) から warm start すると、全件 OK になった。H_ZZ は正定値だった。
- **FACT:** cold start（200 回）の最後の φ と warm start の極大の φ の差は ≤ 9.1e-13 だった。
- **INTERPRETATION:** cold start は warm start と**同じ極大**に到達している（φ が 1e-12 の精度で一致する）。
  - 失敗は、極大が存在しないことによるものでも、多峰性によるものでもない。
  - 原因は、勾配の受理基準（1e-6）が、その点で達成できる浮動小数点の精度より厳しいことである。
  - ただし Z の問題が一意の極大をもつことは証明していない。
- **FACT（設計の変更点）:** AF8 の IS は Z_D から warm start し、`modeZ` の反復は 200 回だった。v2 は決定性のために cold start に統一し、上限を 100 回にした。
  この変更が失敗 draw を顕在化させたと考えられる（INTERPRETATION）。

### 2.2 外側の有効な開始点がない 2 セル

対象は rep01 sparse 列 4 CMP2 の A_sf2_0.667 と、rep02 sparse 列 5 CMP2 の B_sg2_0.667（主 prior）である。

- **FACT:** 3 つの開始点は、どれも 200 回反復して `NOT_CONVERGED` だった。
  - 最後の f は開始点の間で約 1e-5 の範囲で一致し、T は約 7e-10 の範囲で一致した。
  - 同じセルの joint Laplace E は、全開始点が収束し AGREE だった。
- **FACT:** 最後の f での FD 勾配の無限ノルムを、刻み幅 h = 2.5e-5 から 4e-4 で計算すると、h に対して単調でなく跳んだ。
  - 例：1.6e-5 → 7.3e-4 → 1.6e-5 → 7.1e-5 → 4.7e-5。
  - 外側の勾配の許容値は 1e-5 である。
- **INTERPRETATION:** T(f) は内側の解の許容誤差に由来する雑音をもつ。その雑音が FD 勾配に約 1e-5 から 1e-4 の床をつくり、外側の許容値（1e-5）を下回れない。
  極大がないことを示す証拠はない。

### 2.3 共通の原因

**INTERPRETATION:** 残った 2 種類の失敗は、どちらも「収束の受理基準が、達成できる数値精度より厳しい」ことによる。

- AF8 の停止原因（鞍点への収束、LinAlgError、Z の問題が凹でない）は、v2 では再現していない。
  - v2 で受理した点の負 Hessian の最小固有値は E で 0.93、D の f で 6.28 だった。
- 受理基準を緩めることは protocol の変更なので、ここでは行わない（Human Gate）。

## 3. E と E2、IS（主 prior）

| 比較 | 値 |
|---|---|
| \|ΔE−ΔE2\| の中央値／最大値 | 0.190 / 1.141（35 組） |
| E と E2 で符号が逆の組 | 2/35（rep03 sparse 列 3、列 5。\|Δ\| < 0.82） |
| \|ΔE−ΔIS\| の中央値 | 0.146（26 組） |
| E2 と IS で符号が逆の組 | 0/26 |
| IS の差の MC SE の中央値 | 0.025 |

- **限界（FACT）:** IS は E2 と同じ T(f) を使い、提案分布も E2 の f_D と FD Hessian でつくる。
  - したがって S3 は、外側の f 積分の Gaussian 近似だけを確かめるもので、Z の Laplace 誤差 ε_Z は確かめていない。
  - S3 の値（0.013）は MC SE（0.025）と同じ程度で、MC で判別できる限界にある。
- **限界（FACT）:** S3 は、失敗 draw のある 9 セルと有効な開始点のない 1 セルを除いた 26 組だけで計算している。
- E と E2 の差（中央値 0.19）は、2 つの近似の違いである。どちらが正しいかは、Z の厳密な積分なしには決められない（`mathematical_notes_v2.md` §1）。

## 4. AF8 と v2 の比較（`pilot/af8_vs_v2_comparison.csv`）

- 失敗セル：22 → 2。AF8 の「status != OK」の定義を当てはめても、v2 は 2 である。
- 開始点の不一致：AF8 0.056 → v2 0。**定義と単位が違う**ので、直接は比較できない。
  - AF8：(データ, regime, 列, prior) の行ごとに、D と E の開始点の差の最大値をとり、sentinel を含めて 1e-6 を超えるかどうかを見た。
  - v2：セルごとに、D の有効な開始点だけを見た。
  - v2 の無効な開始点は別に記録した：D 65/1944（3.3%。NOT_CONVERGED 54、LINESEARCH_FAIL 6、HESS_FD_FAIL 5）、E 4/2590。
  - 有効な開始点が 1 つだけの D セルが 9 あり、そこでは AGREE が自明に成り立つ。
- \|ΔE2−ΔIS\| の中央値 0.017 → 0.013：IS の実装（warm start か cold start か、分母の扱い）、seed、組の集合（33 組と 26 組）が違うので、同じ条件の比較ではない。
- CPU 時間：5,227 s → 15,040 s。
