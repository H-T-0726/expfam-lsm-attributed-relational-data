# 公平性・妥当性の監査（Experiment A・B、2026-11-27）

同じ AI（Claude）が作成プロセスの中で行った監査であり、人間の第三者査読ではない。評価は研究結果集 09 章の 4 段階（A 直接の対応比較／B 限定付き／C 記述のみ／D 比較してはならない）に従う。

## Experiment A

| 比較 | 評価 | 理由 |
|---|---|---|
| 同じデータでの正指定（Bernoulli）vs 誤指定（Poisson） | **A** | 同一の X・Y・test mask・学習 mask、同一の init/mc seed（独立集計で確認）。family だけが違う |
| dense vs sparse（主要対比 I） | **A（限定付き）** | 同一データ・同一 test。sparse の学習 mask は dense の部分集合で、違いは学習に使う Y の量だけ。ただし学習 Y が変わると MC・初期化の経路（informed init の w0 など）も変わる |
| 本実験と M1（#134）・MX2（PR #168） | **C** | M1・MX2 は列ごとの family（G3/B6/P3）、n=75、d=12。本実験は全列 Bernoulli、n=150、d=15、K-exp2 の K=3 の信号。向きの比較は記述のみ |
| 本実験と fixed 系列（C）の Exp4 | **D**（数値の比較） | 実装系列（E-scalar と fixed）、生成器、Y の観測量の操作の有無が違う |

**確認した項目**
- データ漏洩：test ペアは学習 mask に入らない（生成検査）。非学習ペアの Y を反転しても E-step の勾配・strict Q・M-step（w0）が変わらない（技術検証）。
- 失敗の扱い：160/160 OK、INCOMPLETE なし、再実行・seed 変更なし。
- 独立な単位：20 データ（初期値は平均して 1 つにした）。
- 事前登録：protocol は本実験の fit 前に凍結。gram 相関・Z の L サンプル平均・held-out は事前に決めた副次指標。推定 $Z$ の二乗平均と $\hat w$ の条件別の記述は**事後**。

**注意すべき交絡と限界**
1. sparse では正指定のモデル自身が Z をほとんど回復できていない（RMSE_Z ≈ 1.02、gram 相関 ≈ 0.24）。誤指定の悪影響の大きさは、「正指定でも弱い回復」の上で測ったものである。
2. Procrustes は回転だけを合わせる（尺度は合わせない）。ただし推定 Z の二乗平均はどの条件でも ≈ 1（`scale_Z`）で、gram 相関（尺度に依らない）でも同じ向きだった。
3. 1 つの信号設計（K=3、F = √2.5 Q、w = 1、edge 確率 0.20）、1 つの誤指定（Bernoulli→Poisson）、1 つの sparse 率（10%）。
4. MCEM 10 反復・L=10 の固定予算（収束は確認していない）。

## Experiment B

| 比較 | 評価 | 理由 |
|---|---|---|
| 同じ replicate の G01 vs GM（分散だけ違う Gaussian） | **A** | Z・F・Y・w・w0・雑音 E・init/mc seed が同一。X の雑音の分散だけが違う（独立集計で確認） |
| 同じ replicate の GM vs P（trace を合わせた Gaussian vs Poisson） | **B** | Z・F・Y・seed は同一。期待 Fisher 情報の **trace だけ**を合わせた。方向ごとの情報（Poisson は条件数 1.14〜1.17、Gaussian は等方）、z ごとの情報の変動、Gaussian の分散推定（罰則 +d）、尤度の形が違う |
| 同じ fit での C_Q vs C_Lap | **B** | 研究結果集 FC-14 と同じ理由（θ̂ は C_Lap の停留点ではない、INCOMPLETE は C_Lap 側だけ、推定目標が違う） |
| 本実験と K-exp2 本実験（O-b-9、A-b-9） | **C** | 同じ設計規則だが、乱数の使い方が違い（本実験は 3 条件で Z・F・Y を共有）、データは別物 |
| family の違う条件間で C_Q・C_Lap の絶対値を比べる | **D** | 尤度の正規化・罰則の項数が違う。選択された K だけを比べる |

**確認した項目**：3 条件で Z・F・Y の hash が一致、X の hash は異なる（独立集計）。trace の一致は相対誤差 < 1e-12（技術検証）。期待 Poisson Fisher の閉形式はモンテカルロ（40 万標本）と相対誤差 1.4e-3 で一致。Poisson・Gaussian の Fisher 情報は、解析勾配の数値微分と相対誤差 3e-10 で一致（v2。v1 は二重数値微分の誤差で不合格になった記録を保存）。

**注意すべき交絡と限界**
1. trace の一致は情報量の 1 つの要約であり、「情報量を完全にそろえた」ことではない。
2. GM の分散（約 0.76）は Gaussian-X の推定でも推定される。推定された分散が真値と違えば、推定上の情報量は変わる。
3. 10 データ・1 つの K_TRUE（9）・1 つの信号規則。
4. MCEM 10 反復・L=10。

## 両実験に共通
- 系列 E-scalar（prototype）。fixed 系列の結果ではない。本文採用は Human Gate。
- 探索的な実験。confirmatory evidence と呼ばない。
- A の runner ファイルは、A の本実験中に `tech_B` 関数だけを修正した（commit `3b3b09b`、fit・生成・mask・解析のコードは不変、A の worker は修正前に起動）。そのため A の protocol に記録したファイルの SHA-256 と、現在のファイルの SHA-256 は一致しない。B の protocol は修正後のファイルで凍結した。
- A・B の本実験がすべて終わった後、A の図の縦軸ラベル（切れていた）だけを短くした。そのため、どちらの protocol の SHA-256 も現在のファイルとは一致しない。修正後に `analyze A` を再実行し、CSV と JSON が修正前とバイト単位で同一であることを確認した。B の解析は修正前のファイルで実行した。
