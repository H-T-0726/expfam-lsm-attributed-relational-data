## 1. 訂正：C_Q で K を増やす条件の不等号（`diagnostic_report.md` 165 行）

**誤り（165 行）**

$$-2\Delta(\ln p(X\mid Z)+\ln p(Y\mid Z)) > n(1+\ln 2\pi) + (d-K+1)\ln n$$

- 改善（$\Delta>0$）があるとき、左辺は負になる。そのため、この式はほぼ成立しない。
- 実際、この式と「C_Q が下がった」が一致するのは 270 組中 107 組だけだった。これは C_Q が上がった組の数と同じである。

**正しい条件**
- $\ell(K)$ を、X と Y の対数尤度の L サンプル平均（strict の定数補正を含む）とする。$\Delta\ell=\ell(K)-\ell(K-1)$ とおくと、次が成り立つ。

$$C_Q(K) < C_Q(K-1) \iff 2\Delta\ell > n(1+\ln 2\pi) + (d-K+1)\ln n$$

- 右辺は $425.68 + (16-K)\times 5.0106$。
  - K=2 で 495.8、K=10 で 455.7 になる。
  - K=8→9 では **460.756** になる。
- 270 組（3 条件 × 10 データ × K=2..10）の全てで、この同値関係が保存 C_Q と一致した（別プロセスで確認）。
- 165 行と 224 行のコストの**数値**（約 461、約 460〜500）は正しい。誤りは不等号の向き（左辺の符号）だけである。
- 224 行の「約 460〜500」は、正確には 455.7〜495.8。

**導出の根拠**

| 段階 | 内容 | 根拠 |
|---|---|---|
| ① | $C_Q = -2Q_{\rm strict} + p\ln n$ | `eval_utils.py` `calc_bic_exp` |
| ② | パラメータ数 $p = Kd - K(K-1)/2\;(+d\ \text{Gaussian-X})$ | 同上。$w_0,w$ は数えない |
| ③ | $Q_{\rm strict} = \frac1L\sum_l[\ln p(Z_l)+\ln p(X\mid Z_l)+\ln p(Y\mid Z_l)]$ ＋ 定数補正 | `calc_Q_dual_strict_exp`（208–211 行） |
| ④ | $\ln p(Z_l) = -\frac{nK}{2}\ln(2\pi v_z) - \frac{1}{2v_z}\lVert Z_l\rVert_F^2$ | 同上 |
| ⑤ | `scale_Z` は L サンプル全体で $\frac1{nKL}\sum_l\lVert Z_l\rVert_F^2 = 1$ にそろえる | `reproduction/src/model.py` 497–503 行 |
| ⑥ | $Q_{\rm strict}$ はスケール後のサンプルで計算される | `em_runner.py` 272 行（scale）→ 340 行（Q） |

- ⑤〜⑦より、$-\frac2L\sum_l \ln p(Z_l) = nK(1+\ln 2\pi)$ は厳密に成り立つ。
- ①〜⑦を合わせると、次の式になる。
  - $-2\ell(K) = C_Q - p\ln n - nK(1+\ln 2\pi)$
- K を 1 つ増やしたとき
  - パラメータ数は $p(K)-p(K-1) = d-K+1$ だけ増える。$p$ の式は別プロセスで独立に書き、`num_params` と全 600 fit で一致した。
  - $+d$ と strict の定数補正は K に依らないので、差をとると消える。

## 4. 明確化：A の「校正」の表現（`diagnostic_report.md` 94–110 行、239 行）

- 「誤指定のほうが校正が良い」「改善の中身は過信の少なさ（校正）」という**一般的な言い方はしない**。

| 指標 | 正指定 Bernoulli | 誤指定 Poisson | 有利な側（データ数） |
|---|---:|---:|---|
| 平均対数スコア（大きいほど良い） | −0.573 | −0.540 | 誤指定 19/20 |
| ECE（小さいほど良い） | 0.100 | 0.070 | 誤指定 20/20 |
| 校正の傾き（1 が理想） | 0.218 | 0.087 | **正指定が 1 に近い 18/20** |

| AUC | 0.579 | 0.517 | 正指定 20/20 |

**書き直した表現**
- sparse の plug-in 予測では、次の 3 つが同時に起きていた。
  - 誤指定の fit は予測確率の広がり（SD）が小さく、定数予測に近い。
  - そのため ECE と対数スコアの損が小さかった。
  - 一方、校正の傾きは誤指定のほうが 0 に近く、1 から遠い。
    - 予測確率の違いがリスクの違いとほとんど対応していない、ということである。

- 正指定の fit は、順位付けは上だった（AUC・AP）。ただし、確率の広がりが識別力に比べて大きい（傾き 0.22）。
- dense では、どの指標でも両者の差は小さい。

## 5. 明確化：`Z_mean` による plug-in 予測は事後予測分布ではない

- `Z_mean` による予測は $\sigma(\hat w_0 + \hat w\,\bar z_i^\top \bar z_j)$ である。
  - $\bar z$ は、最後の E-step の L=10 サンプルの平均。
  - これは事後予測分布 $\frac1L\sum_l \sigma(\hat w_0+\hat w\, z_i^{(l)\top} z_j^{(l)})$ では**ない**。
  - 個々のサンプルが保存されていないので、事後予測分布は計算できない。
- 既存の文書は `Z_mean` 予測を「事後予測ではない」と明記している（`analysis_protocol.md` 27 行、`diagnostic_report.md` 25 行）。それでも、104 行の「L サンプル平均で予測すると逆転が消える」は、事後予測の代わりとして読まれうる。
- 新たに確認したこと（NPZ から）：**`Z_mean` は縮んでいる。**
  - sparse での成分の二乗平均：`Z_last` はほぼ 1。`Z_mean` は 0.597（Bernoulli）と 0.416（Poisson）。
  - そのため `Z_mean` 予測は、$\hat z_i^\top\hat z_j$ の広がりが小さい予測になる。
  - 予測確率の SD は、正指定 0.109、誤指定 0.036。
- したがって、`Z_mean` で逆転が消えたことは、サンプル平均による縮小で予測の広がりが小さくなったこととも整合する。
  - このことから、事後予測分布でも逆転が消えるとは言えない。
- 「両モデルとも定数予測に劣る」は、`Z_last` による plug-in 予測に限られる。
  - `Z_mean` 予測では、定数予測に勝ったデータ数は、正指定 15/20、誤指定 10/20 だった。

## 6. C_Lap の数式と実装の対応（最終確認）

**数式**（`laplace_k_criterion.py` の docstring）
- K を固定した推定値 $\hat\theta$ のもとで、Laplace 近似を使う。

$$\ln p(X,Y\mid\hat\theta,K) \approx \Phi(\hat Z) + \tfrac{nK}{2}\ln 2\pi - \tfrac12\ln|H(\hat Z)|$$

$$C_{\rm Lap} = -2\ln p(X,Y\mid\hat\theta,K) + d_K \ln N$$

- 各記号の意味
  - $\Phi(Z) = \ln p(Z)+\ln p(X\mid Z)+\ln p(Y\mid Z)$（strict の定数を含む）
  - $\hat Z$：$\Phi$ の同時モード
  - $H = -\nabla^2_Z \Phi$：$nK\times nK$
  - $d_K = Kd-K(K-1)/2$、$N=n$

**実装との対応**

| 項目 | 実装 | 確認 |
|---|---|---|
| $\Phi$ | `complete_log_density`：`calc_Q_dual_strict_exp` を 1 点の Z で評価 | C_Q と同じ関数・同じ定数 |
| 勾配 | $-Z/v_z + S_X F + w R_Y Z$ | 手で導出した式と一致 |
| $H$ の対角ブロック | $I/v_z + F^\top\mathrm{diag}(c_i)F + w^2\sum_j C_{ij}z_jz_j^\top$ | 手で導出した式と一致 |
| $H$ の非対角ブロック | $w^2C_{ij}z_jz_i^\top - wR_{ij}I$ | 手で導出した式と一致 |
| Gaussian-X の分散 | `diag(sigma)` を列ごとの分散として使う | $\ln p(X\mid Z)$ と同じ |
| 値 | `phi + 0.5 n k ln(2π) − 0.5 logdet` | `laplace_k_criterion.py` 273 行 |
| 有効性の条件 | 勾配の最大値 ≤ 1e-8、かつ $H$ が正定値。そうでなければ値を返さない | ridge・jitter は加えない |
| 罰則 | `d_K · ln(150)` | 全 600 fit で一致 |

- 確認方法：勾配と $H$ の式は、unique pair の Bernoulli/Poisson-Y と列ごとの X の対数尤度を微分して、手で導出した式と照合した。
  - Y 側の勾配 $w\sum_j R_{ij}z_j$ には、1/2 は付かない。順序付きペアの 1/2 と、$z_i$ が 2 回現れることが打ち消し合うためで、採用式と一致する。
- 保存値の分解：$C_{\rm Lap} = \underbrace{-2(\Phi - \ln p(\hat Z))}_{\texttt{lap\_fit\_mode}} + \lVert\hat Z\rVert^2 + \ln|H| + d_K\ln n$
  - Z の事前密度の $-\frac{nK}{2}\ln 2\pi$ は、Laplace 近似の $(2\pi)^{nK/2}$ と打ち消し合う。
  - そのため C_Lap には、C_Q の定数 $nK(1+\ln 2\pi)$ に当たる項がない。

**保存値での確認**（598 個の OK fit。別プロセスでは自分で書いた式から計算）

| 確認した関係 | 最大の差 |
|---|---|
| `lap_fit_mode` = $-2(\Phi-\ln p(\hat Z))$ | 3.6e-12 |
| `lap_log_observed` = $\Phi + \frac{nK}{2}\ln2\pi - \frac12\ln\lvert H\rvert$ | 0 |
| C_Lap を項に分解したときの閉じ方 | 3.6e-12 |
| ln\|H\| の符号が全て +1 | — |
| 別プロセスで計算した C_Lap との相対差 | 0 |

**解釈上の注意**（数式と実装の不一致ではない。適用範囲の限定）
1. $\hat\theta$ は MCEM の推定値である。Laplace で近似した観測データ尤度を最大化したものではない。
   - したがって C_Lap は、$\hat\theta$ での観測データ対数尤度の近似に罰則を足したもので、周辺尤度そのものではない。
2. 単一のモードの近似である。多峰性は扱わない。
3. $\hat Z$ には `scale_Z` の正規化がかかっていない。C_Q のサンプルとは、Z の扱いが違う。
4. 罰則 $d_K$ には Gaussian-X の分散（$d$ 個）が入っていない。C_Q の $p$ は入れている（差は G01・GM で 15、P で 0）。
   - この差は K に依らないので、選ばれる K は変わらない。
   - ただし、C_Q と C_Lap の**絶対値**は比べられない。
5. $N=n$ は作業上の約束で、証明されたサンプルサイズではない。
6. `diagnostic_report.md` 233 行の「C_Lap では 2 データが INCOMPLETE」の明確化
   - 内訳は G01 の 1 fit と P の 1 fit（NOT_STATIONARY）。
   - **GM は 200 fit 全てが OK**。直前の GM の記述（2/10 で過小）とは関係しない。
