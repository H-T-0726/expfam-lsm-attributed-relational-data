# 10 全結果のまとめ（研究領域ごと）

[← README](README.md)

各領域について、問い・最重要の結果・成功した条件・失敗した条件・系列・証拠の強さ・限界・次に必要な検証をまとめる。
「証拠の強さ」は、事前登録・独立なデータでの再現・本監査での再計算の有無から付けた目安で、採用の決定ではない。

## A. 元論文・基礎モデル

| 項目 | 内容 |
|---|---|
| 問い | 一般化実装は先行研究と同じに動くか。採用式は元論文とどう違うか |
| 最重要の結果 | 先行研究条件の $k_{est}$=3・4 で、再現実装との RMSE(Z) 差 < 0.001（VERIFIED） |
| 成功した条件 | Control（Gaussian-X / Bernoulli-Y、$K_{TRUE}=3$）、$k_{est}$=3・4 |
| 失敗・差が出た条件 | $k_{est}=6$ では差 0.024 |
| 系列 | B と reproduction（どちらも 0.5） |
| 証拠の強さ | 中（同一条件の実装比較、5 試行） |
| 限界 | 採用式（1/2 なし）の検証ではない |
| 次に必要な検証 | 採用式の系列（C または E）で同じ比較をするか（Human Gate） |

## B. 指数型分布族への拡張

| 項目 | 内容 |
|---|---|
| 問い | 分布を変えても $Z$ を推定できるか。$n$・$d$・誤指定の影響 |
| 最重要の結果 | fixed 系列で $n=50\to300$ の RMSE(Z) 減少 49.3/41.2/58.6%。誤指定で最悪 4.34×/9.04×/40.37×（VERIFIED） |
| 成功した条件 | 3 シナリオすべてで $n$ とともに改善。$n=150$・$K_{TRUE}=3$ で C_Q が 30/30 |
| 悪化した条件 | 誤指定（特に Y の誤指定。Scen.C で 13〜40 倍）。Scen.B で $d$ を 15 より増やすと平均は増加（ただし中央値は単調に減少し、平均の増加は少数 trial の外れ値による） |
| 差がなかった条件 | Scen.C で $d$ を変えても平坦。Scen.C で Y が正しければ X の誤指定は 1.00 倍 |
| 系列 | C（fixed）。予稿の数値は B（別記） |
| 証拠の強さ | 中（各条件 10 trial、1 つの生成設定） |
| 限界 | historical generator（clip・標準化あり）、一致性ではない、旧 0.5 との対応表がない |
| 次に必要な検証 | canonical 生成器での $n$・$d$ 依存（必要かは Human Gate） |

## C. 実データ

| 項目 | 内容 |
|---|---|
| 問い | 実データで安定に動くか、予測できるか、属性・分布で予測は変わるか |
| 最重要の結果 | 属性・分布族による予測の差は小さい。MovieLens +0.0042（23/30、ばらつきに埋もれる）。Cora BX−GX +1.06×10⁻⁴（13/15、符号はそろうが中心化で逆転）（VERIFIED） |
| 成功した条件 | 新しい組合せ（Bernoulli-X / Poisson-Y）でも数値的に安定。旧 Cora で random を上回る（transductive） |
| 悪化した条件 | MovieLens の raw-count Poisson 属性（−0.100、29/30 で悪化） |
| 差がなかった条件 | MovieLens の mixed vs genre_only は分割間のばらつきに埋もれる |
| 向きが前処理で変わった条件 | Cora の family 差（raw 同士では BX が 13/15 で上回るが、中心化した GXc では逆転） |
| 矛盾する結果 | 旧 Cora で C_Q は $k=1$、AUC/AP は $k=6$、NMI は $k=3$ を選んだ |
| 系列 | C（Wine・旧 Cora・MovieLens in-sample）、E+F（MovieLens #33）、E-scalar（CORA-SH1） |
| 証拠の強さ | 弱〜中（1 データセットずつ、split は独立でない） |
| 限界 | 真の $Z$・$K$・分布は不明。Wine の Y はラベル由来 |
| 次に必要な検証 | 研究者による CORA-SH1 の確認と、E-scalar を評価用の実装として認めるか（Human Gate） |

## D. 複数分布 X（per-column）

| 項目 | 内容 |

## F. 潜在次元 K の選択

| 項目 | 内容 |
|---|---|
| 問い | $K$ を正しく選べるか。どの基準がどの条件で過小・過大になるか |
| 最重要の結果 | **成否と誤りの向きは条件で変わった**。K-exp2 regime a では C_Q 200/200・過大 0。原論文本文どおりの強信号（#165、別の生成器・試行ごとの集計）では C_Q は過小 0 だが誤りは過大（29/50 正解）。K-exp2 の 300 データ全体では C_Q 正解 276・過小 24、C_Lap 正解 249・過小 4・INCOMPLETE 47（$K_{TRUE}=3$ の重複を除いた 270 データでは C_Q 246・24、C_Lap 227・4・39）。弱信号・高い $K_{TRUE}$ では C_Q が過小（K-exp2 A-b-9 0/10、混合 X $K_{TRUE}=9$ 0/10）。同じ fit で C_Lap は 6/10・9/10（VERIFIED） |
| 成功した条件 | 方向ごとの信号を固定（K-exp2 regime a 200/200）、Gaussian-Y、$n$ が大きい |
| 失敗した条件 | 全体の信号を固定して $K_{TRUE}$ が大きい（A-b-7・A-b-9・B-b-9）、$n=75$ の弱信号、条件付き尤度型の基準（常に過大） |
| 矛盾する結果 | C_Lap の過大選択：#159・K-exp2 の完了データでは 0、#165 では 20/50（評価不能 6） |
| 系列 | ほぼ E（prototype）。fixed Exp1 のみ C |
| 証拠の強さ | 中（K-exp2 本実験は事前登録・8,000 fit。C_Lap の比較・追加 A〜C は探索） |
| 限界 | 一致性なし、C_Lap は近似、INCOMPLETE、$K_{TRUE}\neq K^\ast$ の可能性、原論文との比較不可 |
| 次に必要な検証 | 小さい $n$ での高精度な周辺尤度（AIS など）で C_Lap の誤差を測る、θ の最適化不足を測る（いずれも Human Gate） |

## G. 理論・実装監査

| 項目 | 内容 |
|---|---|
| 問い | 数式とコードは対応しているか。基準は何を計算しているか。$K$ は識別できるか |
| 最重要の結果 | 採用式（1/2 なし）の導出。C_Q は ICL 型で Schwarz BIC ではない。Poisson-X（P1）・Gaussian-Y（P2）で population の識別可能性 |
| 未解決 | Bernoulli-Y の識別可能性（U2）、一致性（U6）、C_Q ≈ C_Lap + 2H の近似が成り立つ理由（termA と R3 の打ち消し） |
| 系列 | — |
| 証拠の強さ | 導出と有限差分・恒等式の数値確認（#163：39 項目） |

## 全体の「改善・悪化・差なし」

| 区分 | 例 |
|---|---|
| 改善した | $n$ を増やす（fixed）、sparse-Y での属性の同時利用、強信号・$n$ 大での $K$ 選択、弱信号で C_Lap を使う（同じ fit） |
| 悪化した | 分布の誤指定、raw-count Poisson（MovieLens）、Scen.B で $d$ を増やしたときの平均（中央値は改善、外れ値による）、弱信号・高 $K_{TRUE}$ での C_Q |
| 差がなかった | dense-Y での属性の同時利用（最良の単独 block との比較）、Scen.C の $d$、MovieLens の mixed vs genre_only（ばらつきに埋もれる）、AF6 の Laplace vs Q（未達成） |
| 失敗・中断 | Phase 8b Attempt 1（中断）、AF8・AF8-v2（停止規則）、C_Lap の INCOMPLETE（main10 47/300、重複を除くと 39/270） |
