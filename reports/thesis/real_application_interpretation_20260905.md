# 実応用での解釈 — 真の K が分からない場面で何を評価するか

**作成日:** 2026-09-05
**動機:** 先生のご指摘 6「Y が疎な場合、未知の関係を予測することにどうつながるか」、
および「実応用した際に」という論点への材料整理。

**前提:** `true_k_identifiability_hardened_20260904.md` §2.1 で確定したとおり、
**実データでは `K*`（観測分布を表現できる最小潜在次元）が存在しない**（M-closed 仮定が成立しない）。
したがって実応用では **「真の K を当てられたか」を評価できない。**
本文書は「では何を評価するのか」を整理する。

---

## 1. 人工データと実データで、評価できるものが違う

| | 人工データ（clean） | 実データ |
|---|---|---|
| `K_TRUE` | **既知**（generator の設定） | 存在しない |
| `K*` | 定義できる（M-closed を構成で満たす） | **存在しない**（誤指定） |
| 真値一致率 | 測れる | **測れない** |
| held-out 予測性能 | 測れる | **測れる** |
| 選択の安定性 | 測れる | 測れる |

**結論:** 実データで測れるのは **予測性能と安定性**であり、
**構造的な正しさ（`K*` の回復）ではない。**

---

## 2. 疎な Y のもとで held-out 予測が何を意味するか

本研究の held-out 手続きは **dyad（ノード対）を 20% 取り置く** transductive な設計である。

```
学習: 観測された 80% の dyad のみ
評価: 取り置いた 20% の dyad 上で  y·η − log(1+e^η)  の平均
```

### 2.1 これは「未知の関係の予測」そのもの

疎な Y では、実務上の関心は「まだ観測されていないリンクがあるか」である。
取り置いた dyad はまさにその代理になる。したがって
**held-out スコアは実応用の目的関数とよく対応している。**

### 2.2 ただし transductive である

取り置くのは **dyad であってノードではない。** 全ノードは学習時に存在し、
その潜在座標 `z_i` は他のリンクから推定されている。したがって

- **評価できるのは:** 既知ノード間の未知リンク（link prediction）
- **評価できないのは:** 新規ノードに対する予測（inductive generalization）

`[EMPIRICAL_EXISTING]` 既存の Phase 7e / 8b も同じ transductive 設計であり、
`RESEARCH_MASTER.md` §12.7 に「inductive 一般化は評価していない」と記録されている。

### 2.3 「観測されたゼロ」と「欠測」の区別

**本研究の設定では `y_ij = 0` は「リンクなし」という観測値**であり、欠測ではない。
実データでは両者が区別できないことがある（例: 未観測ペア）。
**本研究はこの区別を扱っていない。** 実応用でここを混同すると、
欠測を「リンクなし」として学習し、密度を過小推定する。`[UNRESOLVED]`

## 3. 属性 X の役割 — 何が言えて何が言えないか

### 言えること

- **sparse-Y の人工設定では、複数属性を同時に使う per-column モデルが指定した comparator より
  RMSE(Z) を改善した**（`RESEARCH_MASTER.md` §12.3、lineage E+F）。
- Poisson-X については **population で `FF^T` が復元でき、X 側の潜在構造が識別できる**（命題 P1）。
  すなわち **X は原理的に潜在座標の情報を持つ。**

### 言えないこと

- 「属性を使えば一般に良くなる」— **dense-Y では利得が +0.0087 まで縮小**し、
  `single_vs_joint` では符号すら逆（−0.0004）。**regime 依存**である（KI-002・§12.3）。
- 「実データでも属性が効く」— MovieLens primary は**平均方向は正だが split 間変動に比べて小さい**。
  有意性検定・CI・検出力は未計算（§12.5）。
- **今回の clean n-sweep からは何も言えない。** X の信号強度を
  平均 `‖f_l‖² = 0.5` の **1 水準に固定**しており、X の寄与を分離して測っていない。

**したがって「Y が疎なとき X が助ける」は、
現時点では *人工データの特定 regime における限定的な証拠* に留まる。**

## 4. 実応用でのモデル選択 — 現実的な手続き

`K*` が存在しない以上、実応用では次の形になる。

### 4.1 実際にできること

| # | 手続き | 根拠 |
|---|---|---|
| 1 | dyad を取り置き、**held-out 予測スコアで K を選ぶ** | 目的関数と直結。本研究の S1 |
| 2 | **複数の初期値で選択が一致するか**を確認する | 今回、初期値不一致が不安定性の指標になった（`n=50` で 8/8 不一致 → `n=150` で 1/8） |
| 3 | **複数の基準で選択が一致するか**を確認する | 今回、S1 と S2 は 64 中 44 セルで一致、S3 は 0〜2 セルしか一致しなかった |
| 4 | 選択の **margin** を見る | margin が極小なら「選べていない」に近い |
| 5 | Poisson-X なら **Gram spectrum を診断として見る** | ただし閾値は事前に決められない（U7） |

### 4.2 実際にはできないこと

- 「真の K を推定した」と言うこと
- 選ばれた K を**構造的な次元**として解釈すること
- 一つの基準の結果だけで K を確定すること

### 4.3 今回の実験が実応用に与える具体的な警告

| # | 警告 | 根拠 |
|---|---|---|
| **W-a** | **`n` が小さいと K を過小に選ぶ。** 誤りの向きは一貫して under-selection だった | `K_TRUE=5` で `n=50` の平均 selected K は 2.62（真値 5） |
| **W-b** | **小さい K が選ばれても「本当に低次元」とは限らない。** 候補集合の下端と tie rule により下限へ張り付きうる | `K_TRUE=1` が全 `n` で 4/4 だが下限効果と交絡 |
| **W-c** | **`Z` を積分しない基準を使ってはいけない。** 候補上限に張り付く | S3 が 64 中 3、ほぼ全セルで `K=7` |
| **W-d** | **初期値を 1 つしか使わないと選択が不安定。** 小 `n` では特に | `n=50` で 8/8 のセルが初期値によって別の K を選んだ |
| **W-e** | **Poisson-Y を使うなら `\|w\| < 1/2` を確認する。** さもないと分散が定義されない | 命題 P6・KI-020 |

**W-a〜W-e はいずれも「今回テストした合成設定での観測」であり、
実データでそのまま成立する保証はない。** ただし **実務上のチェックリストとしては使える。**

## 5. 「真の K が分からないまま何を検証するか」

実データで検証可能なものを、強い順に並べる。

| 強さ | 検証できること | 方法 |
|---|---|---|
| 強 | **未知リンクの予測性能** | dyad holdout + 対数スコア（本研究の S1） |
| 強 | **選択の安定性** | 初期値・分割・基準を変えたときの selected K の一致 |
| 中 | **属性を足したときの予測改善** | X あり / なしの held-out スコア比較（**今回は測っていない**） |
| 中 | **推定された潜在座標の解釈可能性** | クラスタ・既知ラベルとの対応（Cora で試行、KI-011 で基準ごとに最適 k が割れる） |
| 弱 | **選ばれた K の構造的意味** | **`K*` が存在しないので検証できない** |

---

## 6. 修論の実データ章で書くべきこと

1. **`K*` が存在しないことを最初に書く。** そのうえで「予測に最適な K を選ぶ手続き」として提示する。
2. **selected K を「潜在構造の次元」と呼ばない。** 「予測性能を最大化する候補次元」と書く。
3. **複数基準・複数初期値の一致度を必ず併記する。** 単一の値だけを出さない。
4. **transductive であることを明記する。** 新規ノードへの一般化は評価していない。
5. **観測ゼロと欠測の区別を扱っていないことを明記する。**
