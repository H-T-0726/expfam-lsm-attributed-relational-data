## 2. 本サイクルで行った診断

### 2.1 Z の点推定の選び方（D1）

**方法**: 同じ θ̂ と同じ fit から、3 つの点推定を作って比べた。

| 記号 | 定義 |
|---|---|
| `last` | `Z_samples[:, :, -1]`。現行のすべての runner が報告している値 |
| `mean5` | 最後の E-step の L=5 サンプルの平均 |
| `mode` | `ln p(X, Y_train | Z, θ̂) + ln p(Z)` の joint mode。C_Lap 用に計算済み |

- `mode` は fit と同じ training mask（`model._mask_f`）で計算されていることをコードで確認した。test ペアの漏洩はない。
- 真の Z は凍結した data seed から再生成し、X の hash（B）と mask の hash・密度（A1）が記録と一致することを確認した。

**RMSE_Z（Procrustes 後、K_est = K_TRUE、中央値）**（`rmse_z_summary.csv`）

| 実験 | 条件 | last | mean5 | mode | start 間の差の中央値（last → mode） |
|---|---|---|---|---|---|
| A1（Poisson-X） | K_TRUE=3, n=50 | 0.476 | 0.399 | 0.367 | 0.0109 → 0.0027 |
| A1 | K_TRUE=3, n=150 | 0.323 | 0.254 | 0.235 | 0.0132 → 0.0003 |
| A1 | K_TRUE=5, n=50 | 0.607 | 0.484 | 0.440 | 0.0192 → 0.0073 |
| A1 | K_TRUE=5, n=150 | 0.427 | 0.338 | 0.308 | 0.0209 → 0.0003 |
| B（Gaussian-X、強い信号） | K_TRUE=5 | 0.168 | 0.134 | 0.121 | 0.0090 → 0.0006 |
| B | K_TRUE=9 | 0.214 | 0.168 | 0.150 | 0.0031 → 0.0005 |

**S1（held-out の plug-in mean log score）による K 選択**（A1、2 start の平均で選択、`a1_s1_selection_by_estimator.csv`）

| 点推定 | K_TRUE=1 | K_TRUE=3 | K_TRUE=5 | 合計 | per-start の選択の不一致 |
|---|---|---|---|---|---|
| last（記録値と一致） | 16/16 | 9/16 | 14/32 | 39/64 | 28/64 |
| mean5 | 16/16 | 14/16 | 22/32 | 52/64 | 26/64 |
| mode | 16/16 | 14/16 | 22/32 | 52/64 | **5/64** |

K_TRUE=5 の n 別の内訳（exact）は次のとおり。

| 点推定 | n=50 | n=75 | n=100 | n=150 |
|---|---|---|---|---|
| last | 2 | 0 | 4 | 8 |
| mode | 4 | 3 | 7 | 8 |

**言えること（OBSERVED）**
- この 2 つの生成条件では、現行の点推定はサンプリングのノイズを含み、RMSE_Z を約 1.2〜1.45 倍に大きくしていた。
- 同じデータでの start 間の差の大部分も、このノイズで説明できた。
- S1 の K 選択の「過小選択」と「n に対して単調でない真値一致数」（`RESEARCH_MASTER.md` §17.5）は、点推定を変えるだけで大きく変わった。

**言えないこと**
- `mode` が「正しい」点推定であるとは言えない。mode は縮小し、Laplace の solver が NOT_STATIONARY の fit では停止点である。
- S1 が K 選択に適した基準になったとも言えない。
- 事後の比較なので、確認には事前登録した実験が必要である。

**C_Q と C_Lap への影響**
- C_Q は 5 サンプルすべての平均（`Q_strict`）を使い、C_Lap は mode を使う。したがって、この点推定の問題は直接は受けない（FACT）。
- ただし、θ̂ 自体の MC 誤差は受ける（§2.2）。

### A. モデルの数理的妥当性

**A1 X に切片がない（既存の未解決: #28 §19、KI-018）**
- 生成モデルと推定モデルの両方に切片がない。そのため人工データでは、このミスマッチが**一度も現れない**（FACT）。
- Bernoulli-X では z=0 のとき P(x=1)=0.5 に固定され、まれな 0/1 属性（実データの genre など）は Z を歪めて表現するしかない（DERIVED）。
- MovieLens の mixed-X の悪化の候補原因の 1 つだが、切り分けられていない。
- 改善案: 生成側にだけ基準率を入れた人工データで、現行モデルの崩れ方を測る（モデルの変更なしの診断）。そのうえで、切片を加えるかを Human が判断する。
- コスト: 中。モデルの変更は Human Gate。

**A2 識別可能性**（既存: U1・U2・U4）
- Bernoulli-Y（実験で使っている family）の識別可能性は未証明である。
- 回転は Procrustes、スケールは `scale_Z` と prior で扱っている（FACT）。
- 本サイクルでは新しい知見はない。理論課題として残す。

**A3 対応する分布族**（既存）
- categorical と、自然パラメータの定義域が ℝ でない族（NB・Gamma など）は対象外である（#129 §6）。
- 過分散の count（MovieLens の Y）は Poisson で score として扱っているだけである。

## 5. 上位 3 件の検証計画

### E1（最優先）: M1 の再現と、Z の点推定による誤指定の効果の再評価

- **mode**: CHARACTERIZATION（再評価）。M1 の結論を「救う」ことも「否定する」ことも目的にしない。
- **Research question**: M1 の dense / sparse の ΔRMSE_Z と interaction は、Z の点推定を `last` から `mode`（および `mean5`）に替えても、向きと大きさを保つか。その対比較の差は、MC 誤差（model seed の違い）に比べて大きいか。
- **設計**
  - **Part A（replay、80 fit）**: M1 と同じ code（`run_misspecification_m1.py`）、データ、mask、seed で 80 fit を再実行する。状態（`Zsamples`・θ̂）は repository 外に保存し、sha256 を記録する。
  - **integrity 条件**: 記録された `rmse_Z`（last）を 80/80 で再現すること（許容誤差は事前に 1e-12 と固定）。再現しなければ、比較に進まず原因を記録して止める。
  - **Part B（seed の追加、80 fit）**: model seed だけを `1344000 + r` に変えた 80 fit。値は事前に固定し、結果を見て変えない。
  - **点推定**: `last`（再現用）、`mean5`、`mode`。mode は `laplace_k_criterion.laplace_log_observed`（`DualExpFamLSMPerColumnConsistent` に対応済み、training mask を使う）で計算する。NOT_STATIONARY は補完せずに記録し、OK だけの集計と全件の集計を併記する。
- **主要な指標**: `mode` による paired ΔRMSE_Z（wrong − correct）。dense / sparse / interaction について、平均・中央値・IQR・正の数を出す。
- **副次的な指標（事前に固定）**
  - `last` と `mean5` での同じ量。
  - Gram 相関の差。
  - `mode` と `last` での held-out の log score・AUC の差。
  - arm × regime ごとの点推定の膨張 `RMSE_last − RMSE_mode`。
  - seed 間の揺れ `|Δ(seed A) − Δ(seed B)|` と `|Δ|` の比。
- **規模**: 160 fit（M1 は 80 fit で 871 秒）+ Laplace の mode の計算。約 40〜60 分。wrapper は約 150 行。新しい gate・auditor は追加しない（`CLAUDE.md` §6）。
- **結果の分岐（どれでも次の判断が変わる）**

  | 結果 | 分かること | 次の判断 |
  |---|---|---|
  | 向きと大きさが保たれる | M1 の結論は点推定に頑健である | mode を標準の評価にして M2 へ進む |
  | sparse は残り、dense は消える | 「dense では効果がない」と主張を絞る | 同上（主張を狭める） |
  | 両方が消える、または逆転する | M1 の効果は、事後分布の幅とサンプルのノイズの違いによる成分だった | #138 で推奨した framing を見直す（Human） |
  | seed 間の揺れ ≥ \|Δ\| | 1 seed の対比較では効果を判定できない | M2 の前に E2（L の増加）が必要 |

### E2: MC サンプル数 L と iterate averaging

- **Research question**: L を 5 → 20 にすると、θ̂ の揺れの床、基準（C_Q、C_Lap、S1 の mode）の fit 内の揺れ、start 間の一致、K 選択はどう変わるか。最後の 4 反復の θ̂ を平均すると、同じ効果がより安く得られるか。
- **条件（案）**: A1 と同じ generator。K_TRUE=5、n ∈ {75, 150}、replicate 1..8、K ∈ {4, 5, 6}、2 start、L=20、20 反復。96 fit。
  - L=5 の側は既存の EMC 実験（8〜40 反復）を再利用する。
  - averaging は、同じ run の反復ログから事後に計算する（事前登録の副次的な指標）。
- **前提**: 反復ごとに状態を記録する runner（`em_runner_instrumented.py`）は、ローカルのブランチにしかない（§6）。まず remote に保存し、記録の扱いを Human が決める必要がある。
- **結果の分岐**
  - 揺れが L に応じて減り、start 間の一致と選択が安定する → これまでの K 選択の不安定さは主に MC 誤差だった。今後の基準の比較は L≥20 で行う。
  - 減らない → MC 誤差ではなく、多峰性や識別性の問題である。Laplace や K 選択の理論の側へ進む。
- **コスト**: 約 2〜3 時間の計算と、小さな wrapper。

### E3: Z の回復の単純なベースライン（EM なし）

- **Research question**: 単純な方法（Y_train の隣接行列の spectral embedding、標準化した X の SVD、その結合）の Z の回復は、MCEM の推定（`mode`）と比べてどの程度か。その差は dense / sparse でどう変わるか。
- **データ**: A1（64 datasets）と B（25）の保存済みデータ。M1 のデータは E1 の後に追加する。真の Z は seed から再生成する。
- **指標**: Procrustes 後の RMSE_Z と Gram 相関。ベースラインのスケールは、Gram 相関を主にして扱う。
- **結果の分岐**
  - モデルが明確に上回る → モデルに基づく推定の価値を、数字で示せる。
  - 同程度 → この条件の人工データは易しすぎる。どの条件でモデルの価値が出るか（sparse-Y、誤指定、mixed-X）へ実験を集中する。
- **コスト**: 小（数分の計算、約 150 行）。
