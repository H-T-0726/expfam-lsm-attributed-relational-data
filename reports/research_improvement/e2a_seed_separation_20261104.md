# E2a：sparse-Y の推定結果は初期値と MC 乱数のどちらに敏感か（Issue #142）

- 日付: 2026-11-04
- 種別: CHARACTERIZATION
- 系列: lineage E-consistent（per-column、`numerics_mode="consistent"`）。prototype であり、本文には採用できない。
- 前提: E1（Issue #141、PR #145、commit `568b4db`）
- 設計: 実行前に commit `368b938` で固定した。Issue #142 のコメントも参照。

## 1. 問い
- E1 では 1 つの seed が初期値（Z・F）と E-step の MC 乱数の両方を決めていた。そのため、sparse-Y に残った run 間の変動（Δ の A–B 差の中央値 0.046）がどちらから来るのか分からなかった。
- 今回は、片方の seed だけを変えたときに、次の 2 つがどう変わるかを調べた。
  - joint mode での paired ΔRMSE_Z（wrong − correct）
  - fit ごとの推定値

## 2. 方法
- **条件**: E1 の sparse-Y と同じ。
  - n=75、d=12、K=3
  - correct G3/B6/P3、wrong G3/P6/P3、Bernoulli Y
  - データ seed・mask は E1 と同じ
  - L=5、8 反復、consistent、fail_fast
- **seed 分離**: `run_em_experimental` に opt-in の `init_seed` / `mc_seed` を追加した。
  - `init_seed` は `initialize_params` だけに、`mc_seed` は E-step の `rng` だけに使う。
  - 既定値は `seed` で、それ以外の計算は変えていない。
- **組み合わせ**: seed A = 1343000+r、B = 1344000+r とした。

| 組み合わせ | 初期値 | MC | 扱い |
|---|---|---|---|
| AA | A | A | E1 Part A を再利用 |
| BB | B | B | E1 Part B を再利用 |
| AB | A | B | 新規 |
| BA | B | A | 新規 |

- **規模**: 新規 80 fit（20 replicate × 2 組み合わせ × 2 arm）。correct と wrong は同じデータ・mask・seed を共有する。
- **主要指標**: mode（最終 θ̂ での joint mode、Z0 = last）の paired ΔRMSE_Z。replicate ごとに次の対比を計算した。
  - MC 対比: Δ_AB − Δ_AA、Δ_BB − Δ_BA
  - 初期値対比: Δ_BA − Δ_AA、Δ_BB − Δ_AB
  - 交互作用: (Δ_AA + Δ_BB − Δ_AB − Δ_BA) / 2
- **判定の目安（事前に固定）**: 対比の絶対値の replicate 中央値を比べる。
  - 一方が他方の 2 倍以上なら、その側が優勢とする。
  - 両方が 0.01 未満なら、どちらも小さいとする。
  - それ以外は同程度とする。

## 3. 技術的な妥当性
- **smoke**: rep01 sparse の AA・BB × correct・wrong の 4 fit を新しい引数で実行し、E1 の保存結果と比べた。Z_samples、Z_est、F、w0、w、mode と全評価値の 84 項目が完全に一致した（差 0.0、MATCH）。
- **本実験**: 80/80 が成功した。retry・replacement・seed rescue はすべて 0、警告も 0。
- **再利用した組み合わせ**: state から計算し直した値は E1 の CSV と一致した（差 0.0）。
- **joint mode**: 160/160 が OK。新規 fit では最大 |grad| 9.1e-9、H の最小固有値 ≥ 0.23、反復 4〜11。
- **局所解**: mean5 から始めた mode が別の解に収束したのは、E1 で既知の 1 件（BB）だけだった。

## 4. 結果

### 4.1 主要指標：mode の ΔRMSE_Z（wrong − correct）

| 組み合わせ | 平均 | 中央値 | IQR | 正（/20） |
|---|---|---|---|---|
| AA | +0.076 | +0.078 | +0.055 – +0.104 | 18 |
| AB | +0.107 | +0.101 | +0.069 – +0.149 | 19 |
| BA | +0.077 | +0.079 | +0.047 – +0.104 | 17 |
| BB | +0.087 | +0.077 | +0.050 – +0.127 | 20 |

| 対比 | 平均 | 中央値 | 絶対値の中央値 |
|---|---|---|---|
| MC（初期値 A） | +0.031 | +0.028 | 0.044 |
| MC（初期値 B） | +0.010 | +0.009 | 0.028 |
| 初期値（MC A） | +0.001 | +0.004 | 0.046 |
| 初期値（MC B） | −0.020 | −0.019 | 0.040 |
| 交互作用 | −0.011 | +0.007 | 0.021 |
| 両方を変える（AA→BB） | +0.011 | +0.014 | 0.046 |

- replicate ごとに平均した |MC 対比| の中央値は 0.042、|初期値対比| は 0.040 で、判定は **COMPARABLE**（同程度）だった。MC 対比のほうが大きかった replicate は 8/20。
- 交互作用（0.021）は、片方だけを変えたときの差（約 0.04）の半分程度だった。
- 誤指定効果の向きは保たれた。
  - 4 組み合わせすべてで Δ > 0 だった replicate が 14/20、3 組み合わせで正が 6/20 だった。
  - replicate 内での 4 組み合わせ間の Δ の SD は中央値 0.036 で、効果の大きさ（約 0.08）の半分程度。
- 回転＋倍率を合わせた RMSE でも同じ傾向だった（MC 0.034、初期値 0.032、Δ は +0.061〜+0.088）。

### 4.2 fit ごとの推定精度（mode の RMSE_Z、arm 別の対比の絶対値の中央値）

| arm | MC（初期値 A / B） | 初期値（MC A / B） |
|---|---|---|
| correct | 0.022 / 0.020 | 0.047 / 0.030 |
| wrong | 0.022 / 0.023 | 0.032 / 0.034 |

- fit ごとの精度は、初期値のほうに 1.5〜2 倍ほど敏感だった。
- それでも Δ では両者が同程度になった。考えられる説明は次のとおり（INTERPRETATION）。
  - 初期値は両 arm で共有されるため、その影響が対比較の差で部分的に打ち消される。
  - MC 乱数は、arm ごとに経路が分かれたあとで別々に効くため、打ち消されにくい。
- wrong arm の MC 対比は、初期値 A・B のどちらでも 15/20 が正だった。ただし、replicate ごとに異なる seed の組での観察であり、偶然の可能性があるため解釈しない。

### 4.3 解の近さ（同じ replicate・arm の 2 つの組み合わせ間、中央値）

| 共有しているもの | mode の Gram 相関（correct / wrong） | mode 間の RMSE | F の相対差 |
|---|---|---|---|
| 初期値 | 0.967 / 0.954 | 0.165 / 0.185 | 0.27 / 0.21 |
| MC | 0.886 / 0.861 | 0.330 / 0.353 | 0.45 / 0.39 |
| なし | 0.877 / 0.848 | 0.356 / 0.347 | 0.44 / 0.40 |

- 初期値が同じなら、MC 乱数を変えても Z と F はほぼ同じ解に落ち着いた。
- 初期値を変えると、両方を変えた場合と同じくらい違う解になった。
- **8 反復後の解の位置は、主に初期値で決まっている**（OBSERVED）。

### 4.4 副次指標
- held-out log score の Δ は、初期値への感度（0.0125）が MC（0.0077）より大きく、MC 対比のほうが大きかった replicate は 2/20 だった。AUC と Gram 相関の Δ は同程度だった。
- Z のノルム比の Δ は小さかった（中央値 −0.005 〜 −0.015）。
- 組み合わせ別の中央値は、4 組み合わせ間でほぼ同じだった。
  - mode の RMSE_Z: correct 0.70〜0.73、wrong 0.79〜0.82
  - mode のノルム比: 0.84〜0.86
- last では、すべての対比が mode より大きかった（約 0.06）。点推定のノイズが上乗せされるためである。

### 4.5 探索的な事後解析（凍結した設計の外）
- 同じ replicate・arm の 4 組み合わせの中で、mode での log joint（Φ）が最大の解を選んでも、RMSE_Z は 4 組み合わせの平均より 0.003 低いだけだった（中央値 −0.002、低かったのは 23/40）。Spearman 相関の中央値は −0.3。
- 完全データの目的関数で複数の start から選ぶ方法は、この条件では精度をほとんど改善しない可能性がある（HYPOTHESIS、未検証）。

## 5. 言えること
- sparse-Y の誤指定効果（Δ > 0）は、初期値と MC 乱数のどちらを変えても保たれた。
- E1 で見えた A–B の変動（約 0.046）について、次のことが分かった。
  - 初期値だけを変えた場合と MC 乱数だけを変えた場合で、同程度の大きさ（約 0.04）が再現された。
  - 交互作用はその半分程度だった。
  - 片方だけに原因があるわけではない。
- 推定された解の位置（Z の配置、F）は主に初期値で決まり、MC 乱数を変えても同じ初期値からはほぼ同じ解に落ち着く。それでも、MC 乱数だけで fit ごとの RMSE は約 0.02 変わる。

## 6. 言えないこと
- 初期値と MC 乱数の一般的な分散寄与。水準は 2 つずつ、replicate は 20 で、1 つの条件しか見ていない。
- 初期値で解が分かれる原因が、多峰性（別々の局所解）なのか、8 反復では初期値の影響が消えきらない収束不足なのか。今回のデータでは区別できない。
- dense-Y や他の K・family 条件への一般化。
- Φ による start 選択の有効性（探索的な観察のみ）。

## 7. 仮説の区別
| 仮説 | 今回の証拠 |
|---|---|
| 単純な MC ノイズ | 一部だけ当てはまる。同じ初期値で MC 乱数を変えると、fit ごとの RMSE は約 0.02、Δ は約 0.04 変わる。ただし解の位置はほぼ変わらない |
| 多峰性 | 否定できない。初期値を変えると別の解（Gram 相関 0.85〜0.89）になる。ただし、局所解であることは確認していない |
| 収束不足 | 否定できない。8 反復で初期値の影響が残っているだけという説明も同じ観察を生む |

多峰性と収束不足を区別するには、同じ初期値の組で反復数を増やし、解が近づくかどうかを見る必要がある。

## 8. 推定方法への示唆（HYPOTHESIS、Human 判断）
- 評価では、複数の初期値で fit した Δ を平均するのが最も直接的である。初期値の影響は対比較で部分的に打ち消され、MC 乱数の影響は平均で減る。
- L を増やすことで期待できるのは、MC 乱数による約 0.02（fit ごと）の部分だけである。初期値由来の解の分かれは L では解決しない見込みが高い。
- Φ による start 選択は、今回の探索的な観察では効果が小さい。

## 9. 次の Human 判断
- 初期値への感度と MC 乱数への感度が同程度だったため、事前に決めた分岐では「両方の影響が大きい」に当たる。
- 比較可能な次の候補:
  1. **反復延長**: AA・BA の初期値の組で反復を 8 → 40 にし、初期値の違う解が近づくか（収束不足か多峰性か）を見る。
  2. **E2b**: L=20 で、MC 乱数による fit ごとの揺れがどれだけ減るかを見る。
  3. **評価の変更**: 複数の初期値での平均を評価の標準にする。
