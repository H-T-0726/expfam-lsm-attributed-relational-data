# 先生向けブリーフ — 「真の潜在次元」を理論保証した条件での K 選択実験

**2026-09-07 / 詳細版: `canonical_gaussian_y_k_selection_experiment_20260907.md`**

---

## A. 問題

これまで人工データ実験では「生成時に `K = 3` としたから真の潜在次元は 3」として結果を読んでいました。
しかしこれは正しくありません。区別すべきものが 2 つあります。

- **`K_GEN`** … generator で `Z` を何列作ったか（手続き上の数）
- **`K_0`** … その観測分布 `p(X,Y)` を表現するのに必要な**最小**の潜在次元

一般に `K_0 <= K_GEN` で、等号は自明ではありません。
さらに監査の結果、**従来の人工データ生成器では `K_0` がそもそも存在しない**ことが分かりました。
生成器が `Z` を列ごとに標本 z-score しているため、生成分布がモデル族 `M_K` の外に出てしまい、
`min{K : p_* in M_K}` の対象集合が空になるためです（Scenario B・C で証明済み）。

つまり従来の「BIC が `K=3` を 30/30 で選んだ」は、
**`K_hat = K_GEN` の一致**であって **`K_hat = K_0`（真の次元の回収）ではありません。**

---

## B. 今回定義した `K_0`

```
M_K = { p(X,Y) : z_i ~ iid N(0, I_K), theta in Theta_K }
K_0 = min { K : p_* in M_K }
```

---

## C. Gaussian-Y なら `K_0 = K_GEN` を理論保証できる

canonical Gaussian-Y モデル `y_ij = w0 + w z_i^T z_j + eps_ij`（`z_i ~ iid N(0,I_K)`、`eps ~ N(0,sigma_y^2)`）で、
`w != 0` なら **1 本の dyad の周辺分布だけで `K` が一意に決まります**。

```
kappa_4(Y) = 6 K w^4,  kappa_6(Y) = 120 K w^6   =>   K = (200/3) kappa_4^3 / kappa_6^2
phi_Y(t) = exp(i w0 t) (1 + w^2 t^2)^{-K/2} exp(-sigma_y^2 t^2/2)
```

反例を探す姿勢で 7 系統の攻撃（`w` の再スケール、ノイズとのトレードオフ、`w'=0`、`K'=0` 等）を
試しましたが**すべて失敗**し、独立な 2 通りの証明（キュムラント／特性関数）が得られました。

ただしこの定理は**薄い**です。`S_K = S_{K'} + S_{K-K'}`（独立和）なので、
**ノイズを Gaussian に固定するという仮定を外すと厳密な反例が作れます**（`K=2` は `K=1` + 独立ノイズと同分布）。

---

## D. その条件で現行 Q-based 基準を試した

**生成器だけを canonical にし、推定側は従来の fixed official Exp1 と完全に同じ**にしました。
従来の Scenario C と公称パラメータは完全一致で、**差分は生成器の 1 行（`Z` の列 z-score）だけ**です。

- `K_0 in {1,3,5}`（`n=150`）＋ `K_0=3`（`n in {50,150,300}`）＋ `K_0=3`・`n=150` で信号強度 `w in {0.25, 1.0}`
- 各 10 試行、候補 `K = 1..9`
- **630 fits、失敗 0、事前の理論ゲート 10/10 PASS、事後の整合性監査 18/18 PASS**
- 設定は実行前に凍結し、結果を見てからの変更は一切していません

---

## E. 実験結果

**`K_0` を 70/70（100%）で回収しました。** 同点は 0 件、過大選択も過小選択もありません。

| 条件 | 回収 |
|---|---|
| `K_0 = 1`（`n=150`） | 10/10 |
| `K_0 = 3`（`n = 50 / 150 / 300`） | 10/10 / 10/10 / 10/10 |
| `K_0 = 5`（`n=150`） | 10/10 |
| `K_0 = 3`, 信号強度 `w = 0.25 / 1.00`（`n=150`） | 10/10 / 10/10 |

`k = K_0` での推定値も真値へ収束しました（`w_hat = 0.253 / 0.489 / 1.009` に対し真値 `0.25 / 0.50 / 1.00`、
`sigma_y_hat` は全条件で `0.100`）。

**信号強度を 4 倍動かしても選択は変わりませんでした。** これは重要な副産物です。
推定の初期化器は `w` を常に `0.5` に置きますが、`w_true = 0.25` と `1.0` では
**初期値が真値と一致しません**。それでも回収は 10/10 で `w_hat` も真値へ収束したので、
「初期値がたまたま真値と一致していたから当たっていたのでは」という懸念は
少なくともこの範囲では否定されました。

---

## F. なぜその結果になったか（ここが本題）

**「当たった」ことより「なぜ当たったか」が重要でした。** 基準を分解すると厳密に

```
C_Q(K) = D_K            （当てはまり項）
       + P_Z(K)         （潜在変数の事前分布項）
       + P_theta(K)     （明示的なパラメータ罰則 p_hat log n）
```

となり、**`P_Z(K) = n K (log 2*pi + 1)` は完全に決定論的**でした（実測との差 `4.5e-13`）。
推定側の `scale_Z` が `Z` のスケールを固定するため、この項は**データを一切含まない**、
`K` に比例する「隠れ罰則」として働きます。

`K_0` の隣（`K_0 -> K_0+1`）での限界収支:

| 条件（`K_0=3`） | 当てはまりの改善 | 隠れ罰則 | 明示罰則 | 差引 | 隠れ/明示 |
|---|---|---|---|---|---|
| `n=50` | −70 | **+142** | +47 | +119 | **3.0×** |
| `n=150` | −168 | **+426** | +60 | +317 | **7.1×** |
| `n=300` | −285 | **+851** | +68 | +635 | **12.4×** |
| `n=150`, `w=0.25` | −177 | **+426** | +60 | +309 | **7.1×** |
| `n=150`, `w=1.00` | −148 | **+426** | +60 | +337 | **7.1×** |

**隠れ罰則 `+426` は信号強度 `w` を 4 倍動かしても完全に同じ値です。**
式 `n K (log 2π + 1)` に `w` が入らないことの実測確認になっています。`w` が動かすのは当てはまり項だけです。

**当てはまり項 `D_K` は `K` について単調に良くなり続け、`K_0` に極小を持ちません。**
止めているのはほぼ `P_Z` です。実際、`P_Z` を外して選び直す診断では

> **70/70 すべてで選択が変わり、67/70 が候補上限の `K = 9` に張り付きました。**
> 信号強度 arm では 30/30 すべてが `K = 9` でした。この診断結果は `w` に対して頑健です。

さらに罰則の**階数**が Schwarz 型と違います。

```
隠れ罰則 P_Z     の傾き = n (log 2*pi + 1)   =  O(n)        （実測ちょうど 2 倍: 426 -> 851）
明示罰則 P_theta の傾き = (d-K+1) log n      =  O(log n)
```

つまり現行基準の実効的な罰則は **`O(nK)`** であって `O(p log n)` ではありません。
これは潜在変数を「完全データ」として採点する基準（ICL 型）の帰結で、
**「Schwarz BIC と呼ばない」という従来の方針に定量的な裏付けが付いた**形です。

**なお、私が実験前に立てた予測は 2 回とも外れました。**

1. 「当てはまりの改善は dyad 数 `O(n^2)` に比例するので、`n` を上げると隠れ罰則 `O(n)` を
   追い越して過大選択に向かう」→ 実測は改善が `n^0.76`、隠れ罰則が `n^1.00` で、
   **罰則の方が速く伸び、余裕はむしろ広がりました**。
2. 「信号が弱い（`w=0.25`）と当てはまりの改善が縮んで余裕が広がる」→ 実測は**逆**で、
   **信号が弱いほど余分な次元が稼ぐ見かけの当てはまりが大きく（−177 対 −148）、余裕は狭まりました**
   （309 対 337）。真の信号が強いと `K_0` 次元モデルがすでに `Y` をよく説明しており、
   余分な次元が吸収できる残差が少ない、という向きが自然な解釈ですが**切り分けていません**。

いずれも棄却して記録しています。なお `w` による変動幅は ±4.5% と小さく、
**この設定では `n` の方が余裕をはるかに強く支配しています**（`n` 2 倍で余裕 2 倍）。

## G. 先生に相談したい点

1. 真の潜在次元を「観測分布から一意に識別できる `K_0`」と定義する方針でよいでしょうか。
   採用すると、**過去の人工データ実験の読み方を全面的に書き換える**必要があります
   （`K_TRUE` を真値扱いできなくなる）。

2. Gaussian-Y のように識別可能性を理論保証できる条件を「基準の評価台」として使う方向でよいでしょうか。
   それとも識別可能性が未解決の family（Bernoulli-Y など）へ先に広げるべきでしょうか。

3. 現行基準の `K_0` 回収が、明示罰則ではなく **`-2E[log p(Z)]` という `O(nK)` の隠れ罰則**に
   依存していることが分かりました。この項の理論的地位を修論で正面から扱うべきでしょうか、
   それとも「現行基準の記述」に留めるべきでしょうか。

4. 次の 1 手をどれにすべきでしょうか。信号強度 arm は実行済みで、選択は変わりませんでした。
   (a) `sigma_y` の掃引（今回 0.1 に固定。Y の SNR を直接動かす唯一の未検証軸）
   (b) `n` をさらに広げた掃引
   (c) `d` の掃引
   (d) 他 family への拡張

## H. 注意（この結果で言ってはいけないこと）

- **「Q-based 基準は consistent である」とは言えません。** `n` は 3 点のみです。
- **「BIC が正しい」とは言えません。** これは Schwarz BIC ではありません。
- **「すべての指数型分布族で真の `K` を回収できる」とは言えません。** 検証は 1 設定のみです。
- **従来の `30/30` と今回の `70/70` を同じ表に並べてはいけません。** 意味が違います
  （前者は `K_hat = K_GEN`、後者は `K_hat = K_0`）。
- **検証していない軸が残っています。** `sigma_y` は 0.1 に固定、`d` は 15 に固定、
  `w` も 0.25〜1.0 の範囲のみです。`w -> 0`（定理の前提が壊れる境界）は未検証です。
- 信頼区間・検定・検出力・bootstrap は一切計算していません。各条件 10 試行の記述値です。
