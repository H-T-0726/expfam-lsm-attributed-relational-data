## A. 「真の K」について

### Q1. 真の K って結局何ですか？

**短答:** 観測分布 `(X, Y)` を表現できる**最小の潜在次元**です。

**技術的回答:** 潜在次元 `K` のモデルが表現できる分布の集合を
`M_K = { ∫ p(Z)p(X|Z)p(Y|Z)dZ : θ ∈ Θ_K }` とし、真の観測分布 `P0` に対し
`K* = min{ K : P0 ∈ M_K }` と定義しました。`K` は非負整数上を動くので、
候補集合が空でなければ最小元は必ず存在します（入れ子性は不要）。

**証拠:** 理論監査 §2。

**主張境界:** この定義は **`P0 ∈ ⋃_K M_K`（M-closed）を前提**とします。
実データでは普通成立せず、**その場合 `K*` は存在しません。**

### Q2. generator で K=5 にしたなら true K = 5 じゃないんですか？

**短答:** そうとは限りません。`K* ≤ K_TRUE` で、等号は自明ではありません。

**技術的回答:** `K_TRUE` は「`Z` を何列作ったか」という**手続き上の数**、
`K*` は「できた観測分布の最小次元」です。たとえば `rank(F) = r < K_TRUE` かつ `w = 0` なら、
X は `r` 次元しか持たず Y は潜在に依存しないので `K* ≤ r < K_TRUE` です。

**証拠:** 理論監査 §2.3・§5。

**主張境界:** 今回の clean generator は識別可能性の前提（`rank(F)=K`、`w≠0`、`d≥K`）を
**構成で強制**していますが、**それが `K* = K_TRUE` の十分条件であることは family ごとに未検証**（U9）。
したがって**実験の「真値一致率」は `K_TRUE` との一致であって `K*` との一致ではありません。**

### Q3. じゃあ実データに true K なんてあるんですか？

**短答:** 一般には**ありません**。

**技術的回答:** `K*` の定義は M-closed 仮定に依存します。実データでモデル族が
真の分布を厳密に含むことはまずないので、`{K : P0 ∈ M_K} = ∅` となり `K*` は定義されません。
代替として KL 射影次元 `K° = min argmin_K inf_{θ∈Θ_K} KL(P0‖P_θ)` が考えられますが、
その存在には `M_K` の閉性が必要で、**本研究では未確立**です（U11）。

**証拠:** 理論監査 §2.1・§2.4。本リポジトリの Cora・MovieLens は KI-011・KI-012・KI-018 で
誤指定が記録されています。

**主張境界:** 「実データで真の K を推定した」とは書けません。

## B. 生成器について

### Q4. なぜ正規化すると問題なんですか？

**短答:** `z_i ~ N(0, I_K)` が iid でなくなり、識別可能性の証明の前提が崩れるからです。

**技術的回答:** 列ごとの z-score は、列の標本平均を厳密に 0、標本 SD を厳密に 1 に強制します。
すると行（＝ノード）の間に依存が入り、`z_i` は独立ではなくなります。
Gaussian-Y の識別性の証明は `‖z_j‖² ~ χ²_K` を使いますが、これが成立しません。
Poisson-X の証明も `E[exp(f^T z)] = exp(‖f‖²/2)` という Gaussian の MGF を使うので同様です。

**証拠:** `expfam/src/data_generator_expfam.py` L.122-123 / L.282-283（一次コードで確認）。KI-021 G1。

**主張境界:** これは「過去結果が間違い」という主張では**ありません**（Q5 参照）。

### Q5. 過去の実験は全部無効なんですか？

**短答:** **いいえ。無効ではありません。**

**技術的回答:** 過去の結果は「その生成器が作ったデータ上での観測」として有効です。
失われるのは「**canonical model から well-specified に生成したデータで検証した**」という
**強い読み方**だけです。とくに Poisson-X の識別可能性命題は
unclipped link と iid `N(0,I)` を前提とするため、historical generator では
その前提が成立せず、**当該実験の well-specification を保証しません。**

**証拠:** KI-021。理論監査 §13・§17.5。

**主張境界:** 「historical generator のせいで過去結果は無効」と書くことは**禁止**しています。

### Q6. なぜ clean generator を新しく作ったんですか？

**短答:** 識別可能性の前提が成立するデータで K 選択を調べたかったからです。

**技術的回答:** 「真の K を当てられるか」を調べたいのに、そのデータで
真の K が決まる保証がない、という状態でした。そこで forward-only の別モジュールを新設し、
`Z` の正規化なし・`F` の行正規化なし・X の事後正規化なし・Poisson の clip なし・
分散パラメータを実際に使用、という 5 点を直しました。
`rank(F) = K` は QR 分解による**構成**で保証し、**seed rescue（当たるまで引き直す）は禁止**して
失敗したら停止します。

**証拠:** `canonical_clean_generator_spec_20260904.md`、
`expfam/src/experimental/data_generator_canonical.py`、テスト 46 件。
**historical generator は 1 文字も変更していません**（`git diff` で確認可能）。

**主張境界:** 「clean generator で全問題を解決した」とは書けません。
`family_y = bernoulli` の識別可能性は依然として未解決です。

### Q7. 信号の強さを K ごとに揃えたのはなぜですか？

**短答:** 揃えないと「K を当てた」のか「信号が強かっただけ」か区別できないからです。

**技術的回答:** `Var(z_i^T z_j) = K` なので、`w` を固定すると `K` が大きいほど Y 側の信号が強くなります。
X 側も `f_scale` 固定なら平均 `‖f_l‖² = f_scale²K/d` が `K` とともに増えます。
そこで平均 `‖f_l‖² = 0.5` と `w²K = 3.0` が `K_TRUE` によらず一定になるようにしました。

**証拠:** 実験の全 64 セルで平均 `‖f_l‖² = 0.500000`、`w²K = 3.000000`
（`generator_provenance.csv`）。Y density も 0.318–0.340 で揃っています。

**主張境界:** **この整合自体が設計判断**です。`f_scale` を固定して信号が K とともに増える設計では
別の結果になりえます。

## C. 識別可能性について

### Q8. Poisson-X ならなぜ K が分かるんですか？

**短答:** 平均と共分散から行列 `FF^T` を復元でき、その階数が K だからです。

**技術的回答:** `X_l | z ~ Poisson(exp(f_l^T z))`、`z ~ N(0,I)` のとき
Gaussian の MGF から `E[X_l] = exp(‖f_l‖²/2)`。`l ≠ m` では列が条件付き独立なので
`E[X_l X_m] = E[exp((f_l+f_m)^T z)] = exp(‖f_l+f_m‖²/2)`。したがって
`‖f_l‖² = 2 log E[X_l]`、`f_l·f_m = log(E[X_lX_m]/(E[X_l]E[X_m]))` で Gram 行列が決まります。
競合表現 `(K', F')` も同じ式を満たすので `F'F'^T = G`、ゆえに `K' ≥ rank(G)`。
逆に `K' = rank(G)` の表現は実在するので、**X 周辺の最小次元 = `rank(G)`** です。

**証拠:** 理論監査 §7（命題 P1）。数値確認 `poisson_x_gram_recovery`（rel err 0.0017）。

**主張境界:** ①**unclipped exp link** が必要 ②`rank(F)=K` は **generic 条件**で全域ではない
③これは **X 周辺の最小次元 `K^rank`** であって `K*` ではない。`Y` にしか現れない次元は数えません
④**population の主張**であり、有限標本では使えません（Q10）。

### Q9. Bernoulli ではどうなんですか？

**短答:** `d=1` では **X からは** 決まりません（反例あり）。一般の Bernoulli-Y は**未解決**です。

**技術的回答:** `z` が 0 対称で `sigmoid(u)+sigmoid(−u)=1` なので `E[X_l] = 1/2` が
`K` にも `f_l` にも依りません。`d=1` なら観測は各行 1 ビットで行は iid、
よって **X 周辺分布は `K` に依存しません**。
Bernoulli-Y では `w0=0` のときリンク密度が `K` によらず 1/2 になります。
K の情報はノードを共有する motif（2-star・三角形）に入り、`‖z_i‖² ~ χ²_K` を通じて現れますが、
sigmoid の Gaussian 平均が閉形式を持たないため**一般定理を作れていません**。

**証拠:** 理論監査 §8・§10。数値確認 `bernoulli_x_mean`（K=1,3,5 × 4 列すべて）。

**主張境界:** **「Bernoulli では K は識別できない」とは書けません。**
反例は `d=1` **かつ X 周辺のみ**です。実際、`w≠0` の Gaussian-Y を併用すれば
joint では識別されます。逆に「Bernoulli でも識別できる」とも書けません（U2）。

### Q10. Y だけで K を識別できますか？

**短答:** **Gaussian-Y なら、リンク 1 本の分布だけで決まります。** Bernoulli-Y は未解決です。

**技術的回答:** `S = z_i^T z_j` の MGF は `(1−t²)^{−K/2}`（`|t|<1`）で、
キュムラントは `κ_2 = K`、`κ_4 = 6K`、`κ_6 = 120K`。
`Y = w0 + wS + ε` なら `κ_4(Y) = 6Kw⁴`、`κ_6(Y) = 120Kw⁶` なので
`w² = κ_6/(20κ_4)`、`K = κ_4/(6w⁴)`、`σ_y² = κ_2 − Kw²` で全部決まります（`w ≠ 0`）。
さらに三角形の 3 次同時中心モーメントが `w³K` になるので **`w` の符号も `n≥3` で決まります**。

**証拠:** 理論監査 §9（P2・P8）。数値確認: K=3, w=0.8, 8M draws で
`ŵ²=0.6379`(真 0.64)、`K̂=3.019`(真 3)、`σ̂_y²=0.2438`(真 0.25)。
三角形は K=1,3,5 × w=±0.8 の 9 行すべてで符号一致。

**主張境界:** **Gaussian-Y 限定**です。実験で使っているのは Bernoulli-Y なので、
**この強い結果は実験結果に適用できません。** また `w = 0` では `κ_4 = κ_6 = 0` で復元式が破綻します。

### Q11. 有限のデータで `FF^T` の階数を見れば K が分かるのでは？

**短答:** **今回の実験では分かりませんでした。** 推定した `FF^T` は正定値ですらありません。

**技術的回答:** モーメント推定量は制約なしなので PSD 錐の外に出ます。
実験の**全 64 セル**で最小固有値が負（中央値 −1.80 〜 −0.52）、
閾値なしの階数は常に `d = 15` で `K` を返しませんでした。
真の `K` での固有値ギャップ比の中央値は `n` とともに増加します（`K_TRUE=5` で 1.79 → 2.30）が、
**事前に固定できる閾値がありません。**

**証拠:** `gram_spectrum.csv`（64 セル）。理論監査 §7.5・U7。

**主張境界:** **結果を見てから閾値を決めることをプロトコルが禁じています。**
したがってこの診断は selected K を作らず、固有値スペクトルとして保存するだけです。

## D. 実験結果について

### Q12. n を増やしてどうなりましたか？

**短答:** 平均で選ばれる K は真値へ近づきましたが、**真値一致数は単調ではありません。**

**技術的回答:** `K_TRUE=5` で held-out スコアの真値一致は
`n = 50, 75, 100, 150` に対し **2/8 → 0/8 → 4/8 → 8/8**、
平均 selected K は **2.62 → 3.00 → 4.50 → 5.00**。
Q ベース基準は一致 **0/8 → 0/8 → 1/8 → 7/8**、平均 **1.75 → 3.25 → 3.62 → 4.88**。
**誤りの向きは一貫して過小選択**でした。

**証拠:** `selection_matrix.csv` から独立に再計算（`clean_true_k_results_20260905.md` §3・§4）。

**主張境界:** **`n=75` で一致数がいったん 0/8 に下がります。** 単調改善ではありません。
反復は 4 または 8 のみで、信頼区間・検定・検出力は一切計算していません。

### Q13. それは consistency と言えますか？

**短答:** **言えません。**

**技術的回答:** 一致性は `n → ∞` の漸近的性質です。今回観測したのは
`n ∈ {50, 75, 100, 150}` の 4 点における有限標本の記述であり、
そこから漸近的挙動は導けません。さらに本モデルは特異（`O(K)` 不変性で Fisher 情報が退化）なので、
通常の漸近論がそのまま使えるかどうかも不明です。

**証拠:** 理論監査 §16b・U6。

**主張境界:** 書いてよいのは
「**テストした有限の n の範囲では、平均 selected K が真値へ近づき過小選択が減る傾向が観測された**」まで。
「n を増やすと K_TRUE に収束した」「K 選択の一致性を示した」は**禁止**です。

### Q14. K_TRUE=1 は全部当たっていますね。うまくいっている証拠では？

**短答:** **証拠になりません。下限効果と交絡しています。**

**技術的回答:** この設定の支配的な誤り方は**過小選択**であり、`K = 1` は候補集合 `{1,…,7}` の
**下端**です。さらに凍結した選択規則は同点なら**最小の K** を選びます。
したがって「データから K=1 を識別した」のか「下限に張り付いた」のかが区別できません。

**証拠:** 全 `n` で S1・S2 とも 4/4。一方 `K_TRUE=3, 5` では過小選択が支配的
（`clean_true_k_results_20260905.md` §8.1(2)）。

**主張境界:** **`K_TRUE=1` の結果を成功例として引用してはいけません。**
切り分けには候補集合の下端を広げるか tie rule を変えた感度解析が必要で、
**現行プロトコルは凍結済みなので新しい事前登録が要ります。**

### Q15. 初期値によって結果が変わるのは問題では？

**短答:** 変わります。そしてそれ自体が**不安定性の良い指標**になっていました。

**技術的回答:** 2 つの初期値がそれぞれ別の K を選ぶセルは、
held-out スコア・`K_TRUE=5` で `n=50` に **8/8**、`n=150` に **1/8** でした。
**選択が不安定な領域と、最適化が初期値に依存する領域が一致しています。**

**証拠:** `fit_results.csv` から per-start の argmax を再計算（`clean_true_k_results_20260905.md` §8.1(5)）。

**主張境界:** criterion 側の問題か最適化側（多峰性）の問題か、
**本実験では分離できていません**（`[UNRESOLVED]`）。

**技術的回答:** artifact のみを読み **runner を import しない**独立監査器を作りました。
protocol hash・実験 ID・generator version・lineage・family・格子・反復数・896 fits・

結果は verdict **PASS**、BLOCKER 0 / HIGH 0 / MEDIUM 0、LOW 2。
さらに監査器自身を 15 種の単一欠陥変異（selected_k 改竄・fit 欠落・seed rescue・
legacy lineage 混入・historical generator policy・退化 F・retry/resume 宣言・

## E. BIC と選択基準について

### Q17. BIC は結局使えるんですか？

**短答:** **現行実装は Schwarz BIC ではありません。** そして BIC の理論的正当化も、
このモデルでは成立しません。

**技術的回答:** Schwarz BIC が近似するのは観測データの周辺尤度 `ln p(X,Y|θ)`（Q3）です。
現行 `calc_bic_dual` が使う `Q_strict` は完全データ同時密度（Q2）の MC 平均で、
`Z` を積分していません。正当化されない理由は次の 3 つです。
①**モデルが特異**（`O(K)` 回転で観測分布が不変なので Fisher 情報が退化。`rank(F)<K`・`w=0` 上でも退化。
特異モデルでは `(p/2)log n` が RLCT に置き換わるが、本モデルの RLCT は未知）
②**境界パラメータ** ③**有効標本数が未定義**（ノード数 `n` / dyad 数 `n(n−1)/2` / X 要素数 `nd`。
実装は `log n` にノード数を使う。潜在変数 `Z` は `n` とともに増える incidental parameter）。

**証拠:** KI-010・KI-019、`paper_bic_reproduction_alignment_20260904.md`、理論監査 §17.1。
実装事実は `expfam/src/utils_expfam.py` で確認。

**主張境界:** **「BIC は非入れ子だから使えない」は誤りです。**
非入れ子が壊すのは尤度比検定の χ² 近似と Wilks の定理であって、
BIC の導出（モデルごとの Laplace 近似）ではありません。理由を取り違えないでください。

### Q18. 元論文ではなぜうまくいったんですか？

**短答:** **分かりません。** 元論文の評価手続きが本文から特定できないためです。

**技術的回答:** 元論文 Eq.(26) の当てはまり項 Eq.(16) の `ln L` は `p(Z)` を含まず `Z` も積分していない
（Q1 型）ことは一次確認済みです。しかし「どの `Z` を代入するか」「MC 平均をとるか」は
本文から特定できません。したがって元論文の基準と現行実装・今回の S3 の対応関係は確定できません。

**証拠:** `reports/k_selection_theory/paper_bic_reproduction_alignment_20260904.md`。

**主張境界:** **`[UNRESOLVED]`。** 「元論文の基準は誤りだ」とも「正しい」とも書けません。
今回 S3（Q1 型の plug-in 条件付き基準）が 64 中 3 しか当たらず候補上限を選び続けたのは事実ですが、
**S3 は私が定義した基準であり、これを元論文の基準の失敗と読んではいけません。**

### Q19. held-out を使う意味は何ですか？

**短答:** 未知の関係をどれだけ予測できるかを直接測れるからです。

**技術的回答:** リンクの 20% を取り置き、残りだけで学習して取り置いた分の対数スコア
`y·η − log(1+e^η)` を測ります。`η = ŵ0 + ŵ ẑ_i·ẑ_j`。
2 つの初期値で非加重平均し、同点なら最小の K を選びます（tie tolerance 1e-12）。

**証拠:** Phase 7e/8b と**同一定義**の関数を再利用（`run_heldout_k_selection_pilot.py`）。

**主張境界:** これは **plug-in スコア**（推定した `ẑ` を代入）であり、
モデルの予測分布に対する proper scoring rule では**ありません**。

### Q20. predictive K と true K は何が違うんですか？

**短答:** 前者は「予測に最適な K」、後者は「観測分布を表現できる最小次元」です。
**一致する保証はありません。**

**技術的回答:** 理論上、厳密に proper な scoring rule を population で評価すれば、
M-closed かつ `M_K` が交わらない場合に argmin は `K*` に一致しえます。
しかし実際に使っているのは plug-in スコアで、その population target は特定されていません。
有限標本では bias–variance のトレードオフも効きます。

**証拠:** 理論監査 §17.3（U10）。

**主張境界:** **「held-out は `K*` を推定している」とも「していない」とも書けません（U10）。**
ただし独立に確実なことが一つあります:
**「held-out で `K_TRUE` が選ばれた」は「`K_TRUE` が識別された」を意味しません。**
選択（selection）と識別（identification）は別概念です。

### Q21. 3 つの基準で結果が違いましたが、どれを信じればいいですか？

**短答:** 「どれが正しいか」を今回の実験では決められません。**食い違い自体が結果です。**

**技術的回答:** 64 セル中、held-out と Q ベースが一致したのは **44/64**、
held-out と plug-in 条件付きが 2/64、Q ベースと plug-in が 0/64、三者一致は 0/64 でした。
plug-in 条件付き（S3）は 64 中 3 しか当たらず、ほぼ全セルで候補上限 `K=7` を選びました。
`ln p(Z)` を含めず `Z` を積分しないため、潜在次元を増やすほど代入した `ẑ` への
当てはまりが良くなり、`p log n` の罰則が追いつかないためです。

**証拠:** `clean_true_k_results_20260905.md` §5。

**主張境界:** 言えるのは「**Q1 型の plug-in 条件付き基準はこの設定で強く過大選択する**」まで。
S1 と S2 のどちらが「正しい」かは、**`K*` が何かを確定できていない以上、決められません。**

## F. 研究全体について

### Q22. 指数型分布族に広げる意義は何ですか？

**短答:** 属性・関係の観測形式（連続・二値・カウント）が現実には混在しており、
Gaussian 固定では誤指定になるからです。

**技術的回答:** X 側・Y 側を独立に family 指定できる実装があり（Gaussian / Bernoulli / Poisson）、
fixed 系列の人工データでは分布族の誤指定が RMSE(Z) を悪化させることが観測されています。

**証拠:** `RESEARCH_MASTER.md` §14 ALLOWED 行、`fixed_official/exp4/*`。

**主張境界:** Categorical は**未実装**（KI-005）。「指数型分布族すべてに対応」とは書けません。
また誤指定倍率は系列・条件ごとに別値なので、出所を明記して引用します（KI-003）。

### Q23. 複数分布にしたから理論が崩れたんですか？

**短答:** **いいえ。** 崩れる理由は分布族の数ではなく、潜在変数モデルの構造です。

**技術的回答:** BIC が正当化されない理由（特異性・境界パラメータ・有効標本数の未定義）は、
family が 1 つでも同じく生じます。分布族を増やして新たに分かったのは、
**識別可能性が family によって大きく異なる**という点です
（Poisson-X は決まる、Gaussian-Y は 1 dyad で決まる、Bernoulli-X `d=1` は決まらない、
Bernoulli-Y は未解決、Poisson-Y はモーメント存在条件が要る）。

**証拠:** 理論監査 §6〜§11・§17.1。

**主張境界:** 「複数分布への拡張が理論を壊した」という因果は主張しません。

### Q24. この研究の新規性は何ですか？

**短答:** 拡張したモデルについて、**生成モデルの成立性・「真の K」の定義・family 別の識別可能性**を
明示的に扱い、**その前提を満たすデータで K 選択を事前登録して測った**ことです。

**技術的回答:** 具体的には ①canonical model の properness とモーメント存在条件の分離
②`K*` の定義と `K_TRUE` からの分離 ③Poisson-X と Gaussian-Y の population 識別可能性の証明
④Gaussian-Y での `M_K` 非入れ子性 ⑤`w` の符号が三角形から決まること
⑥前提を満たす clean generator の構築と、その上での事前登録済み n-sweep。

**証拠:** 理論監査の命題 P1・P2・P3・P6・P8、`clean_true_k_asymptotics_20260904/`。

**主張境界:** ⑥は **1 つの合成設定（`d=15`、Poisson-X / Bernoulli-Y、信号 1 水準）** に限ります。
また実装 lineage は **experimental prototype で本文採用不可**です。

### Q25. この研究の限界は何ですか？

**短答:** 一致性が未解決であること、Bernoulli-Y の識別可能性が空いていること、
実験が 1 合成設定に限ることです。

**技術的回答:** ①**`n→∞` の一致性は未解決（U6）** ②**Bernoulli-Y の識別可能性が未解決（U2）**
——しかもこれが実験で使っている family ③有限標本の rank 判定が未解決（U7）
④held-out の population target が未解決（U10）⑤`K* = K_TRUE` が未検証（U9）
⑥`K_TRUE=1` の下限効果が未分離 ⑦初期値不一致の原因が未分離
⑧実データでは `K*` が存在しない ⑨lineage E は本文採用不可。

**証拠:** 理論監査 §16、`clean_true_k_results_20260905.md` §9。

**主張境界:** ——（限界の列挙そのもの）

### Q26. 修論で最終的に何を主張しますか？

**短答:** 「拡張モデルの K 選択について、**何が言えて何が言えないかを、
理論と事前登録実験で切り分けた**」ことを主張します。

**技術的回答:** 書けるのは ①canonical model が明示条件下で proper であること
②`K*` の定義と `K_TRUE` からの区別 ③Poisson-X・Gaussian-Y の population 識別可能性
（前提を明記）④historical generator が literal generator でないこと（過去結果は無効化しない）
⑤clean 設定での**有限標本の** selected-K パターン ⑥現行基準が Schwarz BIC ではないこと。

**証拠:** `RESEARCH_MASTER.md` §17、`clean_true_k_results_20260905.md` §10。

**主張境界:** 書けないのは K 選択の一致性 / 漸近一致性 / universal true-K recovery /
現行実装が Schwarz BIC として妥当であること / held-out 予測 = true-K recovery /
Bernoulli 一般の識別可能性 / 本合成設定を超える一般化。
