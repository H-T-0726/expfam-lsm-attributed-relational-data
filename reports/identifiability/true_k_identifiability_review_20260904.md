## 2. BLOCKER

### R-01 — 反例 C1 を joint model の非識別性として書いていた（両レビュアーが独立に指摘）

**指摘（A: F-02 / B: B-01）:** §2.1 の `M_K` は **joint** `(X, Y)` の分布族である。
C1 が示したのは **X 周辺**が `Bern(1/2)^n` に縮退することだけで、`Y` については何も言っていない。
ところが同じ文書の **P2** は、Gaussian-Y・`w ≠ 0` なら `K` が **Y 側だけ**から識別されることを示している。
したがって `family_x=bernoulli, d=1, family_y=gaussian, w≠0` では `K` は joint で識別可能であり、
**C1 は同じ文書の P2 と矛盾する。**

**本監査の独立検証:** 指摘は正しい。C1 の証明は `P(X_1=1)=1/2` しか使っておらず、`Y` の分布に触れていない。
一般則として、**周辺分布で示した肯定的識別性は joint に移送できるが、否定的な非識別性は移送できない。**
P1 は前者（安全）、C1・C3 は後者（周辺限定）である。

**判定: REJECT（初版が誤り）。** §8.2 を「X 周辺に限る」へ rescope し、一般則を明記。
§5 の該当行を Y 条件付きに修正。§15 の C1・C3 に「X 周辺のみ・joint の反例ではない」を追記。
§17.4 から C1 の引用を外し、`w=0`（C2）と「X 側・Y 側とも無情報な配置」に限定。
§18 の ledger 行に「かつ X 周辺のみ」を必須限定として追加。

### R-02 — `w` の符号は識別されないという断定（Reviewer A）

**指摘（A: F-01）:** 「`w` の符号は識別されない」は**単一 dyad 周辺についてのみ**正しい。
三角形の 3 次同時モーメント `E[S_ij S_ik S_jk] = K` により、Gaussian-Y では
`E[(Y_ij−w0)(Y_ik−w0)(Y_jk−w0)] = w³K` となり、**符号が識別される**。

**本監査の独立検証:** 自前の Monte-Carlo（3×10⁶ triangles、K=1,3,5）で確認した。

| K | `E[S₁₂S₁₃S₂₃]`（se） | 解析値 | `w=+0.8` の三角形モーメント | `w=−0.8` | `w³K` |
|---|---|---|---|---|---|
| 1 | 1.0048 (0.0030) | 1 | +0.5145 | −0.5145 | ±0.512 |
| 3 | 3.0015 (0.0072) | 3 | +1.5368 | −1.5368 | ±1.536 |
| 5 | 5.0095 (0.0120) | 5 | +2.5649 | −2.5649 | ±2.560 |

導出も独立に再構成した: `z_i` について先に期待をとると `E[z_i z_i^T] = I_K` より
`E[S_ij S_ik | z_j,z_k] = z_j^T z_k = S_jk`、ゆえに `E[S_ij S_ik S_jk] = E[S_jk²] = κ_2(S) = K`。
`ε` は独立平均 0 なので交差項が消え、3 次同時中心モーメントは `w³K`。

**判定: REJECT（初版が誤り）。かつ新命題として採択。**
§9.5 を単一 dyad 限定に修正し、**新命題 P8** として §9.6 に追加。
検証スクリプトに `triangle_third_moment_of_S` / `triangle_identifies_sign_of_w`（9 行）を追加した。
**この命題は初版になく、敵対レビューによって初めて得られたものである。**

## 3. HIGH（採択したもの）

### R-04 — clip が historical データの有限性を説明するという因果（A: F-03）

**指摘:** 実現サンプルは clip の有無によらず a.s. 有限である（`S` が a.s. 有限なので `λ` も `Y` も有限）。
発散するのは population の 2 次モーメントであって実現値ではない。
さらに `w0=0, w=0.5` では `P(η_y > 10)` が 10⁻⁷ オーダーで、**clip はほぼ発動しない**。

**本監査の確認:** 論理は正しい。`clip` の非発動もレビュアーの 2×10⁷ dyad の見積もり
（K=1: 0、K=3: 5e−08、K=5: 0）と、`w·S` の分散が `w²K = 0.25K` であることから整合する
（`η_y > 10` は K=3 で約 11.5σ）。

**判定: REJECT（初版が誤り）。** §11.3 を全面改訂。正しい記述は
「`w=0.5` は canonical unclipped model で population 分散が発散する境界そのものであり、
clip はその事実を隠しても救ってもいない」。
加えて B-19 の指摘（`Z` の z-score により `‖z_j‖² ~ χ²_K` が成立しないので、O1 は
historical データの分布についての主張ではない）も採択した。

### R-05 — Schwarz BIC の導出は入れ子性を前提としない（A: F-04 / B: B-04）

**指摘:** 初版 §12.3-3 は「尤度比検定の χ² 近似、Schwarz BIC の標準的導出、Wilks の定理」を
まとめて「入れ子性を前提とする漸近論」と書いたが、**BIC はモデルごとの Laplace 近似であり
非入れ子比較に使うのは標準的**である。しかも同じ文書の §17.1 は正しいことを書いており、
**内部矛盾**していた。B はさらに正しい診断（特異性・境界パラメータ・有効標本数）を提示した。

**本監査の確認:** 指摘は正しい。BIC の導出は per-model の周辺尤度近似であり、
モデル間の包含関係を使わない。壊れるのは LRT と Wilks である。
また `RESEARCH_MASTER.md` §14 UNRESOLVED に既に「本モデルの RLCT 未知（U5）」がある
（レビュアー B の指摘どおり、既知の正しい診断を誤った診断で置き換えていた）。

**判定: REJECT（初版が誤り）。** §12.3-3 と §1 executive を訂正。
§17.1 を全面改訂し、BIC が正当化されない実際の理由（`O(K)` 不変性による特異性、
`rank(F)<K`・`w=0` 上の退化、境界パラメータ、有効標本数の未定義）を明記した。

### R-06 — held-out score が `K*` を推定していないという断定（A: F-05 / B: B-07）

**指摘:** キュムラント論法は非論理的（「`K*` が 4 次・6 次に符号化されている」ことは

population argmin は `K*` に一致しうる。
**B は正しい論拠を提示した**: Phase 7e/8b が使うのは推定 `ẑ` を代入した **plug-in raw-eta score** であり、
モデルの予測分布に対する proper scoring rule ではない。その population target は特定されていない。

**本監査の確認:** 両方とも正しい。とくに「plug-in である」という指摘は決定的で、
初版はこの語を一度も使っていなかった。

**判定: REJECT（初版が誤り）→ `[UNRESOLVED]`（U10）に降格。**
「held-out は `K*` を推定している」とも「していない」とも書かない。
なお初版の従属節「『held-out で `K_TRUE` が選ばれた』は『`K_TRUE` が識別された』を意味しない」は
**独立に正しく、§17.3 の壊れた前提に依存しない**ので維持した（A も同じ判断）。

### R-09 — 漸近レジーム・有効標本数・incidental parameter の欠落（B: B-05）

**指摘:** §17 が model selection を論じているのに、**何が無限大に行くのか**が定義されていない。
ノード数 `n` / dyad 数 `n(n−1)/2` / X 要素数 `nd` で有効標本数が異なり、
`calc_bic_dual` の `log n` はノード数を使う。`Z ∈ R^{n×K}` は `n` とともに増える incidental parameter で、
`Q_strict` は `Z` を完全データとして扱う一方 penalty は `Z` を数えない。
さらに P1・P2 の有限標本版は **従属な** dyad の平均であり、一致性は自明でない。

**本監査の確認:** すべて正しく、初版の重大な欠落である。
`utils_expfam.py` を確認し、`num_params = kd − k(k−1)/2 + [d] + [1]`、`bic = −2 Q_strict + num_params·log n` を
一次コードで確認した。`w0`・`w` が数えられていないことも確認した（A: F-14）。

**判定: REJECT（欠落）。** **§16b「漸近レジームの未確定性」を新設。**
§9.5 に「P2 は population の主張であり、実際は network 1 個の従属 dyad である」を追記。
§17.1 に `calc_bic_dual` の実装事実と、「`K` の唯一の担い手である `w` が penalty から外れている」点を追記した。

### R-10 — M-closed 仮定が明示されていなかった（B: B-08 / A: F-13）

### R-12 — P2・P3 は Gaussian-Y 限定なのに §17.1 が family 限定を落としていた（B: B-11）

### R-13 — Phase 8b の「真値一致」は `K_TRUE` との一致であり `K*` との一致ではない（B: B-12）

**指摘:** §2.3 で正しく区別しているのに、実際に効く場所で適用していない。
`K* < K_TRUE` なら `K < K_TRUE` の選択が `K*` に対しては**正しい**のに miss と数えられる。
これは `K_TRUE=5` の under-selection（2/6）に対する未検討の候補説明である。

**判定: REJECT（欠落）。** §17.5 に明記し、
「Phase 8b の真値一致率は `K*` recovery である」を「書いてはいけない」に追加した。

### R-14 — identifiability の定義が自身の §4 に反していた（B: B-03）

**指摘:** 「異なる `θ` が異なる `P_θ` を与える」は §4 の `O(K)` 不変性により**決して成立しない**。
また parameter identifiability と order identifiability（`K` の識別）を「または」で 1 セルに束ねていた。
さらに脚注「復元できれば異なるパラメータは異なるモーメントを持つ」は誤りで、
モーメント復元が確立するのは**復元された関数 `g(θ)` の identifiability だけ**である。

**判定: REJECT。** §3 の表を parameter（`O(K)` を法として）/ order / functional /
local·global / generic·everywhere / estimability の 6 行に再構成し、脚注を正した。
`[NUMERIC_CHECK]` 等の凡例も併せて整備した。

### R-15 — P1 の証明に競合表現への量化がなかった（A: F-08）

**指摘:** identifiability は「すべての表現について」の主張である。
初版の証明は真値についてしか述べておらず、`(K+1, F'=[F,0])` が X 周辺を完全再現することを排除していない。

**判定: REJECT（証明が不完全）。** §7.4 に「任意の競合表現 `(K', F')` も (7.1)(7.2) を満たすので
`F'F'^T = G`、ゆえに `K' ≥ rank(G)`、逆に `K' = rank(G)` の表現が実在する」という最小性の一段を追加。
併せて **P1 が確立するのは `K*` ではなく `K^rank`** であることを §2.4 に明記した。
