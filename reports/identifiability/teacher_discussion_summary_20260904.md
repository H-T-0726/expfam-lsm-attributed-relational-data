## 1. 先生から何を指摘されたか

1. 指数型分布族へ拡張したモデルが、**生成モデルとして本当に成立しているか**確認する必要がある。
2. **「真の潜在次元 K」とは何なのか**を明確にする必要がある。
3. 人工データで `K_TRUE` を設定しただけでは、それが**観測分布から識別可能な「真の K」であるとは限らない**。
4. 複数の確率分布へ拡張した場合、**従来の BIC 等の理論的性質がそのまま成立するとは限らない**。
5. 有限データでたまたま K を選べることと、**`n → ∞` で真のモデルを選択できることは別**であり、理屈から考える必要がある。

**結論を先に言うと:** 1〜4 については具体的な答えが出ました。**5 は未解決のままです。**
ただし「なぜ難しいのか」の構造は特定できました。

## 2. 生成モデルとして成立しているか（指摘 1）

### 成立します。ただし条件付きです。

```
z_i     ~ N(0, I_K)                        （各ノードの潜在ベクトル）
x_il    ~ ExpFam_X( f_l^T z_i )            （属性）
y_ij    ~ ExpFam_Y( w0 + w z_i^T z_j )     （関係、i < j）
```

これは `n, d, K` が有限で、パラメータが有限で、Gaussian の分散が正なら、
**きちんとした確率モデル（proper probability model）として定義できます。**
Gaussian / Bernoulli / Poisson を X 側・Y 側に自由に組み合わせること自体に矛盾はありません。

### ただし「確率モデルである」ことと「モーメントが存在する」ことは別問題でした。

**Poisson-Y には落とし穴がありました。** `Y` の平均や分散が有限であるためには

| 必要なもの | 条件 |
|---|---|
| 平均 `E[Y]` が有限 | `\|w\| < 1` |
| **分散 `Var(Y)` が有限** | **`\|w\| < 1/2`** |
| `r` 次モーメントが有限 | `\|w\| < 1/r` |

**そして現在のコードの Poisson-Y の既定値は `w = 0.5` で、これは分散が発散する境界ちょうどです。**

分布自体は正しく定義されていて、データも生成できます。しかし理論上は分散が無限大なので、
**標本分散は `n` を増やしても収束しません。** 二乗誤差や相関を使った議論がそのまま使えない領域です。

新しく作った generator では、Poisson-Y を使うときは `|w| < 1/2` を**強制**するようにしました。

## 3. これまでの人工データ生成の何が問題だったか（指摘 3 の前提）

コードを直接読んで確認したところ、**現在の人工データ生成は、上のモデルからそのまま
データを作っているわけではありませんでした。** 具体的には次の 5 点です。

| # | 実装 | モデルとの差 |
|---|---|---|
| G1 | `Z` を生成した後に**列ごとに標準化**している | `z_i` が iid `N(0, I_K)` ではなくなる。列の平均が厳密に 0、SD が厳密に 1 になるため、行の間に依存が入る |
| G2 | `F` の各行を**一定のノルムに正規化**している | `F` が自由パラメータでなくなる。全列の `‖f_l‖²` が同じ値に固定される |
| G3 | Gaussian-X を生成した後に**列ごとに標準化**している | `x \| z ~ N(Fz, Σ)` ではなくなる。返ってくる `F`・`Σ` と実際の `X` が対応しない |
| G4 | Poisson の `η` を **`[−20, 10]` で切っている** | 上限を超えると黙って値が変わる |
| G5 | `sigma_x_true` という引数が**宣言されているが一度も使われていない** | この引数を変えても生成データは変わらない |

**大事な点:** これは「過去の実験結果が間違っている」という話では**ありません**。
過去の結果は「その生成器が作ったデータの上での観測」として有効です。

言えなくなるのは、**「モデルどおりに正しく生成したデータで検証した（well-specified）」という強い読み方**だけです。
今回はその読み方ができるように、**別の生成器を新しく作りました**（既存の生成器は 1 文字も変えていません）。

## 4. 今回 clean generator で何を直したか

新モジュール `expfam/src/experimental/data_generator_canonical.py`。

| 直した点 | 内容 |
|---|---|
| `Z` | iid `N(0, I_K)` のまま。**標準化しない** |
| `F` | 自由パラメータ。**行を正規化しない。** `rank(F) = K` は QR 分解による**構成で保証**（乱数を引き直して当たるまで待つ、いわゆる seed rescue は禁止し、失敗したら止まる） |
| Gaussian-X | `N(Fz, Σ_X)` のまま。**標準化しない**。`Σ_X` を実際に使う |
| Poisson | `exp(η)` をそのまま使う。**切らない。** 危険な値なら**その場で停止**する |
| 分散の意味 | 引数名に意味を埋め込んだ（`sigma_x_var` は**分散**、`sigma_y_sd` は**標準偏差**）。これで G5 のような取り違えが起きない |
| Poisson-Y | `\|w\| < 1/2` を既定で強制。境界の `w = 0.5` を知らずに使えないようにした |

**さらに、`K_TRUE` を変えたときに信号の強さが変わってしまう交絡を潰しました。**
何もしないと `K` が大きいほど X 側も Y 側も信号が強くなり、
「K を当てられた」のか「信号が大きかっただけ」なのか区別できなくなります。
そこで平均 `‖f_l‖²` と `w²K` が `K_TRUE` によらず一定になるようにしています。

生成器には 46 件のテストを付けました（標準化が入っていないこと、`rank(F) = K` であること、
Poisson が黙って切られていないこと、分散の意味が実際に効いていること、など）。

## 5. 「真の K」をどう定義したか（指摘 2）

### 定義

観測できるのは `(X, Y)` の分布です。潜在次元 `K` のモデルが表現できる分布の集合を `M_K` と書くと、

> **`K*` ＝ 真の観測分布 `P0` を表現できる最小の潜在次元**

と定義できます。

### ここが重要です: `K*` と `K_TRUE` は別物です

| 記号 | 意味 |
|---|---|
| `K_TRUE` | 人工データを作るとき `Z` を**何列作ったか**という手続き上の数 |
| `K*` | そうしてできた**観測分布**の最小潜在次元 |

一般に `K* ≤ K_TRUE` で、**等号は自明ではありません。**
「人工データで `K_TRUE = 5` と設定したから真の K は 5 だ」とは言えない、というのが指摘 3 の内容です。

### さらに一つ、実データでは注意が要ります

この定義は「`P0` が候補モデル族のどれかで**厳密に**表現できる」ことを前提にしています。
実データではふつう成立しません（本研究の Cora・MovieLens でも誤指定が記録されています）。
**成立しない場合、`K*` はそもそも存在しません。**

## 6. どの条件では K の識別可能性を示せたか（指摘 3）

### 示せたもの

**(a) Poisson-X なら、条件付きで K が決まります。**

`X_l | z ~ Poisson(exp(f_l^T z))` のとき、population の平均と共分散から

```
‖f_l‖²   = 2 log E[X_l]
f_l · f_m = log( E[X_l X_m] / (E[X_l] E[X_m]) )
```

が成り立ち、これで行列 `FF^T` が完全に復元できます。その階数が K です。

**条件:** `exp` を切らないこと、`rank(F) = K`、population のモーメント。
**注意:** これは **X から見える最小次元**であって、`Y` にしか現れない潜在次元は数えません。

**(b) Gaussian-Y なら、たった 1 本のリンクの分布から K が決まります。**

`S = z_i^T z_j` のモーメント母関数が `(1 − t²)^{−K/2}` になることから、
`Y` の 4 次・6 次キュムラントが `6Kw⁴`・`120Kw⁶` になります。したがって

```
w² = κ₆ / (20 κ₄)      K = κ₄ / (6 w⁴)      σ_y² = κ₂ − K w²
```

で `(w0, w², K, σ_y²)` が全部決まります（`w ≠ 0` のとき）。

**(c) `w` の符号は、三角形（3 ノード）を見れば決まります。**

1 本のリンクだけでは `w` の符号は決まりません（`+w` と `−w` が同じ分布になるため）。
しかし 3 ノードの積の期待値が `w³K` になるので、**3 ノード見れば符号も決まります。**

### 示せなかったもの、および反例

**(d) Bernoulli-X で `d = 1` のときは、X からは K が全く分かりません（反例）。**

`E[X_l] = 1/2` が `K` にも `f_1` にも依らず成り立つので、
どんな `K` でも観測は「表裏 1/2 のコイン」に見えます。
**ただしこれは X だけを見た場合の話で、Y 側が情報を持てば joint では識別されえます。**

**(e) Bernoulli-Y は未解決です。**

これが一番痛いところで、**実際に実験で使っているのは Bernoulli-Y です。**
1 本のリンクの分布からは K の情報が取れないことは分かりましたが
（`w0 = 0` ならリンク密度は K によらず 1/2）、
ノードを共有する複数リンク（2-star、三角形）には K の情報が入ります。
ただし**一般的な識別可能性の定理は作れていません。**

**(f) Gaussian-X で `Σ` が未知の場合も未解決です。** 因子分析の古典的な識別問題そのもので、
次元の数え上げ条件 `(d−K)² ≥ d+K` を満たさないと識別できません（例: `d=2, K=1` は不可）。

## 9. 元論文の BIC との違い（指摘 4）

### 3 つの量を区別する必要があります

| 記号 | 内容 |
|---|---|
| Q1 | `ln p(X, Y | Z, θ)` — 潜在変数を代入しただけの条件付き尤度 |
| Q2 | `ln p(Z, X, Y | θ)` — 完全データの同時密度 |
| **Q3** | **`ln p(X, Y | θ)` — 観測データの周辺尤度（`Z` を積分したもの）** |

**Schwarz の BIC が近似しているのは Q3 です。**

一方、現在のコードの `calc_bic_dual` が使っているのは `Q_strict`、すなわち **Q2 の MC 平均**です。
`Z` を積分していないので、**これは Schwarz BIC ではありません。**
だから本研究では「Schwarz BIC」と呼ばないことにしています。

### さらに、BIC が使えない理由は「モデルが入れ子でないから」ではありません

今回 Gaussian-Y については **`M_K` が入れ子でない**ことを証明しました。
ただし調べ直したところ、**非入れ子で壊れるのは尤度比検定（χ² 近似・Wilks の定理）であって、
BIC の導出そのものは非入れ子でも壊れません。**

BIC がこのモデルで正当化されない本当の理由は別にあり、次の 3 つです。

1. **モデルが特異である。** 潜在ベクトルを回転しても観測分布が変わらないため、
   Fisher 情報が退化します。`rank(F) < K` や `w = 0` の近くでも退化します。
   特異モデルでは BIC の `(p/2) log n` という罰則の形自体が正しくなくなります。
2. **境界パラメータ。** 分散は 0 以上という制約があり、K の比較はしばしば境界の上で起きます。
3. **「標本数」が何なのかが決まっていない。** ノード数 `n` なのか、リンク数 `n(n−1)/2` なのか、
   属性の要素数 `nd` なのか。現在のコードは罰則に **ノード数の `log n`** を使っています。
   さらに潜在ベクトル `Z` は `n` と一緒に増える（`nK` 個）ので、
   古典的な iid の設定ではありません。

なお実装を読むと、**`w0` と `w` はパラメータ数に数えられていません**（元論文の慣行を踏襲）。
Gaussian-Y では `K` の情報をもっぱら `w` が運んでいることが分かったので、
この扱いは K 選択の文脈では検討の余地があります（`K` に依存しない定数なので順位には影響しませんが）。

## 10. held-out スコアは何を選んでいるのか

Phase 7e / 8b、そして今回の実験で主基準にしているのは
**held-out（取り置いた）リンクに対する予測スコア**です。

```
η_ij = ŵ0 + ŵ ẑ_i·ẑ_j          （推定した潜在座標を代入）
score = y η − log(1 + e^η)      を取り置いたリンク上で平均
```

**これが `K*` を推定しているのかどうかは、今回**未解決**という結論になりました。**

- 理論的には、厳密な proper scoring rule を population で評価すれば `K*` に一致しうる。
- しかし実際に使っているのは**推定した `ẑ` を代入した plug-in スコア**であり、
  モデルの予測分布に対する proper scoring rule ではありません。何を選んでいるかが特定できていません。
- 有限標本では bias–variance のトレードオフもあります。

**ただし、これとは独立に確実に言えることが一つあります:**

> **「held-out で `K_TRUE` が選ばれた」ことは「`K_TRUE` が識別された」ことを意味しません。**
> 選ぶこと（selection）と、観測分布から決まること（identification）は別の概念です。

たとえば、データに K を区別する情報が全く無い場合でも、
「同点なら小さい K を選ぶ」という規則があれば手続きは `K = 1` を出力します。
それが偶然 `K_TRUE = 1` と一致しても、それはデータから識別した結果ではありません。

## 11. 修論で安全に主張できること

**（実験結果を踏まえた最終版は `clean_true_k_results_20260904.md` の claim ledger を参照。）**

現時点で理論として書けること:

- 提案モデルは、明示した条件下で proper probability model として定義できる。
  ただし Poisson-Y ではモーメントの有限性が別条件になる。
- 「真の K」は `K* =`「観測分布を表現できる最小の潜在次元」と定義でき、
  これは人工データの `K_TRUE` とは**別概念**である。
- **Poisson-X** では、明示した条件下で（切らない `exp` リンク、`rank(F)=K`）
  X から見える最小次元が `FF^T` の階数として決まる。
- **Gaussian-Y** では、`w ≠ 0` なら 1 本のリンクの分布から `(w0, w², K, σ_y²)` が決まり、
  `w` の符号も 3 ノード見れば決まる。
- Bernoulli-X で `d = 1` のときは、**X からは** K が識別できない（反例あり）。
- 現行の `calc_bic_dual` は観測データの周辺尤度を使っていないので **Schwarz BIC ではない**。

**書いてはいけないこと:**

- 「BIC は理論的に正しい」「held-out なら真の K を必ず選べる」
- 「Poisson-X なら常に K が識別可能」（条件が要る）
- 「Bernoulli では K は識別できない」（反例は `d=1` かつ X 側のみ）
- 「K 選択の一致性を証明した」「n を増やせば必ず `K_TRUE` に収束する」
- 「clean generator で全部解決した」「過去の結果は無効」
- 実験の「真値一致率」を `K*` の回復率と呼ぶこと

## 12. 先生に相談したいこと

1. **Bernoulli-Y の識別可能性（U2）をどう攻めるか。**
   実験で実際に使っているのがこの設定なので、ここが空いているのが一番痛いところです。
   ノードを共有する motif（2-star・三角形）に K の情報が入ることまでは分かりましたが、
   一般定理が作れていません。Gaussian-Y のようなキュムラント論法が使えないためです。

2. **`n → ∞` の一致性（U6）に、どの枠組みで取り組むか。**
   モデルが特異なので通常の BIC 漸近論は使えません。特異学習理論（RLCT）で扱うのか、
   別の基準（交差検証の漸近論など）を採るのか、方針をご相談したいです。
   その前提として、**「標本数」を何と定義するか**（ノード数 / リンク数）を決める必要があります。

3. **有限データでの階数判定（U7）。**
   `FF^T` の推定値は正定値ですらなく、負の固有値が出ます。
   「固有値がどれくらい離れていれば K とみなすか」の閾値を、
   結果を見てから決めるわけにはいきません。事前に決める根拠をどう作るか。

4. **`K* = K_TRUE` の確認（U9）。**
   新しい generator は識別可能性の前提（`rank(F)=K`、`w≠0`、`d≥K`）を強制していますが、
   これが `K* = K_TRUE` の**十分条件**であることは family ごとに確認できていません。

5. **held-out スコアの位置づけ（U10）。**
   plug-in スコアである以上、population で何を選んでいるかが特定できません。
   修論では「予測に最適な K を選んでいる」と書くにとどめるべきか、
   それとももう少し踏み込めるか。

6. **実データでは `K*` が存在しない可能性。**
   誤指定下では最小次元という概念自体が定義できません。
   実データの章では何を目標量として書くべきか。
