# 修士研究の方向性：3 案の比較

- **位置づけ**：方向性を相談するための比較である。**どの案を採るか、論文の結論をどうするかは、研究者と指導教員が決める。**
- **ラベル**：FACT（一次資料）と JUDGMENT（研究上の判断。提案）を分けて書く。
- **前提**：どの案も、現状の証拠以上に成功しているように見せない。本文に採用するかどうか（prototype の昇格）は Human Gate である。

---

## 0. 前提となる事実（FACT）

1. **研究目的**：属性付き関係データの潜在構造モデルを指数型分布族へ一般化し、その挙動・有効な条件・限界を評価する（[`RESEARCH_MASTER.md` §1](https://github.com/H-T-0726/expfam-lsm-attributed-relational-data/blob/f71c04d/RESEARCH_MASTER.md)）。
2. **標準モデル**では `family_x` は全列で共通。**列ごとの family と自動選択は、すべて prototype**（lineage E・F、PR #129）である。
3. **本文に採用できる結果（ALLOWED）**は、実装レベルの一般化、先行研究の再現、n 依存性、誤指定による悪化（fixed 系列）、識別可能性の命題（条件つき）。
4. **誤指定と Y の情報量**（M1、E1、#168）は lineage E の結果で、本文に採用するかは未決定。
   - sparse の悪化は、別の seed 系列でも再現した。
   - 誤指定の種類によって、交互作用の向きが変わる。
5. **AF1〜AF8-v3 で分かったこと**：
   - 自明なケース（{0,1}、Bernoulli と Poisson）では、自動選択は機能する。
   - 自明でないケース（Poisson と CMP2）では、Q も Laplace も積分型の基準も、誤りの向きを入れ替えるか、判定境界を動かすだけだった。
   - 事前登録の確認（AF6）は未達成。AF8-v3 は NO-GO。
6. **先生の質問（2026-10-13）**：「正しい分布で生成して正しい分布を仮定するだけでは、拡張の意味の説明として弱い。間違った分布を仮定すると何が起きるか」（[`distribution_misspecification_synthesis_20261013.md` §1](https://github.com/H-T-0726/expfam-lsm-attributed-relational-data/blob/f71c04d/reports/advisor_feedback/distribution_misspecification_synthesis_20261013.md)）。
7. **2026-09-05 のストーリーライン監査の結論**：物語の型は「性能向上」ではなく「主張境界の確定」である（[`thesis_storyline_20260905.md` §0、§6](https://github.com/H-T-0726/expfam-lsm-attributed-relational-data/blob/f71c04d/reports/thesis/thesis_storyline_20260905.md)）。

## 案 A：指数型分布族への拡張を中心に据え、分布は既知として扱う

**内容**：分布は研究者が指定する（既知とする）。拡張モデルの定式化、推定、誤指定の影響、属性と関係の補完、K の選択の性質を本論にする。AF は扱わないか、今後の課題で一言触れる。

| 観点 | 評価 |
|---|---|
| 研究目的との整合性 | **高い**。目的文そのもの |
| 先行研究との差 | X と Y の分布の一般化、精度行列の V(η) = A''(η)/φ の導出、1/2 係数の扱い、識別可能性の命題（P1〜P8） |
| 数理的な主張 | 定式化と E-step の式（DERIVED）、識別可能性（population、条件つき）、C_Q が BIC ではない理由 |
| 実験的な根拠 | ALLOWED：再現、n 依存性、誤指定による悪化（fixed）。<br>QUALIFIED：補完効果、M1・E1（prototype）、MovieLens |
| 不足している検証 | 誤指定の結果の多くは lineage E で、本文に採用するかは未決定。<br>Bernoulli-Y の K の識別は未解決。実データでの有効性は弱い |
| 実現可能性 | **高い**。新しい実験はほぼ不要。<br>本文を固定した lineage の結果で書き直す作業と、prototype の結果を採用するかの判断が中心 |
| 弱点 | 先生の質問（なぜ分布を選ぶ意味があるのか）に対して、「分布が既知なら」という前提を置くことになる。実務では分布は未知である。この点の扱いが弱く見えるおそれがある |
| 先生に確認すること | 分布を既知とする前提でよいか。lineage E（M1・E1・#168）の結果を本文に使ってよいか |

## 案 B：拡張を中心とし、分布自動選択の難しさと限界を追加分析として扱う

**内容**：案 A を本論とし、「分布が未知のときに、データから選べるか」を 1 章（または付録）の追加分析として扱う。成功例ではなく、何が分かって何が難しいかを書く。

| 観点 | 評価 |
|---|---|
| 研究目的との整合性 | **高い**。「挙動・条件・限界の評価」という目的文に沿い、限界の一部として位置づけられる |
| 先行研究との差 | 案 A に加えて、潜在変数がある場合の分布選択の難しさを具体的に示せる |
| 数理的な主張 | {0,1} 列での優越（DERIVED、AF1・AF2）。<br>KL ≥ 0 は母集団の性質で、潜在の Z では有限標本の保証にならない（DERIVED）。<br>積分した基準は prior（測度）に依存する（DERIVED、AF8） |
| 実験的な根拠 | 自明なケースでは成功し、誤指定の損失を回避した（AF1）。<br>Poisson と CMP2 では、Q が CMP2→Poisson に偏る（AF2、AF3）。<br>Laplace 型の基準は向きを入れ替える（AF5・AF6、confirmatory で未達成）。<br>積分は境界を移動させ、prior に依存する（AF8-v3）。<br>いずれも prototype・1 条件 |
| 不足している検証 | AF2 以降は 1 つの生成条件（n=75、K=3、G3/P3/CMP2×3）だけ。<br>Z の推定への影響は AF1・AF2 でしか評価していない。<br>AF3 の機構は仮説 |
| 実現可能性 | **高い**。結果はそろっており、新しい実験は不要。<br>否定的な結果を正確に書く作業が中心。AF6 の事前登録と未達成の記録が、手続きの信頼性を示す材料になる |
| 弱点 | 否定的な結果が中心なので、書き方を誤ると「失敗の羅列」に見える。<br>prototype で、本文に採用するかは未決定 |
| 先生に確認すること | 否定的な結果・限界を 1 章として書く価値があるか。付録で十分か。PR #129 の CMP generic model を論文で扱ってよいか |

## 案 C：潜在構造の推定と分布選択の相互依存を、研究の中心課題として再構成する

**内容**：「Z が潜在であるため、分布の選択と Z の推定が互いに依存する」ことを主題にし、理論と方法を新しく作る。

| 観点 | 評価 |
|---|---|
| 研究目的との整合性 | **中〜低**。目的文（指数型分布族への一般化と評価）から主題が移る |
| 先行研究との差 | 潜在変数モデルの分布選択の問題として新しさはありうる。ただし、関連する先行研究（混合モデル・潜在変数モデルのモデル選択）の調査はまだしていない |
| 数理的な主張 | 現時点で使えるのは、AF3 の機構の仮説、AF8 の測度依存の導出、KL の母集団性だけ。<br>**有限標本の識別や一致性の結果はない**（S-1、S-8） |
| 実験的な根拠 | 自明でないケースで提案法が機能した証拠は**ない**（AF6 は未達成、AF8-v3 は NO-GO）。<br>使えるのは、問題が存在することを示す観察（AF2、AF3、AF7）だけ |
| 不足している検証 | 新しい理論、新しい方法、新しい独立データでの確認、複数の生成条件、実データ。すべて未着手 |
| 実現可能性 | **低い**。修士研究の残り期間で、理論と確認実験の両方を仕上げる見込みを示す証拠がない |
| 弱点 | 本来の研究の成果（拡張モデル）が脇役になる。否定的な結果だけで主題を立てることになる |
| 先生に確認すること | 主題の変更を許容するか。博士課程や後続の研究のテーマとして切り出すほうが適切か |

## 提案（JUDGMENT。決定ではない）

**確定した事実**：
- 本来の研究の結果は、ALLOWED と QUALIFIED の範囲でそろっている。
- AF の結果は、自明でないケースで手法として成功していない。ただし、事前登録と独立監査をつけた記録として残っている。

**研究上の判断**：最も妥当なのは**案 B**だと考える。理由は次のとおり。

1. 目的文（挙動・条件・限界の評価）と一致し、AF の否定的な結果を「限界」として正しい位置に置ける。
2. 先生の質問（なぜ分布を選ぶ意味があるのか）に、2 段階で答えられる。
   - 「誤指定すると Z が悪化し、その程度は Y の情報量と誤指定の種類で変わる」（M1、E1、#168）。
   - 「では分布をデータから選べるか。自明なケースでは選べるが、近い分布どうしでは Z が潜在であることが選択を難しくする」（AF）。
3. 新しい実験なしで書ける。AF8-v3 の NO-GO をもって、AF の開発は終えられる。

**ただし、次は人間の判断が必要である。**
- lineage E の結果（M1、E1、#168、AF）を本文に使うか、付録・予備的検討にとどめるか。
- AF の章を独立した章にするか、限界の節に圧縮するか。
- 案 A を選ぶ場合でも、AF の記録は削除せずに残す（PR #166〜#173 は open または close のまま、branch は保存）。
