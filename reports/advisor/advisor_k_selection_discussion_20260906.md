## 3. 真の潜在次元 K の整理

**ここが今回いちばん大きな整理です。** 「真の K」には少なくとも 4 つの意味があります。

| 記号 | 意味 |
|---|---|
| `K_GEN` | 人工データを作るときに私が指定した次元。**手続き上の数** |
| `K*` | その観測分布を表現できる**最小の**潜在次元 |
| `K^rank` | 属性 X 側の情報だけから決まる次元（因子行列 `F` の Gram 行列 `FF^T` の階数） |
| `K_PRED` | 有限のデータで**予測性能が最良**になる次元 |

**これらは一般には一致しません。** 関係は `K^rank ≤ K* ≤ K_GEN` で、等号は自明ではありません。

**ただし Poisson-X では、条件付きで `K* = K_GEN` を導けます。**
`x_l ~ Poisson(exp(f_l^T z))` の場合、母集団のモーメントから

```
‖f_l‖² = 2 log E[X_l]        f_l^T f_m = log{ E[X_l X_m] / (E[X_l] E[X_m]) }
```

により `FF^T` が復元でき、`rank(F) = K_GEN` なら `K^rank = K_GEN` となります。
さらに `K^rank ≤ K* ≤ K_GEN` の挟み込みから `K* = K_GEN` が従います。

**この結論に必要な条件（省略できません）:** 候補モデルがどの `K` でも同じ canonical Poisson-X であること、
リンク関数を打ち切らないこと、`rank(F) = K_GEN` かつ `d ≥ K_GEN`、母集団のモーメントであること
（有限標本ではない）、真の分布が候補族に含まれること。
**現在の人工データ実験はこれらを満たすよう作ってあります。**

**一方、Bernoulli-Y の一般的な K の識別可能性は未解決です。**
辺 1 本の周辺分布はスカラー 1 個の情報しかなく、K の情報は共有ノードを持つ部分構造（三角形など）に入りますが、
それが K を決めるかは証明できていません。**実験で実際に使っているのがこの分布です。**

## 4. 理論面で分かったこと

### 4.1 生成モデルは成立している

`z_i ~ N(0, I_K)`、X と Y の条件付き分布に Gaussian / Bernoulli / Poisson を使う場合、
**X 側 3 × Y 側 3 = 9 通りすべてで、有限パラメータ・Gaussian 分散 > 0 の下で同時分布は proper です。**
各条件付き分布が確率分布として定義でき、`Z` について積分しても全体の確率が 1 になることを確認しました。

**したがって「指数型分布族へ拡張したことで生成モデルそのものが矛盾した」という問題は、現時点では確認されていません。**

**ただし分布が定義できることと、モーメントが有限であることは別問題です。**
Poisson-Y では `E[Y^r] < ∞` に `|w| < 1/r` が必要で、**分散が有限なのは `|w| < 1/2` のときだけ**です。
古い生成器の既定値 `w = 0.5` はちょうどその境界でした。

### 4.2 「BIC」と呼んでいたものの実体

`Z` の扱いで 3 つの量を区別する必要がありました（`Z` は観測されない潜在変数）。

| | 式 | `Z` の扱い |
|---|---|---|
| **Q1** | `log p(X, Y \| Z, θ)` | 推定値を代入するだけ |
| **Q2** | `log p(Z, X, Y \| θ)` | `p(Z)` を掛けるが積分しない |
| **Q3** | `log p(X, Y \| θ) = log ∫ p(Z,X,Y\|θ) dZ` | **積分する** |

**標準的な Schwarz BIC が対象とするのは Q3 だけです。**

- **原論文 Eq.(26)** の当てはまり項（Eq.(16)）は **Q1 系**
- **これまでの実装で「BIC」と呼んでいたもの**は **Q2** を使う Q ベースの基準

**したがって、過去の人工データ実験で「BIC が真の K を選んだ」という結果は事実ですが、
「標準的な Schwarz BIC の一致性が確認された」とは言えません。**

**現行モデルで標準的な BIC の一致性は NOT PROVED です。** よくある説明として
「モデル族が入れ子でないから BIC が使えない」がありますが、**これは理由として誤りです**
（入れ子でないモデルの比較に BIC を使うこと自体は標準的です）。
実際に未整理なのは、回転不変性による**特異性**、境界・冗長な次元、
`Y_ij` と `Y_ik` が `z_i` を共有する**依存構造**、**有効標本数の定義**（ノード数 `n` か辺の数 `n(n−1)/2` か）、
漸近レジーム、`K` をまたぐモデル間の関係、分布族ごとの正則性の 7 点です。

## 5. 人工データ実験で確認したこと

**以下は有限標本での観察であり、理論の証明ではありません。**

### 5.1 過去の実験（historical 系列）

- Poisson-X / Bernoulli-Y、`K_TRUE=5`、`n=150`、候補 K = 1..10 → **5/5** で K=5 を選択
- fixed 系列（P/B・G/P・B/G の 3 条件）、`K_TRUE=3`、`n=150`、候補 K = 1..9 → **合計 30/30**

### 5.2 今回の追試 — 過去の条件のまま `n` だけ変えた

| n | 50 | 75 | 100 | 150 |
|---|---|---|---|---|
| K=5 を選んだ回数（5 回中） | **1/5** | 4/5 | 5/5 | 5/5 |

`n=150` の 50 セルは過去の記録と数値が完全に一致することを確認したうえで実施しました。
**過去の条件のままでも、`n` を小さくすると K 選択は悪化します。**

### 5.3 現在の clean 条件（Poisson-X / Bernoulli-Y、`K_TRUE=5`、held-out 評価）

| n | 50 | 75 | 100 | 150 |
|---|---|---|---|---|
| 8 反復（8 回中） | 2/8 | 0/8 | 4/8 | **8/8** |
| 40 反復（8 回中） | 2/8 | 1/8 | 6/8 | 7/8 |

### 5.4 ここから言えること

1. **反復回数を 8 から 40 に増やしても、K 選択は一貫して改善しませんでした。**
   「8 反復固定だったから当たらなかった」という説明だけでは足りません。
2. **「Poisson だから K 選択ができない」という説明も否定されます。**
   `n` が十分なら過去・現在とも高い割合で当たっています。
3. **標本サイズは有力な要因候補です。** ただしそれだけでは説明できません。
   特に `n=75` で過去 4/5 に対し現在 0/8 と大きく食い違っており、
   ここに標本サイズ以外の差が効いています。

## 6. 現在残っている課題

### 整理できたこと

- canonical 生成モデルの properness（9 通りすべて）
- 「真の K」の 4 つの意味の区別
- Poisson-X での条件付き K 識別可能性
- これまで「BIC」と呼んでいたものの実体
- 有限標本で標本サイズが K 選択に影響する例
- 8 → 40 反復だけでは解決しないこと

### 未解決のこと

- **Bernoulli-Y を含む同時モデルの一般的な K 識別可能性**（実験で使っている分布）
- 標準的な BIC やその他の基準の一致性
- `K*` と `K_PRED` の関係
- `n → ∞` の漸近レジーム
- 過去と現在の差のうち、signal / generator / criterion / Y の hold-out のどれが主要因か

### 補足 1 — `n → ∞` について

`P(K̂ = K*) → 1` のような一致性を議論するには、**何を無限大にするのかを先に決める必要があります。**
`n → ∞`（`d, K` は固定）、Y が密な場合、Y が疎な場合、`d` も増える場合で結論が変わりえます。

また **Y は `O(n²)` 本の辺がありますが、`z_i` を共有するため `n²` 個の独立標本としては扱えません。**
`Y_ij` と `Y_ik` は独立ではないので、標準的な漸近論をそのまま当てはめられません。
**この点は未解決として明記しています。**

### 補足 2 — sparse / missing Y について

- **sparse:** 辺は観測されているが値の多くが 0（疎なネットワーク）
- **missing:** 辺そのものが未観測

**欠測の場合、観測された X と Y から `Z` を推定し、未観測の `Y_ij` を予測する使い方が構造的に可能です。**
現在の held-out 評価はこの設定に近い形になっています。

**ただし、予測に最良の `K_PRED` が最小表現次元 `K*` と一致する保証はありません。**
現在の評価指標は、それ自体は適切なスコア（proper scoring rule）ですが、
予測分布を積分したものではなく**推定値を代入した予測器**に適用しているため、
それが母集団で何を選ぶのかが未解決です。

## 7. 相談したいこと

**Q1. 修論ではどの K を研究対象とするべきでしょうか。**
`K_GEN`（生成次元）／`K*`（最小表現次元）／`K_PRED`（予測最適次元）の 3 つが候補です。
理論上は `K*` を中心にするのが自然だと考えていますが、`K*` は真の分布が候補族に含まれることを前提とし、
実データでは存在しないこともあります。実応用を重視するなら `K_PRED` も考える必要があります。

**Q2. Bernoulli-Y の K 識別可能性を、証明するところまで進めるべきでしょうか。**
それとも、Poisson-X や Gaussian-Y など**条件付きで理論が成立する範囲を明示**し、
Bernoulli-Y は未解決として有限標本実験で扱う形で、修論として十分でしょうか。

**Q3. K 選択基準は今後どこまで扱うべきでしょうか。**
(a) 標準的な周辺尤度 BIC の理論を追う／(b) 予測基準を中心にする／
(c) 複数基準の有限標本比較として整理する、のどれを中心に置くべきでしょうか。

**Q4. 実験面では、過去と現在に残る差のうちどれを次に切り分けるべきでしょうか。**
候補は signal 強度・generator・criterion・Y の hold-out の 4 つです。
`n=75` での食い違い（4/5 対 0/8）が最も大きな手掛かりだと考えており、
私としては signal と hold-out が直接効いていると見ていますが、これは推測です。
