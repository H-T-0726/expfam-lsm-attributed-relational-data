## 1. 研究背景と目的

- 元論文（Mikawa et al. 2024）は、属性付き関係データの潜在構造モデルを提案した。属性 X は Gaussian、関係 Y は Bernoulli である。
- 本研究は X 側・Y 側を、それぞれ独立に指数型分布族（Gaussian / Bernoulli / Poisson）へ一般化する。そのうえで、一般化モデルの挙動・有効条件・限界を調べる。一般化が有効であることは前提にしない。
- この実験の問い：一般化モデルで、**潜在次元 K を情報量基準でどこまで選べるか。また、失敗するならどの条件で、どの向きに失敗するか。**

## 2. 元論文との違い

### 2.1 元論文が K 選択について示したこと（FACT。`original_paper_audit.md`）

- 実験 2 の条件：真の次元 k* = 1, 3, 5, 7, 9、候補 k = 1〜10、n = 150、d = 15、MC サンプル L = 10、10 反復、10 試行。
- 示したこと：Fig.3 で、k* ごとの BIC の曲線が k = k* で最小になる。
- **書いていないこと**：
  - 「各 k* で 10 試行すべてが正解した」とは書いていない。
  - 曲線が 1 試行か、平均か、最良の試行かも書いていない。
  - Z をどこで評価したかも書いていない。
- 論文は「BIC は一致性を持つ」と述べている。ただし、このモデルについての根拠は示していない。
- 元論文の BIC（Eq.(26)）は次の式である。

  BIC = −2 ln L + ((k+1)d − k(k−1)/2) ln n

  L は Z を与えたときの尤度（Eq.(16)）で、ln p(Z) を含まない。

### 2.2 本研究の違い

| 項目 | 元論文 | 本研究 |
|---|---|---|
| family | X = Gaussian、Y = Bernoulli のみ | X・Y を G/B/P に一般化（全 X 列で同じ family）。今回は 4 組 |
| 生成器 | 一部不明（w0・w の分布、F の分散の意味） | canonical-clean-v1（正規化なし、clip なし、F は等特異値の直交型） |
| 推定式 | 印刷式（Y 側に 1/2 あり） | 採用式（extra 1/2 なし）。lineage E、consistent numerics |
| μ_x・σ_z² | 推定する | μ_x なし。σ_z² = 1 に固定し、各 E-step の後に scale_Z |
| 基準 | Eq.(26)（Z を条件とした尤度。ln p(Z) なし） | C_Q（Z を MC で平均。ln p(Z) を含む） |
| 試行 | 「異なる初期値で 10 試行」。集計方法は不明 | 10 データ × 2 初期値。2 初期値の C_Q を平均して選ぶ |

- **したがって「元論文 Exp.2 の再現」とは言えない。** 言えるのは、「分布の組合せ（G/B）と n・d・k*・候補 K・L・反復数を対応させた比較」までである。

## 3. 生成モデルと K 選択基準

### 3.1 生成モデル

```
z_i  ~ N(0, I_K)                                   i = 1..n
x_il ~ ExpFam_X( η = f_lᵀ z_i )                     l = 1..d（バイアスなし）
y_ij ~ ExpFam_Y( η = w0 + w z_iᵀ z_j )              i < j
```

- F = s·Q とする。Q は d×K の列直交行列なので、F の K 個の特異値はすべて s で、rank F = K である。
- 2 つの信号の設計（regime）：

| | regime a（PRIMARY） | regime b（事前登録した感度分析） |
|---|---|---|
| 考え方 | 1 方向あたりの信号を固定 | 全体の信号を固定 |
| F の特異値² s² | d/6 = 2.5（K によらない） | 0.5d/K（K = 9 で 0.83） |
| F の平均行ノルム² | 0.5K/3（K とともに増える） | 0.5（一定） |
| Y の w（O・A・C） | 1 | √(3/K) |
| Y の w（B） | 0.12 | 0.12√(3/K) |

- w0 の決め方：
  - Bernoulli-Y：母集団の平均辺確率が 0.20 になるように較正した。
  - Poisson-Y：w0 = (K/2) ln(1−w²) とし、E[λ] = 1 にした。
  - Gaussian-Y：0。
- ノイズ：Gaussian-X の条件付き分散は 0.1、Gaussian-Y は 1.0。
- **K_TRUE = 3 では、regime a と b がまったく同じ条件になる**（w = 1、s² = 2.5）。そのため、独立な条件は 400 − 40 = 360 である。

### 3.2 基準 C_Q の定義（DERIVED。コードと照合済み）

MCEM の最後の E-step の L 個のサンプルを Z⁽¹⁾…Z⁽ᴸ⁾ とし、θ̂ を最後の M-step 後のパラメータとする。

```
Q_strict(θ̂) = (1/L) Σ_l [ ln p(Z⁽ˡ⁾) + ln p(X | Z⁽ˡ⁾, θ̂) + ln p(Y | Z⁽ˡ⁾, θ̂) ]   （正規化定数・階乗項を含む）
C_Q(K)      = −2 Q_strict(θ̂) + p_K ln n
p_K         = K d − K(K−1)/2  +  d·[Gaussian-X]  +  1·[Gaussian-Y]
```

コードとの対応：
- Q_strict は `calc_Q_dual_strict_exp`（`expfam/src/experimental/eval_utils.py` L.186–229）で計算する。
- C_Q は `calc_bic_exp`（同 L.232–259）で計算する。
- Q_strict に渡す Z_samples は、`em_runner.py` L.272 で `scale_Z` した後のものである。
- `scale_Z`（`reproduction/src/model.py` L.468–505）は、全 L サンプルの全要素について、Z² の平均を 1 にそろえる。
- var_z = 1 である（`model.py` L.99）。

### 3.3 C_Q を 3 つの項に分ける（DERIVED）

上の 2 つの事実から、事前密度の項はデータによらない定数になる。

```
(1/L) Σ_l ln p(Z⁽ˡ⁾) = −(nK/2) ln 2π − (1/2)·(1/L) Σ_l ‖Z⁽ˡ⁾‖²
                     = −(nK/2) ln 2π − nK/2              （scale_Z により (1/L)Σ‖Z⁽ˡ⁾‖² = nK）
```

したがって、C_Q は次の 3 項に分けられる。

| 項 | 式 | 中身 | K → K+1 の増分 |
|---|---|---|---|
| ① 潜在変数の事前密度の項 | P_Z(K) = nK(1 + ln 2π) | **データによらず、K だけで決まる** | **+425.68**（n = 150） |
| ② 観測データの項 | D(K) = −2·(1/L)Σ_l [ln p(X\|Z⁽ˡ⁾,θ̂) + ln p(Y\|Z⁽ˡ⁾,θ̂)] − 2·（定数） | E-step のサンプルで平均した当てはまり。X と Y の両方を含む | データ次第（負なら改善） |
| ③ パラメータの罰則 | PEN(K) = p_K ln n | F の自由度（回転を除く）など | +(d − K) ln n = (15 − K)·5.01（K = 1 で 70.2、K = 9 で 30.1） |

- **K を 1 増やしたときに、データに関係なく払うコストは ① と ③ の和で、455.7〜495.8 になる。** そのうち 86〜93% が ① である。
- ② の「観測データの項」は、観測データの周辺尤度 ln p(X, Y | θ) ではない。Z を E-step のサンプルに固定したときの条件付き尤度の平均である。

## 8. C_Q の理論的な懸念

### 8.1 C_Q は観測データの尤度ではない（DERIVED）

任意の Z の分布 q について、次の恒等式が成り立つ。

```
ln p(X, Y | θ) = E_q[ ln p(X, Y, Z | θ) ] + H[q] + KL( q ‖ p(Z | X, Y, θ) )
```

- E_q[ln p(X, Y, Z | θ)] は Q 関数の項、H[q] は q のエントロピーである。
- C_Q は −2 × (Q 関数の項) だけを使い、**H[q] と KL を落としている。** したがって −2 ln p(X, Y | θ) の近似ではなく、Schwarz BIC（観測データの最大対数尤度 + p ln n）でもない。
- 呼び方は「Q ベースの完全データ型基準（ICL 型）」とする（KI-010）。

### 8.2 落としたエントロピーが K の罰則として働く（DERIVED。近似）

- q を、ラプラス近似の正規分布 N(Ẑ, H⁻¹) とする。H は −ln p(X, Y, Z) の Z についての Hessian（nK×nK）である。
- このとき、エントロピーは次のようになる。

  H[q] = (nK/2)(1 + ln 2π) − ½ ln|H|

- よって、−2 ln p(X, Y) のラプラス近似は次のように書ける。

  −2 ln p(X,Y) ≈ D 型の当てはまりの項 + ln|H| + （小さい項）

- C_Q は、この ln|H| の代わりに ① P_Z = nK(1 + ln 2π) を持つ（§3.3）。
- 新しい 1 次元を足したときの両者の増分は、次のとおりである。
  - C_Q：常に +425.68
  - ラプラス近似：Δln|H|。おおよそ、各ノードの新しい方向の**事後精度**（事前分布の 1 ＋ データの情報）の対数の和
- この 2 つが等しくなるのは、ノードあたりの事後精度の対数の平均が 425.68/150 = 2.84、すなわち**事後精度 ≈ 17** のときである。
  - **事後精度がこれより小さい（弱い）方向では、C_Q はラプラス近似より強く罰する** → 過小選択の向きに働く。
  - **情報のない方向（事後精度 ≈ 1）でも、C_Q は 426 を課す** → 過大選択が起きにくい。8,000＋600 fit で過大選択が 0 だったことと整合する。
- 限定：
  - 2.84 という閾値は、ブロック対角とラプラス近似を仮定した目安である。既存の d-sweep では、この閾値だけで選択を予測できなかった（`RESEARCH_MASTER.md` §21）。
  - §7.3 の Fisher 情報の近似を当てはめると、A-b-9 の X 側の精度は約 1 + 1.1 で 17 よりずっと小さい。ただし Y 側の情報を含めていないので、目安にとどまる。

### 8.3 記録済みのデータで、どこまで厳密に分解できるか（今回確認したこと）

| 分解 | 可否 | 理由 |
|---|---|---|
| ① P_Z、② D、③ PEN の 3 項 | **厳密に可能**（浮動小数点の丸めの範囲で） | ① は scale_Z により解析的に決まり、③ は K だけで決まる。② = C_Q − ① − ③。実行は `tools/research_audit/decompose_cq_terms_k_exp2.py`、出力は `.../cq_term_decomposition_20261126/`（K_TRUE ≥ 7 の 16 セルの 10 反復目と、収束感度の 3 セルの 10・20・40 反復目）。選択は既存の解析と 250/250 データで一致した |
| ② を X の項と Y の項に分ける | **厳密には不可能** | L = 10 個の Z サンプルの平均が必要である。NPZ には Z_last（L 個目のサンプル）と Z_mean（平均）しか保存していない。MC サンプルを再生成するには、乱数の状態を含めて MCEM をやり直す必要がある |
| plug-in 値（Z_mean や Z_last での ln p(X\|Z)、ln p(Y\|Z)） | 計算はできる | **C_Q の分解ではない**別の量である。Z_last の値は L 個のうち 1 個だけで、平均とは違う。Z_mean では Jensen の不等式の分だけ値がずれる。今回は計算していない |

**算術上の反実仮想**：① を取り除いた「② + ③」で選ぶと、調べた 19 セル（K_TRUE ≥ 7 の 16 セル ＋ 収束感度の 3 セル）・190 データのすべてで、K = 10（候補の上限）が選ばれた（`per_k_terms.csv` から集計）。
- つまり、C_Q で過大選択が起きなかったのは、① という K だけで決まる項があるからである。① がなければ、完全データ型の当てはまりの項は、K を増やすごとに罰則 ③ より大きく改善する。
- これは、「① を取り除けば正しく選べる」という意味ではない。①の大きさが観測データの尤度から導かれたものではない、という問題を示している。
- この反実仮想は基準ではない。選択規則も変えていない。

### 8.4 C_Lap（ラプラス近似による基準）

- **式**（`expfam/src/experimental/laplace_k_criterion.py`。`RESEARCH_MASTER.md` §19）：

  ```
  C_Lap(K) = −2[ ln p(X | Ẑ, θ̂) + ln p(Y | Ẑ, θ̂) ] + ‖Ẑ‖² + ln|H(Ẑ)| + d_K ln N
  Ẑ = argmax_Z Φ(Z),  Φ(Z) = ln p(Z) + ln p(X|Z,θ̂) + ln p(Y|Z,θ̂)    （同時 mode。E-step のサンプルではない）
  H = −∇²_Z Φ(Ẑ)（nK × nK。Y でノードが結合する）,  d_K = K d − K(K−1)/2,  N = n（作業上の約束）
  ```

  ln ∫ e^Φ dZ ≈ Φ(Ẑ) + (nK/2) ln 2π − ½ ln|H| の −2 倍に罰則を足したものである。nK ln 2π の項は、事前密度の項と打ち消し合う。
- **性質**：
  - 観測データの evidence のラプラス近似を動機にしている。**厳密な周辺尤度ではない**（重点サンプリングによる補正は重みが退化し、近似誤差を評価できていない。KI）。
  - θ̂ は MCEM の推定値で、ラプラス近似の尤度を最大化した値ではない（Z9-U2）。
  - 一致性は検討していない。
- **適用できる範囲**：
  - lineage E の `DualExpFamLSMConsistent` だけ。
  - Y が Bernoulli・Poisson のときだけ。Gaussian-Y は未対応である。
  - したがって、系列 O・A・B には使える（8,000 fit のうち 6,000 fit、収束感度の 600 fit はすべて）。**系列 C には使えない。**
- **保存済み NPZ から計算するための条件**：
  - NPZ には F、Σ、w0、w、var_z、σ_Y、Z_last、Z_mean が入っている。X・Y は入っていないので、data seed から生成器で再生成し、`per_fit.csv` の x_hash・y_hash と照合する（監査ではスポットチェック 8 データで一致を確認済み）。
  - 同時 mode を探す開始点（Z_mean か Z_last）と、N・d_K の取り決めは、結果を見る前に決める必要がある。
  - checkpoint ごとに使える状態：
    - 8,000 fit の NPZ は 10 反復目の状態である。収束感度の 10 反復目の C_Q とビット単位で一致したので、同じ軌道の 10 反復目として扱える。照合は事前に決める。
    - 収束感度の NPZ は 40 反復目だけである。**20 反復目の状態は保存していないので、20 反復目の C_Lap は計算できない。**
  - NPZ はローカルの D ドライブにだけある（zip の退避あり）。
- **計算量**：
  - 1 回の評価に必要なのは、同時 Hessian の構成（O(n²K²)）と、Newton 法・slogdet・固有値（O((nK)³)、K = 10 で nK = 1,500）である。
  - 既存の実測（n = 150、d = 15）では、1 評価の中央値は K = 5 で 0.27 秒、K = 7 で 0.68 秒（最大 1.3 秒）だった。K = 10 は 3 乗則による外挿で約 2 秒と見込まれる。
  - 合計 6,600 評価で、CPU 1〜2 時間程度、8 並列で 30 分以内の見込み。メモリは 1 評価あたり 100 MB 未満。
  - 既存の評価では NOT_STATIONARY（同時 mode の収束失敗）が 0.1〜0.5% あった（4/2,688 件、1/224 件）。事前に決めた規則で INCOMPLETE として扱う必要がある。
- **既存の知見**（lineage E、別の条件。`RESEARCH_MASTER.md` §19・§22）：
  - 同じ fit で比べると、C_Lap の選ぶ K は C_Q 以上であることが多かった（延べ 126 件のすべてで K̂_Q ≤ K̂_Lap）。
  - 信号の弱い条件では、C_Lap の方が真の K を多く選んだ。
  - ただし、C_Lap も過小選択した条件があり、一部の条件では過大選択も起きた。**一般に C_Lap の方が優れているとは言えない。**
