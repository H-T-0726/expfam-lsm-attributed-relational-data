# C_Q と C_Lap の比較（同じ fit の上で、6,600 評価）：結果レポート

- 作成日：2026-11-26。branch `experiment/k-selection-exp2-generalization-20261125`。
- **探索的な追加解析である。** 8,000 fit と 600 fit の C_Q の結果を見た後に計画した。結果は confirmatory evidence ではない。
- **C_Lap はラプラス近似による基準で、厳密な周辺尤度ではない。**
- C_Q は Q ベースの完全データ型（ICL 型）の基準で、Schwarz BIC ではない。
- 実装系列は lineage E（prototype、Human Gate 未通過）。
- 事前登録は `clap_comparison_protocol.md`（protocol SHA-256 `ae62f041…3432`、凍結 commit `dd95ff9`）。
- 新しい MCEM・fit はしていない。8,000 fit・600 fit の結果と protocol は変更していない。

## 1. 目的

**同じ推定結果 θ̂ のまま、選択基準だけを C_Q から C_Lap に変えると、K の選択がどう変わるか**を調べる。

- 最重要の対象は A-b-9（Poisson-X / Bernoulli-Y、全体の信号を固定、K_TRUE = 9）である。C_Q は 10・20・40 反復のどれでも 0/10（K ≈ 5）だった。
- 2 つの基準の数式上の違い（事前登録 §1.3）：

  C_Q − C_Lap = −2[ℓ̄_MC − ℓ(Ẑ)] + [nK(1+ln 2π) − ‖Ẑ‖² − ln|H|] + (p_K − d_K) ln n

  これは、次の 4 つの項の和になる。
  1. 評価点の項：−2[ℓ̄_MC − ℓ(Ẑ)]
  2. 事前密度の項：nK(1+ln 2π) − ‖Ẑ‖²
  3. 体積の項：−ln|H|
  4. 罰則の項：(p_K − d_K) ln n（K によらない）

[C_Q(K_TRUE) − C_Q(K̂_Q)] − [C_Lap(K_TRUE) − C_Lap(K̂_Q)] を、4 つの項に分けた（恒等式で、和は 10⁻⁶ 以内で閉じた）。表の値は中央値で、括弧内は範囲である。

**1 次元あたり（中央値）**：

| セル | (1) 評価点 | (2) 事前密度 | (3) 体積 |
|---|---|---|---|
| A-b-9 | +146 | +278 | −245 |
| A-b-7 | +141 | +279 | −259 |
| B-b-9 | +139 | +291 | −331 |

読み取れること（DERIVED と OBSERVED。断定しない）：

- **(2) 事前密度の項**は、1 次元あたり約 +278 だった。
  - これは n ln 2π ≈ 275.7 にほぼ等しい。C_Lap の ‖Ẑ‖² は 1 次元あたり約 148 ≈ n 増えるので、P_Z の増分 n(1 + ln 2π) との差は、ほぼ n ln 2π になる。
- **(3) 体積の項 ln|H|** は、1 次元あたり約 240〜330 増え、(2) の大部分を打ち消した。
  - A-b-9 では、(2) + (3) は 1 次元あたり約 +33 しか残らない。
- **(1) 評価点の項**は、1 次元あたり約 +140〜150 で、A-b-9 では (2) + (3) の残りより大きかった。
  - C_Q は、データの当てはまりを E-step のサンプル（事後分布の広がりを含む）で平均する。C_Lap は mode で評価する。その差が、K とともに増えた。
  - 近似的な解釈（DERIVED）：Z の分布が mode のまわりの正規分布なら、E[−2ℓ] − (−2ℓ(Ẑ)) ≈ tr(H_ℓ H⁻¹) となる。1 ノード・1 次元あたり最大 1 で、実測は約 0.97 だった。ただし E-step のサンプルはラプラス近似の正規分布からの draw ではないので、目安にとどまる。
- **結論**：C_Q と C_Lap の選択の違いは、(1)〜(3) の組合せで生じた。「C_Q の事前密度の項 P_Z だけが原因」という説明は、この内訳とは合わない。P_Z の K に依存する部分のかなりの割合は ln|H| と対応しており、評価点の違いも同程度に効いている。
- ただし、どの項が「原因」かは、この恒等式からは決められない。各項は互いに独立な量ではない。

## 8. 過小選択は改善したか

- **同じ θ̂ のもとで、基準を C_Lap に変えると、K_TRUE を選ぶデータが増えた。**
  - A-b-9：0 → 6/10（10・40 反復とも）
  - A-b-7：1 → 10/10
  - B-b-9：10 反復で 5 → 10/10、40 反復で 7 → 8/10（INCOMPLETE 2）
- A-b-9 では 4/10 が過小選択のまま残った（K = 8・7）。C_Lap の余裕は小さい（§4）。
- **C_Q の過小選択は、推定値 θ̂ だけで決まっていたのではなく、基準の作りに強く依存していた**（OBSERVED、探索的）。

## 10. 研究として新しく言えること（Human Gate を通った場合。共通の限定を付ける）

共通の限定：
- 探索的な解析である
- lineage E の prototype である
- C_Lap はラプラス近似で、厳密な周辺尤度ではない
- C_Q は Schwarz BIC ではない
- n = 150、d = 15
- 各セル 10 データ
- 系列 C は対象外
- θ̂ は MCEM の推定値である

1. 同じ推定結果の上で、選択基準を C_Q から C_Lap に変えると、次のようになった。
   - Poisson-X / Bernoulli-Y の K_TRUE = 9 では、K_TRUE を選んだデータが 0/10 から 6/10 に増えた（10・40 反復とも）。
   - K_TRUE = 7 では 1/10 から 10/10 に増えた。
   - Gaussian-X / Poisson-Y の K_TRUE = 9 では、10 反復の推定値の上で 5/10 から 10/10 に増えた。
2. 選択が変わったデータでは、すべて C_Lap の方が大きい K を選んだ。C_Q で正解したデータで、C_Lap が違う K を選んだものはなかった。
3. 選択が完了したデータでは、C_Lap の過大選択は 0 件だった。ただし、余裕は C_Q より小さかった。
4. 2 つの基準の差を恒等式で 4 項に分けると、事前密度の項の K 依存分の大部分は ln|H| に対応した。データの当てはまりを E-step のサンプルで評価するか mode で評価するかの違いも、1 次元あたり約 140〜150 寄与した。
5. **C_Q の過小選択は、推定結果だけでなく基準の作りに強く依存していた。** 特に、600 fit の結果（「A-b-9 の過小選択は反復不足では説明できない」）と合わせると、A-b-9 の過小選択を「データの情報が足りないため」とだけ説明することはできない。

## 11. まだ言えないこと

- 「C_Lap が正しい」「C_Lap は一致性を持つ」「C_Lap は一般に C_Q より優れている」とは言えない。
  - INCOMPLETE が 16%（main10）あった。
  - 過大選択に対する余裕が小さい。
  - A-b-9 でも 4/10 は過小選択だった。
  - ラプラス近似の誤差は評価していない。
- 「C_Q の P_Z（ln p(Z) 項）が過小選択の唯一の原因」とは言えない（§7）。
- A-b-9 で K = 9 が「データから識別できる」とは言えない。C_Lap の曲線は K = 8〜9 でほぼ平らである。
- INCOMPLETE のデータの結果（特に過大選択）は分からない。
- θ̂ は Q ベースの推定値である。C_Lap を最大化する θ を使った場合の選択は分からない。
- 系列 C（Gaussian-Y）、他の n・d・生成規則には一般化できない。
- 元論文 Exp.2 の再現ではない。

## 12. 次に必要な検証（いずれも新しい Human Gate。今回は開始していない）

1. **NOT_STATIONARY の扱い**：失敗の約半数は、勾配が許容値をわずかに超えただけだった。max_iter や許容値を変える再評価は、新しい事前登録が必要になる。結果を見た後の救済にならないよう、規則を先に決める必要がある。
2. **ラプラス近似の精度**：A-b-9 の K = 8・9 付近で、重点サンプリングなどによる確認。既存の試みでは重みが退化したので、方法の検討が必要。
3. **評価点の項の検討**：E-step のサンプルとラプラス近似の正規分布の違い（既存の termA・R3 の分解）を、この条件で調べる。
4. **C_Lap を最大化する θ**、または両基準に共通の θ の推定。
5. 系列 C（Gaussian-Y）の evaluator、他の n・d での確認。
