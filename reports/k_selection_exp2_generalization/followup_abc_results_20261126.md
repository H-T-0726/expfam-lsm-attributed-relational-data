## Experiment A：C_Lap の開始点に対する感度

### 条件（FACT）

- 対象：
  - main10（10 反復）：A-b-9、A-b-7、B-b-9、O-b-9
  - conv40（40 反復）：A-b-9、B-b-9、O-b-9
  - 全データ・全候補 K・両初期値、計 1,400 評価
- 同時 mode を探す開始点を、Z_last（公式）から Z_mean（保存済みの L 個の E-step サンプルの平均）に変えた。
- θ̂、N = 150、d_K、grad_tol 10⁻⁸、max_iter 200 は同一にした。
- 基準となる Z_last の値は、公式の 6,600 評価の行をそのまま使った。2 つの結果のうち良い方を選ぶことはしていない。

### 結果（OBSERVED）

- **status の組合せ**（Z_last → Z_mean）：OK→OK が 1,386、OK→NOT_STATIONARY が 8、NOT_STATIONARY→OK が 6。
- **mode が同じだったか**：両方 OK の 1,386 評価のうち、1,381 評価で Φ(Ẑ) と ln|H| の差が 10⁻⁶ 以下だった（同じ mode）。|ΔC_Lap| の中央値は 4.5×10⁻⁹ だった。
- **違う mode に収束した評価**：実質的に 4 評価。どれも K > K_TRUE の候補で、Z_mean から始めた方が C_Lap は 1.7〜8.0 小さかった。
  - A-b-7 の r5（K = 10）と r9（K = 9）、A-b-9 の r8（K = 10）、B-b-9 の r5（K = 10）
  - B-b-9 の r7 の差は 10⁻⁶ 程度で、許容差をわずかに超えただけである。

| セル（source） | 正解：Z_last → Z_mean | INCOMPLETE：Z_last → Z_mean | 両方完了したデータでの選択の一致 |
|---|---|---|---|
| A-b-9（main10） | 6 → 6 | 0 → 0 | 10/10 |
| A-b-9（conv40） | 6 → 6 | 0 → 0 | 10/10 |
| A-b-7（main10） | 10 → 10 | 0 → 0 | 10/10 |
| B-b-9（main10） | 10 → 7 | 0 → 3 | 7/7 |
| B-b-9（conv40） | 8 → 10 | 2 → 0 | 8/8 |
| O-b-9（main10） | 9 → 10 | 1 → 0 | 9/9 |
| O-b-9（conv40） | 9 → 5 | 1 → 5 | 5/5 |

- **両方の開始点で完了したデータでは、選んだ K はすべて一致した**（59/59）。過小選択・過大選択の数も変わらなかった。開始点で変わったのは、INCOMPLETE になるかどうかだけである。
- **A-b-9**：
  - 10 反復・40 反復とも、全 20 データで K = 7・8・9 の順位が 2 つの開始点で同じだった。
  - C̄_Lap(8) − C̄_Lap(9) も、データごとに 4 桁以上一致した（例：r0 は −4.48、r8 は +0.597）。
  - 中央値の曲線も、K = 1〜10 のすべてで一致した（K = 8 で +3.48、K = 10 で +41.05）。
  - 図：`clap_followup_20261126/expA/analysis/fig_ab9_gap8_9_by_start.png`

### 解釈

- **A-b-9 の 6/10 と、K = 8 と 9 の小さな差は、開始点を Z_last から Z_mean に変えても変わらなかった**（INTERPRETATION：この 2 つの開始点の範囲で、数値的に安定している）。
- K = 8 と 9 の差が小さいのは、mode 探索の数値誤差によるものではない。この θ̂ のもとでの C_Lap の値そのものが近いためである。
- **開始点への依存**：
  - 余分な次元（K > K_TRUE）では、別の mode が見つかることがある（4/1,386）。
  - どちらの K でも、開始点によって停留条件を満たすかどうかが変わることがある（14/1,400）。
  - したがって、C_Lap の INCOMPLETE は開始点に依存する。
- UNRESOLVED：
  - 同時 mode が一意かどうか。
  - Z_last・Z_mean 以外の開始点での挙動。

## Experiment B：INCOMPLETE と数値収束の感度

### 条件（FACT）

- 対象：公式の NOT_STATIONARY 52 評価と HESSIAN_NOT_PD 5 評価。
- 手順：
  1. まず max_iter 200 で再現し、公式の記録とビット単位で一致することを確かめた（57/57 で一致）。
  2. NOT_STATIONARY は、max_iter = 400（Z_last、同じ θ̂、同じ grad_tol 10⁻⁸）で 1 回だけ評価した。
  3. HESSIAN_NOT_PD は救済しない。返された点での H の固有値だけを記録した。
- 「B 規則」：技術検証により、max_iter = 400 は収束済みの評価を変えない。したがって B 規則は、**全評価に一様に max_iter = 400 を適用した**のと同じである。特定のデータだけに別の成功条件を使ったわけではない。

### 結果（OBSERVED）

- **NOT_STATIONARY 52 件のうち、max_iter 400 で収束したのは 6 件だけだった。** 6 件とも K > K_TRUE の候補だった。**46 件は残った。**
- 残った 46 件の内訳（候補 K と K_TRUE の関係）：K > K_TRUE が 29、K = K_TRUE が 5、K < K_TRUE が 12。
- 残った 46 件のうち 12 件は、200 回目と 400 回目で max|∇Φ| がまったく同じだった（1.0×10⁻⁸〜3.2×10⁻⁷）。直線探索で Φ を増やせない点で止まっており、浮動小数点の精度の限界で許容値 10⁻⁸ にわずかに届かない例である。
- 他の 34 件は、400 回でも勾配が 10⁻⁸ を超えたままだった（最大 0.23）。
- **HESSIAN_NOT_PD 5 件**：
  - いずれも、負の固有値がちょうど 1 個（−0.026〜−0.061）の鞍点だった。
  - nK = 1,050〜1,500。すべて、K_TRUE = 1・3 のデータに K = 7・10 を当てはめた余分な次元の状態である。
  - そのうち 2 件は、K_TRUE = 3 の a・b の重複（同じ状態）である。
  - 固有値は B の実行中に計算したが、CSV の書き出しで列が落ちた。凍結した同じ関数で決定論的に計算し直し、`expB/analysis/hnpd_eigen.csv` に保存した。
- **INCOMPLETE のデータ数**：
  - main10：47 → 44/300（A-a-1、A-a-5、A-b-1 で各 1 データが完了した。3 データとも正解）
  - conv40：3 → 3/30
- **正解・過小・過大**（B 規則）：main10 は正解 252、過小 4、過大 0、INCOMPLETE 44。conv40 は正解 23、過小 4、INCOMPLETE 3。注目する 4 セルは変わらなかった。
- **選択バイアス**（`expB/analysis/selection_bias.csv`）：
  - main10 の INCOMPLETE 47 データのうち 39 データは K_TRUE が 1・3・5 だった。
  - 47 データすべてで、C_Q は正解していた。
  - C_Q が過小選択したデータ（24）は、すべて C_Lap が完了したデータに含まれていた。

### 解釈

- **INCOMPLETE の大部分は、Newton 法の反復上限によるものではない**（52 件中 46 件が 400 回でも残った）。
- 残った失敗は 2 種類に分かれる。
  - 精度の限界で許容値にわずかに届かないもの（12 件）
  - 勾配が十分に小さくならないもの（34 件）
- 鞍点（HESSIAN_NOT_PD）は、余分な次元で起きた。
- **全体の結論への影響は小さい。** 注目する 4 セルの結果は変わらなかった。INCOMPLETE が減ったデータも、すべて正解だった。
- 「C_Lap が完了したデータでの正解率」を全体の成功率と呼んではいけない。
  - INCOMPLETE は K_TRUE の小さいデータと K > K_TRUE の候補に偏っている。
  - C_Lap の過大選択を評価できないデータが残っている。
- UNRESOLVED：
  - 34 件の非停留の原因（平坦な方向か、多峰性か）。
  - 許容値をどう定義すべきか。

## Experiment C：複数分布 X での高次元 K 選択

### 条件（FACT）

- **n・d・X**：n = 150、d = 15。X の列は Gaussian 5 列（条件付き分散 0.1）、Bernoulli 5 列、Poisson 5 列（この順のブロック）。Y は Bernoulli。
- **生成器**：既存の `data_generator_canonical_mixed`（canonical-clean-mixed-v1）を変更せずに使った。
  - Z と F は全列で共有する。
  - 正規化・clip はしない。
  - 危険な率のときは生成を止める（seed の救済はしない）。
- **信号**：regime b と同じ規則にした。
  - F = s·Q（等特異値、s² = 0.5d/K、平均行ノルム² = 0.5）
  - w = √(3/K)
  - w0 は凍結した regime b の較正値（母集団の平均辺確率 0.20）
  - 単一 family の系列と Fisher 情報量が等しいとは仮定していない。
- **推定**：`em_runner.run_em_experimental` に family_x_list を渡した（→ `DualExpFamLSMPerColumnConsistent`）。consistent numerics、fail_fast、L = 10、10 反復。
- **規模**：K_TRUE = 5・7・9、候補 K = 1〜10、各 10 データ、2 初期値で 600 fit。seed は data_seed = 30,261,126,000 + 1000·K_TRUE + rep で、単一 X の実験とは別系統。
- **基準**：同じ状態の上で、C_Q（p = Kd − K(K−1)/2 + 5）と C_Lap（evaluator v1、Z_last から開始、max_iter 200、d_K ln n）を計算した。
  - 事前に決めた副次解析として、NOT_STATIONARY の評価は max_iter 400 で 1 回だけ評価し直した。
- **保存**：E-step の L 個のサンプルも NPZ に保存した。そのため、今回は C_Q の観測データの項を family ごとに厳密に分けられる（単一 X の実験ではできなかった）。

### 解釈と、単一分布 X の実験との比較（INTERPRETATION）

- **共通点**：
  - regime b の高い K_TRUE で、C_Q は過小選択した（単一 X の A-b-9 は 0/10、混合 X の K_TRUE = 9 も 0/10）。
  - 同じ推定結果に C_Lap を使うと、K_TRUE を選ぶデータが増えた（単一 X の A-b-9 は 6/10、混合 X は 9/10）。
  - どちらの基準でも過大選択はなかった。ただし、C_Lap の過大選択に対する余裕は小さかった。
  - 選択が変わる向きは常に「C_Lap の方が大きい K」だった。
- **相違点**：
  - 混合 X では、C_Q の過小選択が K_TRUE = 7 から現れた（6/10）。単一 X の regime b の K_TRUE = 7 では、A 系列が 1/10、O・B・C 系列が 10/10 だった。
  - 混合 X の C_Lap は、K_TRUE = 9 で単一 X の A 系列より多く正解した（9/10 と 6/10）。
- **これらの比較は、生成器・family の構成・seed が違う条件の間の記述的な比較である。** 「分布を混ぜると良くなる・悪くなる」という因果的な主張はしない。
  - 混合 X には Gaussian 列（ノイズ分散 0.1）が 5 列ある。1 方向あたりの情報量は、純粋な Poisson-X の系列とは違う。
- Phase 9X（d = 12、G3/B6/P3、n = 75、K_TRUE ≤ 4、MCEM 8 反復）は参考資料にとどめる。条件が違うので、直接比べられない。

### 数式とコードの対応（DERIVED、検証済み）

- **C_Q** = −2·(1/L)Σ_l[ln p(Z⁽ˡ⁾) + Σ_{family} ln p(X_f | Z⁽ˡ⁾) + ln p(Y | Z⁽ˡ⁾)] + (Kd − K(K−1)/2 + 5) ln n
  - `calc_Q_dual_strict_exp` が、family_x = 'mixed' のときに Poisson 列の階乗補正を入れる。
  - `calc_bic_exp` が、n_gaussian_x_cols = 5 を罰則に加える。
  - scale_Z により、(1/L)Σ ln p(Z⁽ˡ⁾) = −nK(1 + ln 2π)/2 になる（独立集計では誤差 4.5×10⁻¹³）。
- **C_Lap** = −2[ℓ(Ẑ)] + ‖Ẑ‖² + ln|H| + d_K ln n
  - ℓ の Gaussian 列の項は分散 diag(Σ)_g で割る。Bernoulli・Poisson 列は canonical link で、曲率は A″(η)。
  - `laplace_k_criterion._x_dispersion` は、per-column モデルの Gaussian 列にだけ分散を使う。
- **E-step**：`_calc_gradient` は −∇_{z_i}Φ を返し、`_calc_precision_matrix` はその Jacobian（数値微分で確認）。

## 6. まとめ

### 新しく明らかになった事実（OBSERVED、探索的）

1. A-b-9 の C_Lap の 6/10 と、K = 8・9 の小さな差は、同時 mode の開始点（Z_last・Z_mean）によらなかった。開始点への依存は、余分な次元での別の mode と、停留条件を満たすかどうか（INCOMPLETE）に限られた。
2. C_Lap の INCOMPLETE の大部分（52 件中 46 件）は、Newton 法の反復上限では解消しなかった。鞍点 5 件は、どれも余分な次元で負の固有値を 1 個持っていた。INCOMPLETE を減らしても結論は変わらなかった。

4. 混合 X では、E-step のサンプルを保存したので、C_Q の当てはまりの項を family ごとに厳密に分けられた。改善の大部分は Y と Gaussian 列から来た。
