## 2. 人工データの生成モデル

### 2.1 数式（FACT、`expfam/src/experimental/data_generator_canonical_mixed.py`）

```
z_i  ~ N(0, I_K)                               i = 1..n        （正規化しない）
F    = Q · f_scale,  Q は d×K の正規直交列       （rank(F) = K を構成で保証）
x_il ~ ExpFam_{c_l}( η_il^X = f_l^T z_i )        列 l ごとに family c_l（Gaussian / Bernoulli / Poisson）、バイアスなし
y_ij ~ Bernoulli( σ(η_ij^Y) ),  η_ij^Y = w0 + w z_i^T z_j     i < j（上三角だけを生成して対称化、対角は 0）
```

- Gaussian 列: `x_il = f_l^T z_i + ε`、`ε ~ N(0, sigma_x_var)`（**sigma_x_var は分散**）。z-score 化しない。
- Bernoulli 列: `x_il ~ Bernoulli(σ(f_l^T z_i))`。
- Poisson 列: `x_il ~ Poisson(exp(f_l^T z_i))`（clip なし。危険な率なら generator が停止する）。
- この generator は `CLAUDE.md` §1 の確定モデル（`w0, w` はスカラー、X 側にバイアスなし）と一致する。
  列ごとに family が異なるのは系列 E の prototype の機能である。

### 2.2 実際の生成順序（FACT、コードの行で確認）

乱数は次の順で消費される（`MIXED_RNG_CONSUMPTION_ORDER = ("Z", "F", "X_columns_ascending", "Y")`）。

1. **Z を生成**（`rng.standard_normal((n, K))`、l.178）
2. **F を生成**（ガウス行列を QR で正規直交化し、f_scale を掛ける。l.182、`build_full_rank_loadings`）
3. **Z から F を介して X を生成**（`η^X = Z F^T` を計算し、列 0 → 11 の順に 1 列ずつ乱数を引く。l.187–202）
4. **z_i と z_j から η^Y を作り、Y を生成**（`η^Y = w0 + w·Z Z^T` の上三角から Bernoulli を引く。l.206–214）

**重要な帰結（FACT、Phase 9P/9T の preflight で 20/20 確認済み）**: 乱数を Z → F → X → Y の順に使うので、
w0 や w だけを変えても **Z・F・X はビット単位で同じ**になり、変わるのは Y だけである。
weak / baseline / strong の比較は「同じ人・同じ属性で、関係のつながり方だけを変えたデータ」の比較になっている。

## 5. w と w0 の意味

### 5.1 研究者向け（DERIVED）

`η_ij = w0 + w S_ij`、`S_ij = z_i^T z_j`、`p_ij = σ(η_ij)`、`z_i, z_j ~ iid N(0, I_K)` とする。

- `E[S] = 0`、`Var(S) = K` なので、**`E[η] = w0`、`Var(η) = w² K`**。
  - baseline: Var(η) = 3（SD 1.73）、weak: 1.5（SD 1.22）、strong: 6（SD 2.45）。
- **w0 は η の位置（中心）**である。S = 0（潜在的に「無関係」な組）のつながる確率は σ(w0) で、w0 = −1 なら 0.269。
  §4.3 の表で、fixed-w0 の 3 条件の p の中央値がすべて 0.27 なのはこのためである。
- **w は、潜在構造 `z_i^T z_j` が η にどれだけ強く反映されるか（η の広がり）**である。
  w が大きいほど、潜在的に近い組はよりつながりやすく、遠い組はよりつながりにくくなり、確率は 0 と 1 の両端に寄る（飽和）。
- **w は平均の edge 確率も変える**。母集団の平均確率 `p̄(w0, w) = E[σ(w0 + w S)]` は σ が非線形なので w に依存する。
  S は 0 について対称なので、w0 = 0 なら w によらず p̄ = 1/2 になる。しかし w0 = −1 では、広がりが増えると
  上側の裾（確率が大きく上がる組）の寄与が、下側の裾（もともと小さい確率がさらに下がる組）の寄与を上回り、p̄ は増える。
  - fixed-w0（w0 = −1）での母集団の平均 p（Monte Carlo 2×10⁶、記述のみ）: weak **0.310** / baseline **0.331** / strong **0.356**。
  - 一般には「w を増やすと p̄ が単調に増える」ことは導出していない（σ は負の側でだけ凸）。この条件で数値的に確認したことにとどめる。

### 5.2 先生向け（直感）

- **w0 は「全体としてどれくらいつながりやすいか」のつまみ**である。w0 を下げると、ネットワーク全体がまばらになる。
- **w は「潜在空間で近い人ほどつながる」という傾向の強さのつまみ**である。
  w が小さいと、つながりは潜在位置とあまり関係のない、ランダムに近いものになる。
  w が大きいと、近い組はほぼ必ずつながり、遠い組はほぼつながらない、はっきりした構造になる。
- ただし w0 を固定したまま w だけを動かすと、ネットワーク全体の密度も少し動いてしまう。これが §7 の問題である。

## 7. fixed-w0 比較だけでは足りなかった理由

研究の流れ（INTERPRETATION）:

1. w を変えると、関係の「構造のはっきりさ」（η の広がり）が変わる。これが調べたかったことである。
2. ところが w0 を固定すると、**平均の edge 密度も一緒に変わる**（weak 0.306、baseline 0.333、strong 0.352、実現密度の中央値）。
3. すると、weak で K の過小選択が増えたのは「構造が弱いから」なのか「edge が少なく情報が減ったから」なのかが混ざってしまう。
4. そこで、**母集団の平均 edge 確率を w によらず揃えるように w0 を調整し**、密度の違いを取り除いたうえで w の違いを見直すことにした（#110 → #112 → #113）。

### 9.3 9T から言えること（INTERPRETATION）

**Phase 9P で見えた w-sensitivity は、平均密度の違いだけでは説明されない。**
残っている差は「η の広がり（構造のはっきりさ）」と「確率の飽和（分布の形）」であり、9T はこの 2 つを分けていない。
したがって、9T の結果は「平均密度を揃えたときの w-sensitivity」と呼び、「純粋な関係信号の効果」とは呼ばない。

### 9.4 事後の補足: 推定した Z の回復（EXPLORATORY、本書で新たに再集計、EM なし）

Phase 9 の事前に決めた評価は K 選択であり、Z の回復は事前の結果に含まれていない。

generator で再生成した真の Z と比べた。Z は回転を除いてしか識別できないので、回転だけの Procrustes RMSE（`run_family_selection_pilot.procrustes_rmse_z` と同じ定義）を使った。

## 11. まだ不足していること

1. **edge 密度の水準そのもの（w0 の水準）を変えていない。** Phase 9 の全条件は平均 edge 確率が約 0.33 の密なネットワークである。

2. **w の範囲が狭い。** 検討したのは w = 0.71〜1.41 で、√2 倍ずつの 3 点である。先行研究の再現用 generator では |w| の中央値が約 2 で、それより大きい強い飽和の領域は調べていない。
3. **他の n / d / K_true / family 構成で w を変えていない。** Phase 9X（K_true = 1..4）は w² K_true = 3 に揃えた設計なので、w の感度ではない。

4. **「η の広がり」と「確率の飽和」を分けていない。** 9T は平均だけを揃えたので、純粋な信号の強さの効果とは言えない。
5. **Z の回復（§9.4）は事後の再集計**であり、事前に決めた評価ではない。
6. 証拠はすべて系列 E の prototype の合成データであり、学会予稿の系列や実データには一般化しない。

## 13. 修論研究への意味

- **既存の証拠だけで、先生の w に関する疑問にはかなり答えられる。**
  baseline の条件は「w が小さくて易しい」条件ではなく、w を弱めると難しくなり、強めると易しくなるという単調なパターンの中間にある。
  これは、密度を揃えた比較と Z の回復でも同じ向きだった。
- 修論本文で人工データの実験を示すときは、§3 の条件表と §4 のデータのイメージ（密度 0.33、確率の範囲、属性の値域）を必ず添えると、
  先生の「条件が分からない」という指摘に直接答えられる。
- **限界として明記すべきこと**: 調べたのは密なネットワーク（平均 edge 確率 ≈ 0.33）だけであり、w の範囲は 2 倍（η の分散で 4 倍）である。
  また、平均密度を揃えても飽和は揃っていない。
- これらはすべて系列 E の prototype の合成データの結果であり、本文の主張に昇格させるには Human の判断が必要である。

## 14. 先生に 1〜2 分で説明する場合の要点

1. **データ**: 75 人に 3 次元の潜在位置を与え、そこから 12 個の属性（連続 3・2 値 6・カウント 3）と、2775 組の 0/1 の関係を作っています。
   関係は約 3 組に 1 組がつながり、1 人あたり平均 25 人とつながる密なネットワークです。
2. **w と w0**: つながる確率は σ(w0 + w·z_iᵀz_j) です。w0 は全体のつながりやすさ、w は「潜在空間で近い人ほどつながる」傾向の強さです。
   baseline は w0 = −1、w = 1 です。
3. **w を変えた結果**: w を 0.71 と 1.41 に変えて同じ 20 データで比べました。
   w を小さくすると K を小さく選びがちになり、Z の推定も悪くなりました。大きくすると K = 3 に揃い、Z の推定も良くなりました。
   **つまり「w が小さいからうまくいった」のではなく、w が小さいほど難しいという結果です。**
4. **密度の影響を除いた確認**: w を変えると全体の密度も変わってしまうので、w0 を調整して平均密度を 0.331 に揃えて再実験しました。
   結果はほぼ同じで、密度の違いでは説明できませんでした。
5. **まだ調べていないこと**: すべての実験は平均密度 0.33 の密なネットワークです。まばらな関係（w0 が小さい側）は未検討で、必要なら小さな追加実験 1 つで確認できます。

## DECISION

## **B: ONE_BOUNDED_W_W0_FOLLOWUP_IS_USEFUL**

w についての先生の疑問には、既存の証拠（9P・9S2・9T と、事後の Z 回復の再集計）でかなり答えられる。
したがって w をさらに振る実験は提案しない。
一方で、**w0 を edge 密度の水準として変えた実験は一度もなく**、まばらな関係は実データに直結するうえ、どちらの結果が出ても修論の限界の書き方が変わる。
この 1 点についてだけ、小さな追加実験は新しい情報を増やす。#130（分布の誤指定）との優先順位は Human が判断する。

### 提案する最小の実験（1 つだけ、設計のみ、実行しない）

- **名前**: sparse mean-density sensitivity at fixed w（仮称 Phase 9T-sparse）
- **研究上の問い**: w = 1 を固定し、母集団の平均 edge 確率を 0.331（baseline）から **0.10** に下げたとき、C_Lap / C_Q の K 選択と K = 3 での Z の回復はどう変わるか。
- **操作**: w0 だけを変える。`p̄(w0, 1) = 0.10` を満たす w0 を、Phase 9S2 の厳密な密度による 1 次元積分（`density_w_recalibration.py`）で凍結する。新しい較正法は作らない。
- **固定するもの**: n = 75、d = 12、K_true = 3、G3/B6/P3、Bernoulli-Y、f_scale = √2、sigma_x_var = 1、L = 5、8/8 反復、K = 1..5、start_B、同じ 20 seed。
  Z・F・X は 9K とビット単位で同じになる。baseline は 9K の記録を再利用する。
- **主要な結果**: K_hat_Lap / K_hat_Q の分布（exact / under / over）と、9K との replicate ごとの対応。
  副次的に、K = 3 での Procrustes RMSE_Z を**事前に決めた**副次結果として出す。
- **規模**: 新しい条件 1 つ、新しい EM ≤ 200。既存の runner（`run_density_controlled_w.py` と同じ流れ）に protocol を与える最小の wrapper だけを追加し、新しい gate や auditor は追加しない（`CLAUDE.md` §6）。
- **呼び方の制約**: 「平均密度の水準の感度」と呼ぶ。w0 を変えると確率の分布の形（下側の飽和）も変わるので、「純粋な密度の効果」とは呼ばない。
- **0.10 を選ぶ理由**: baseline の約 1/3 で、各人の期待次数は約 7。K の過小選択が起きうる程度にまばらで、Y の情報が完全には消えない水準である。
  これは研究上の提案値であり、最終的な値は Human が決める。Cora（0.011）ほどまばらではないので、実データの挙動を直接再現するものではない。
