# 修士研究｜潜在次元Kについて今回確認したこと

出発点にあるのは、「昔は選べていたKが、現在のclean条件では特に小さいnで選びにくい。この差をどう解釈すればよいのか」という疑問である。
あわせて先生から、何を真の潜在次元とするのか、BICで選んでよいのか、そもそも生成モデルとして成立するのか、という指摘を受けた。
このページでは、過去と現在の人工データ実験を確認し、その結果を読むために必要なKの意味と選択基準の整理までをまとめる。
以下は理解しやすさを優先した説明順であり、実験と理論検討を行った時系列ではない。

最終更新：2026-09-06

## 1. なぜ潜在次元Kを調べ直したのか

研究では、各対象の属性データを `X`、対象間の関係データを `Y` とし、その両方を共通の潜在ベクトル `z_i` で説明するモデルを扱っている。`K` はこのベクトルの次元、`n` は対象数（ノード数）である。属性数は `d` と書く。属性側・関係側の分布を、それぞれGaussian・Bernoulli・Poissonから指定できるように拡張した。

人工データでは生成時にKを設定できるので、まず「生成に使ったKと、複数候補を推定して選んだKが一致するか」を確認していた。しかし、その一致だけでモデル選択について十分に説明できるのか、という問いが残る。

先生からの指摘と今回の疑問は、次の3点に整理できる。

1. 何を「真の潜在次元」とするのか。生成モデルとしての成立性も含めて、理論から確認する必要がある。
2. 過去の選択結果と現在の結果はなぜ違うのか。そもそも比較している条件や評価対象は同じなのか。
3. BICなどの選択基準をどう位置づけるのか。生成時のKとの一致から、何を主張できるのか。

## 2. 昔の「K選択成功」は何を意味していたか

過去の結果には、複数の候補Kを実際に比較した実験が残っていた。以下の2系列は別の実装による結果である。

### fixed系列：生成次元K_TRUE=3

ここでのfixedは、Y側の追加1/2係数を除いた推定実装の名称であり、**「Kを固定した実験」という意味ではない。**

`n=150`、候補 `K=1,…,9` で、次の3条件を各10試行行っている。表の略記はX側／Y側の順である。

| 分布の組合せ | 略記 | K=3との一致数 |
|---|---|---:|
| Poisson-X / Bernoulli-Y | P/B | 10/10 |
| Gaussian-X / Poisson-Y | G/P | 10/10 |
| Bernoulli-X / Gaussian-Y | B/G | 10/10 |

合計30/30で、当時「BIC」と呼んでいたQベース基準がK=3を選択した。[候補Kごとの一次結果](../../expfam/results/fixed_official/exp1_k9/fixed_exp1_bic_k1to9_summary.csv)

### historicalの旧0.5系列：生成次元K_TRUE=5

こちらはPoisson-X / Bernoulli-Y、`n=150`、候補 `K=1,…,10` の5試行で、Qベース基準が5/5でK=5を選択した。[一次結果のk_true=5の行](../../expfam/results/exp2_bic_A.csv)

この旧0.5系列ではY側項だけに追加1/2係数が残っているため、Newton方向が全体として正しいとは断定できない。ただし、記録された選択結果は、その実装・生成条件での観察として残る。

昔はKを固定したままRMSEだけを見ていたわけではなく、複数の候補Kを比較して、生成次元と一致するKを選択していた。少なくとも、family名がPoissonであることだけでは現在の結果を説明できない。これは過去の結果の読み取りであり、Poissonだけを変えた原因切り分け実験ではない。

一方、fixed系列の別のn-sweepでは、生成側だけでなく推定モデルにもK=3を与え、`n=50→300` に伴う潜在変数の推定誤差 `RMSE_Z` の改善を見ていた。これはparameter recovery（潜在変数などの回復）の実験であり、K選択成功とは区別する。[RMSEの一次結果](../../expfam/results/fixed_official/exp2/fixed_exp2_n_sweep_improvement.csv)

## 3. clean条件では何が起きたか

現在の比較対象は、Poisson-X / Bernoulli-Y、`K_TRUE=5` の人工データ実験である。生成器は `canonical-clean-v1` を使う。ここでcleanと呼ぶのは、潜在変数Zを生成後に標準化せず、Poissonのリンクも打ち切らないなど、記述したcanonicalモデルに沿って生成する条件である。

候補Kは1〜7、各nで8データセット、各候補で2つの初期値を使い、EM反復数は8とした。推定実装はobjective-consistent系列で、第2節の2系列とは異なる。これはexperimental prototypeであり、修論本文への無条件な採用を意味しない。

選択にはheld-out S1を使った。Yの約20%のペアを学習から外し、その関係をどの程度予測できるかを測るスコアである。各Kについて2つの初期値のスコアを平均し、最も高い候補を選ぶ。関係の一部が未観測で、そこを予測したいという使い方に近い設定である。

| n | K=5との一致数（8反復） |
|---:|---:|
| 50 | 2/8 |
| 75 | 0/8 |
| 100 | 4/8 |
| 150 | 8/8 |

今回の有限試行では、小さいn側でK=5との一致数が低く、選択は低いK側に寄る傾向があった。一方、n=150では全試行で一致した。「小標本なら必ず失敗する」という結果ではなく、一致数がnに対して単調に増えているわけでもない。

[各試行のselected K](../../expfam/results/k_selection/clean_true_k_asymptotics_20260904/selection_matrix.csv) ／ [各fitのスコア](../../expfam/results/k_selection/clean_true_k_asymptotics_20260904/fit_results.csv)

## 4. 反復数とsample sizeで説明できるか

### 反復数を増やした確認

小さいn側の結果が、8反復で止めていることだけで説明できるかを確認するための実験も行っている。データ、分割、学習マスク、初期値、生成器、推定実装を同じにして、40反復までの経過を比較した。

第3節の8反復を基準にすると、結果は次のようになった。

| n | K=5との一致数（40反復） | 8反復からの一致数の増減 |
|---:|---:|---:|
| 50 | 2/8 | 0 |
| 75 | 1/8 | +1 |
| 100 | 6/8 | +2 |
| 150 | 7/8 | −1 |

反復数を40まで延ばしても、K=5との一致数が全条件で一貫して増えたわけではなかった。nによって変化の向きも異なる。

追加反復では新しいMonte Carloサンプルも引かれるため、純粋な最適化の進行だけを測った比較ではない。この結果を、収束の証明や「最適化は原因ではない」という結論には使えない。

[反復ごとの一次結果](../../expfam/results/k_selection/em_convergence_sensitivity_20260905/checkpoint_results.csv)

### 昔の条件でnだけを変えた確認

historical条件の成功が、n=150だったことにどの程度依存するかを見るため、旧0.5系列の生成器・推定・選択基準・seed規約を保ち、nだけを変えたbridge実験がある。これは第3節のclean実験とは別系列である。

| n | K=5との一致数（historical条件、各5試行） |
|---:|---:|
| 50 | 1/5 |
| 75 | 4/5 |
| 100 | 5/5 |
| 150 | 5/5 |

n=150では、10候補K×5試行の計50fitについて、BICとRMSE_Zが過去の記録と完全一致している。50個の独立試行があるという意味ではない。[一致確認の記録](../../expfam/results/k_selection/historical_pb_k5_n_sweep_20260906/replication_gate.json)

historical条件でも小さいnでは一致数が落ちた。sample sizeは、今回のK選択の難しさに関係する要因の一つと考えられる。[bridgeの一次結果](../../expfam/results/k_selection/historical_pb_k5_n_sweep_20260906/fit_results.csv)

ただしn=75では、historicalが4/5、current cleanの8反復が0/8で、同じnでも結果に差が残る。両者はnと試行数以外にも複数の条件が異なる（第9節）。

> sample sizeだけでは、historicalとcurrentの差全体を説明できない。
> この比較から「currentの方が悪い」「差は信号による」といった優劣や原因を読み取ることはできない。

## 5. そもそも、どのKを「真のK」と呼ぶのか

ここまでは生成時のKとの一致を数えていた。しかし、生成に使った次元と、観測分布を表現するために必要な次元、予測に適した次元は同じとは限らない。実験で数えた「成功」の意味を考えるには、この区別が必要になる。

| 記号 | 意味 |
|---|---|
| `K_GEN` | 人工データ生成時に指定した次元。ここまでの実験の `K_TRUE` |
| `K*` | 真の観測分布を表現できる最小潜在次元 |
| `K^rank` | X側の構造から階数（rank）として識別される次元。利用できる条件は分布による |
| `K_PRED` | 指定した予測手続き・スコアで、予測上最適となる次元 |

**これらは一般には同じとは限らない。**

`K*` は、真の観測分布が比較するモデル族に含まれるというM-closedの仮定の下で定義する。実データではこの仮定が成り立たず、`K*` が存在しない場合もある。また、有限のheld-outデータから実際に選ばれたKを、そのまま予測上最適な `K_PRED` とみなすこともできない。

## 6. 生成モデルは成立し、Kはどこまで識別できるか

### 成立・モーメント・識別・選択は別の問題

canonicalモデルでは、`z_i ~ N(0,I_K)` とし、属性の自然パラメータを `f_l^T z_i`、関係の自然パラメータを `w0 + w z_i^T z_j` とする。属性側にバイアスはなく、`w0` と `w` はスカラーである。

有限のn・d・K、有限パラメータ、正のGaussian分散の下では、X側とY側それぞれGaussian・Bernoulli・Poissonの3×3=9通りで、同時分布はproper（全確率が1）になる。

ここから先は段階を分けて考える必要がある。確率モデルとして成立すること、必要なモーメントが有限であること、観測分布からKを識別できること、有限標本の選択手続きがそのKを選ぶことは、それぞれ別の主張である。前の段階が成り立っても後の段階は自動的には従わない。

例えば、打ち切りのないPoisson-Yは分布としては成立するが、分散が有限になるのは `|w|<1/2` のときである。identifiability（識別可能性）が成立する場合でも、有限標本で実際に選べるかはさらに別の問題として残る。

| 分布 | 既存の理論整理で言える範囲 |
|---|---|
| Poisson-X | canonical・打ち切りなしの条件で、母集団モーメントから `FF^T` を識別できる |
| Gaussian-X | 雑音共分散 `Σ` が既知なら、X側の階数を議論できる。未知の場合の十分条件は未解決 |
| Bernoulli-X | 一般の属性数dについては未解決。既存の非識別例はd=1のX周辺に限る |
| Gaussian-Y | `w≠0` の条件で識別結果がある。単一ペアの周辺分布についての結果であり、観測値1個から推定できるという意味ではない |
| Bernoulli-Y | Y側単独の一般的なKの識別可能性は未解決 |
| Poisson-Y | モーメントの存在条件と識別可能性は別。後者は未解決 |

### 現在のP/B条件でK_GENを意味づける範囲

canonical・打ち切りなしのPoisson-Xでは、属性と潜在変数を結ぶ行列Fの `FF^T` が母集団モーメントから識別される。既存の理論整理では、次の条件を明示してKの関係を整理している。

- Zが独立に `N(0,I_K)` に従うcanonicalモデルで、Poissonリンクを打ち切らない。
- 真の観測分布が候補モデル族に含まれる（M-closed）。
- `rank(F)=K_GEN` かつ `d≥K_GEN`。
- 有限標本の推定値ではなく、母集団モーメントについて考える。必要なモーメントは候補パラメータ空間で有限。
- 候補空間が必要な次元を含み、どの候補Kでも同じcanonical Poisson-Xを使う。

この条件下では、

```
K^rank ≤ K* ≤ K_GEN
K^rank = rank(F) = K_GEN
したがって K* = K_GEN
```

と整理できる。[理論整理の§3.1.1に条件と導出を記載している](../k_selection_theory/true_k_identifiability_and_selection_theory_20260906.md)。

> 現在のP/Bのclean生成条件には、Poisson-X側から条件付きで `K*=K_GEN` を意味づける整理がある。
> 一方、Bernoulli-Y側単独の一般的なKの識別可能性は未解決である。両者は対象が異なり、後者の未解決性が前者を取り消すわけではない。

これは条件付きの理論整理であり、すべての分布・生成器・選択手続きに一般化しない。Zを標準化し、Poissonリンクを打ち切るhistorical生成器にも、そのまま適用できない。母集団での関係が成立することと、現在のS1などが有限標本でそのKを選ぶことは、別問題として残る。

## 7. 過去のBICと現在のS1は何を選んでいるか

Kの意味に加えて、選択に使った量も異なる。過去のコードや原論文に「BIC」と書かれていても、潜在変数Zをどう扱うかまで確認する必要があった。

| 区分 | 量 | Zの扱い・対応する基準 |
|---|---|---|
| Q1 | `log p(X,Y \| Z,θ)` | Zに条件づける量（conditional／plug-in）。原論文Eq.(16)・Eq.(26)側 |
| Q2 | `log p(Z,X,Y \| θ)` | Zの事前分布も含む完全データの同時対数密度。historical expfam基準の当てはまり項は、この量の近似事後期待値 |
| Q3 | `log p(X,Y \| θ)` | Zを積分した観測データの周辺対数尤度。standard Schwarz BICが通常対象とする量 |

historical expfamの実装は、Q2側の `Q_strict` を使うQベース完全データ型基準であり、Schwarz BICではない。原論文の印刷式もQ1側で、Q3ではない。ただし原論文で具体的にどのZを代入するかなどの評価手続きは、本文からは特定できていない。

> 過去のcriterionで真の生成次元と一致するKを選べたことは事実だが、それはstandard Schwarz BICのconsistency（一致性）を確認したことを意味しない。

現在のS1は、学習から外した関係ペアに対するheld-out Bernoulli log scoreである。log score自体はproperなスコアだが、現在評価しているのは、潜在変数やパラメータの推定値を代入したplug-in predictorであり、それらの不確実性を積分した予測分布ではない。

この手続きで選ばれるKと `K*` が一致する条件、また `K_PRED` と `K*` の関係は未解決である。過去のQベース基準の成功をS1の保証として読むことも、S1の結果からQベース基準の方が正しいと結論することもできない。

## 8. ここまでで答えられたこと

- 過去には、生成次元と一致するKを複数候補から選んだ実験があった。Kを与えた状態でのRMSE改善とは別の結果である。
- current cleanでは、有限標本の条件によって生成次元との一致数が変わった。
- 反復数を延ばしても、一致数の一貫した改善は見られなかった。収束や最適化上の問題の解消まで確認したわけではない。
- historical条件でも小さいnで一致数が落ちたため、sample sizeは関係する要因の一つと考えられる。
- canonicalモデルそのものは確率生成モデルとして成立し、Poisson-Xでは明示条件下で `K_GEN` を `K*` として意味づける整理がある。
- historicalのQベース基準、standard Schwarz BIC、現在の予測スコアは区別する必要がある。実験での一致は、選択手続きの一致性の証明ではない。

## 9. まだ切り分けられていないこと

### 実験条件として残るもの

旧条件とclean条件は同じK・同じ分布の組合せでも、信号の強さと構成が異なる。旧条件では関係側の `w=1.5`、Fの各行の二乗ノルムは0.9である。clean条件では `w=sqrt(3/K)`、Fの行の二乗ノルムは平均0.5としている。この信号整合は、K間で分布形まで同じにしたという意味ではない。

生成器も異なり、旧条件のZ標準化やPoissonリンクの打ち切りはclean条件にはない。さらに、Yの全ペアを学習に使うか一部をholdoutするか、Qベース基準かS1か、初期化・初期値数、推定実装の系列にも違いがある。

これらの寄与は分離されていない。どれを主要因とするかは未解決であり、選択結果だけから実装バグの有無を判断することもできない。

### 理論として残るもの

Bernoulli-Y側単独の一般的なKの識別可能性、standard marginal BICの一致性、S1の選択対象と `K*` の関係が残っている。第6節の条件付き整理によって、これらまで解決したわけではない。

`n→∞` を議論する場合も、属性数dを固定するのか、関係データの疎性や観測量をどう設定するのかという漸近レジームを決める必要がある。関係ペアは潜在変数を共有するため、ペア数をそのまま独立な標本数とは扱えない。有効標本数や正則性なども未整理であり、今回のnの比較を一致性の証拠にはできない。

## 10. 先生に相談したいこと

1. **修論では、何を「真のK」の中心概念として扱うべきか。**

   `K*` を中心にするか、予測上の `K_PRED` との関係まで扱うかによって、実験の成功の定義と必要な理論が変わる。

2. **Bernoulli-Y側の一般的識別可能性を、修論内の証明対象として追うべきか。**

   現在のP/B条件にはPoisson-X側からの条件付き整理があるため、Y側単独まで扱う範囲を決めたい。

3. **K選択の理論と実験に、どこまでを求めるか。**

   standard marginal BICの一致性、予測基準の位置づけ、有限標本特性の整理では課題の範囲が異なるため、修論で到達すべき点を相談したい。

4. **追加実験を行うなら、残る条件差のどれを優先して切り分けるか。**

   信号・生成器・Yのholdout・基準・推定実装の違いを一度に原因とすることはできないため、確認する問いを絞る必要がある。
