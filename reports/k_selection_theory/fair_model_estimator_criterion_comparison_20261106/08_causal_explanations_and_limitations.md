# 08 原因の候補の検証と限界（2026-11-06）

機械可読の版：`causal_hypothesis_verdicts.csv`。結果の列は解析 CSV から計算し、手入力はしていない。候補・予測・比較・判定の文は固定の文で、結果を見た後に書いた（INTERPRETATION）。

判定の語彙：
- SUPPORTED：予測どおりの結果
- PARTIALLY_SUPPORTED：一部だけ予測どおり
- NOT_SUPPORTED：予測が外れた
- REJECTED：反証された
- INCONCLUSIVE：比較が成り立ったが差を判別できない
- UNRESOLVED：比較が成り立たない

**公平な比較でないものからは原因を断定しない。**

## 2. 依頼で挙げられた原因の 5 分類への対応

| 分類 | 結論 | 根拠の強さ |
|---|---|---|
| (a) モデルの違い | 原因ではない（H1） | 強い（数値の同一性と導出） |
| (b) 推定器の違い（1/2・初期値・最良反復） | n=150 では C_Q の選択を変えなかった（H2）。失敗が起きる n=75 では未検証なので、現在の失敗の原因かどうかは**判定できない**。Q_Z なしの基準とは交互作用がある | 低い〜中程度（各 2 データ、n=150 だけ） |
| (c) 基準の違い（Q_Z、plug-in、Laplace） | Q_Z を除くと過大になる（H3）。C_Lap は C_Q より n=75 での正解が多い（完全なデータでの割合）が、近似の精度は未確認（H9） | 強い（過大）／未解決（Laplace） |
| (d) データ条件（n、信号、生成器、分布族） | n は一要因の比較で効果が明確（H4、SUPPORTED）。信号（H5）・分布族（H6）・生成器（H8）は多要因の比較なので、**原因の大きさの順位は付けない**。信号は 2 水準しかなく、n=75 での信号の効果（0/4→2/4）は強い信号での n の効果（2/4→4/4）と同程度 | n：中程度（各 4 データ）／他：因果の主張なし |
| (e) 観測マスク | 方向は予測どおりだが、判別できない（H7） | 弱い |

## 3. 「Python はなぜ K=9 を選べたのか」（問 3）

- **OBSERVED**：同じ生成器（G_old）・同じ n=150 で、OLD 推定器を共通の予算（L=5、8 反復、2 初期値）で再実行すると、C_Q・C_Lap・PY_hist のどれでも K_GEN=9 を選ぶ（2/2）。系列 E でも同じ。G_canon（z-score なし、w²=0.75）でも同じ。
- **INTERPRETATION**：n=150・d=15・全ペア観測という条件では、K=9 の過小側の余裕が大きい（C_Q で 734〜2235）。この条件では「Python の推定器が特別だった」「旧生成器が特別だった」ことは必要ではなかった。現在の canonical の失敗（n=75、80% マスク、弱い信号）とは条件が違うが、どの違いがどれだけ効くかは、n 以外は判定できない。
- **限界**：各条件 2 データ。元の Python の結果 CSV（5/5）が今のコードで作られたことは確認できない（PR #158）。

## 4. 「原論文 Fig. 3 の成功」（問 4）

- **UNRESOLVED**。生成の n・信号・推定の L と反復・Z の評価点・集計方法が本文から決まらない（PR #158）。本研究の結果と矛盾はしない（n=150 なら K=9 まで選べる）が、**同じ条件の再現ではない**ので、「Fig. 3 を再現した」「Fig. 3 の成功の理由を説明した」とは言わない。

## 5. 限界

1. データ数：E1 は各条件 2、E2・E3 は各 4。件数の差が 1〜2 データの比較（分布族、マスク、信号の一部）は判別力が低い。
2. 予算：L=5、8 反復は全セル共通。MC の変動（PR #159 の mcse_B は 4 程度）は、過小側の余裕が ±50 以内のデータの判定に影響しうる。
3. E2 の Gaussian-X は、Fisher 情報の期待値をそろえた**構成された比較**で、support・分散関数が違う。
4. E2 の信号は F と w を同時に変えた。単独の効果は PR #155 を参照（本研究では判定しない）。
5. C_Lap の INCOMPLETE（7 状態、Laplace NOT_STATIONARY）は補完していない。そのセルの C_Lap の件数は少ない。
6. Laplace の IS は退化し、近似誤差の大きさは分からない（H9）。
7. K_GEN = K0 は仮定していない。Bernoulli-Y を含む識別可能性は UNRESOLVED。G_old のデータは canonical モデルからの独立な標本ではない。
8. OLD と E の比較は Gaussian-X・全ペア・n=150 だけ。
9. 系列 E は prototype で、本研究の結果は manuscript evidence ではない。
10. OLD は 0.5 系列で、OLD の結果には「Newton 方向が全体として正しいとは断定できない」が付く（KI-001）。E1 で OLD と系列 E を同じ表・図に並べるのは、推定器の比較という設計による例外（KI-002）で、行ごとに系列を明記した。
11. PY_hist は元の Python Exp.2 の規則（3 初期値の最小、30 反復）ではなく、2 start の平均・8 反復で集計した Python 型の規則である。
12. 照合ゲートは代表の 3 状態だけを再推定した。照合ゲートは runner を commit する前の作業ツリーで実行した。E1〜E3 の間に、runner・protocol・推定コードの変更はない。
