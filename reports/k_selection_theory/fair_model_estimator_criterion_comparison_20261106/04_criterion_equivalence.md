# 04 K 選択基準の同等性（Phase C、2026-11-06）

C_Q は Q ベースの complete-data / ICL 型の基準で、Schwarz BIC ではない。C_Lap はラプラス近似で、厳密な周辺尤度ではない。詳細な導出は PR #159 の `reports/k_selection_theory/qz_criterion_existing_states_20261106/01_mathematical_definitions.md`、Figure 3 の数値化は PR #158。

## 2. 公平な比較の 2 種類

- **比較 1（基準だけを変える）**：同じ推定状態に A〜E を適用する。E1・E2・E3 のすべての状態でこれを行い、`criterion_scores.csv` に並べる。
- **比較 2（推定器だけを変える）**：E1 で、同じデータ・同じ初期状態・同じ seed の旧推定器と系列 E の状態を、同じ共通評価器・同じ基準で採点する。
- 推定器と基準を同時に変えた歴史的な比較（例：Python 再現の BIC と現在の C_Q）からは、どちらの単独の効果も断定しない。

## 3. Q_Z の意味（C7）

- **事前分布としての役割**：ln p(Z) はモデルの一部で（論文 Eq.(17)(18) にも入る）、Q 関数（EM で最大化する量）に含まれるのは正しい。「余計な項」や「バグ」ではない。
- **`scale_Z` による定数化**：L 個の標本をまとめて縮尺し、標本の平均二乗を 1 にするので、−2Q_Z = nK(1 + ln 2π) となり、θ にも X・Y にもよらない（PR #159、全状態で誤差 1e−12）。つまり、**選択基準の中で Q_Z が担っているのは「事前分布の当てはまり」ではなく、K に比例する定数**である。
- **正規化が事後標本の分布を変えるか**：`scale_Z` は各 E-step の後に標本全体を 1 つの定数で縮尺する。これは厳密な MCEM の手順ではない（近似 Gibbs の連鎖をスケール変換で止める操作）。事後分布の形は変えないが、尺度は固定される。尺度の固定は回転・スケールの不定性（Z ↔ F の尺度の付け替え）を取り除く役割を持つ（INTERPRETATION）。
- **K に比例する項は数理的に必要か**：周辺尤度 Q3 では、事前分布は積分に入り、各次元に「事前の体積 − 事後の体積」の項（ラプラス近似では ½ ln|H| − (nK/2) ln 2π と ‖Ẑ‖²/2）が現れる。不要な次元では事後分布が事前分布とほぼ同じになり、この項はほぼ 0 になる。必要な次元では、事後分布が事前分布より狭くなるので負の寄与（Occam 因子）になる。**Q2 の Q_Z は、この「次元ごとの Occam 因子」を、データによらない定数 (1 + ln 2π)/2 で置き換えたものと見ることができる**（INTERPRETATION）。その大きさに統計的な根拠はない。
- **Q_Z を除くことと、妥当な基準を得ることは別問題**である（PR #159：Q_Z を除くと過大選択）。

## 4. 潜在変数モデルの BIC の理論条件（C8）

| 条件 | 本モデルでの状況 |
|---|---|
| Schwarz BIC の仮定：観測データの周辺尤度、正則なモデル、真値が内点、Fisher 情報が正則 | 周辺尤度は Z の nK 次元積分で、閉じた形がない。C_Q も Eq.(26) も周辺尤度ではない |
| 潜在変数の積分 | C_Lap はラプラス近似で行う。近似誤差は n、K、Y の結合の強さに依存（§9 の IS 確認） |
| 回転不変性 | F → FR、Z → ZR で不変。罰則の k(k−1)/2 はこれを引いている。K > K0 では余分な方向が特異点を作る |
| 識別可能性 | Poisson-X は X だけで K0 = rank(FFᵀ)（P1）。Gaussian-X は因子分析の条件。Bernoulli-Y は UNRESOLVED（`true_k_identifiability_hardened_20260904.md`） |
| 特異モデル | K > K0 では、パラメータ空間の真値の集合が特異。BIC の罰則は過大になりうる（Watanabe の WBIC の領域）。本研究では扱わない |
| 有効サンプルサイズ | X は n 個の独立な行。Y は n(n−1)/2 個のペアだが、ペアは独立でない（z を共有）。罰則の ln N に n と n(n−1)/2 のどちらを使うかは決まらない。C_Lap は N = n を作業上の約束として使う |
| K に応じたパラメータ数 | p_K = Kd − K(K−1)/2（＋Gaussian-X の d）。w0・w・σ_z² は数えない（定数なので選択に影響しない） |
| ラプラス近似の成立条件 | 事後分布が単峰で正規に近いこと。nK 次元で、各 z_i の事後の情報量は X（d 個）と Y（n−1 個の結合）から来る。n が小さく、Y の結合が強いと、正規近似の誤差が大きくなりうる |

**結論**：どの基準も、Schwarz BIC としての理論的な正当化は証明されていない。C_Lap は「Z を積分する」という点で BIC の考え方に最も近いが、(i) ラプラス近似の誤差、(ii) N の選び方、(iii) 特異性、(iv) θ が短い MCEM の推定値であること、が未解決である（UNRESOLVED）。
