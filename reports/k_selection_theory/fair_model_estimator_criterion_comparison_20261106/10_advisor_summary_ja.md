# 10 指導教員向けの要約（2026-11-06）

対象：原論文（Mikawa et al. 2024）のモデルと、指数型分布族への一般化（系列 E、prototype）の同等性、および潜在次元 K の選択が成功・失敗する条件。新しい MCEM fit は 659 件（上限 900）で、すべて正常に終了した。詳細は 02〜08。

## 結論（10 項目）

1. **同じモデルか**：同じ。原論文のモデルで μ_x=0・σ_z²=1 とすると、Gaussian-X/Bernoulli-Y の ExpFam モデルと完全データ対数密度が一致する（数値差 0）。違うのは実装で、旧 Python 再現の E-step には Y 側に余分な 1/2 がある（DERIVED + OBSERVED）。
2. **何が違ったのか**：歴史的な成功（Python 再現、#139、初期 ExpFam）と現在の canonical の失敗の間では、n（150 と 75）、観測（全ペアと 80%）、信号、生成器、推定器、基準が同時に違っていた。統制実験では、**n の違いが最も大きい要因**だった（OBSERVED）。
3. **Python はなぜ K=9 を選べたか**：n=150・d=15・全ペア観測では、K=9 は余裕をもって選べる条件だったから。同じデータで旧推定器と系列 E を同じ初期値・seed で比べても、どちらも C_Q で K=9 を選んだ（2/2）。z-score をしない生成器でも同じ（OBSERVED、各条件 2 データ）。
4. **原論文 Fig. 3 の成功**：理由は**未解決**。生成と集計の手順が本文から決まらず、同じ条件を作れない（UNRESOLVED）。
5. **現在の失敗の要因**：n=75 での過小選択。n=75→150 で C_Q の正解は 0/4→3/4（弱い信号）、1〜2/4→4/4（強い信号）。X の分布族（Gaussian と Poisson）、推定器、生成器は主因ではなかった（OBSERVED）。
6. **成功の条件**：本研究の範囲では、n=150、d=15、K_GEN ≤ 9（Gaussian-X 全ペア）または K_GEN=5（80% マスク）。信号が弱くても C_Q は 3/4、C_Lap は 4/4 が正解だった。
7. **過小・過大の条件**
   - **過小**：C_Q・C_Lap を n=75 で使った場合。
   - **過大**：Q_Z（K に比例する項）を除いた基準、または条件付き plug-in 基準を使った場合。系列 E の全 44 データで過大になった。
   - C_Q と C_Lap は、どの条件でも過大にはならなかった。
8. **K の選択と推定の関係**：選択が失敗する条件（n=75、弱い信号）では、K を正しく与えても潜在構造の回復が悪い（ZZᵀ の相関 0.76〜0.84。n=150・強い信号では 0.92〜0.94）。誤った K の held-out の予測は、わずかに悪い（1 ペアあたり約 0.007 nat）。
9. **直すべきこと**：
   - K 選択の成否を n と信号の条件と一緒に報告する（n=75 の失敗を「手法の失敗」と一般化しない）。
   - Q_Z を除いた基準や plug-in 基準は採用しない。
   - C_Lap は有望だが、近似の精度を確かめる方法がない（IS が退化した）。
   - 旧 Python の 1/2 は導出上の誤りだが、本研究の条件では K 選択を変えなかった。
10. **論文で言えること・言えないこと**
    - **言える（系列 E は prototype という条件つき）**：
      - モデルは原論文と同等であること。
      - n=150 では C_Q・C_Lap が K_GEN（5、9）を選ぶこと。
      - n=75 では過小選択が起きること。
      - Q_Z を除くと過大選択になること。
    - **言えない**：
      - 「原論文 Fig. 3 を再現した」
      - 「C_Q は BIC である」
      - 「C_Lap は周辺尤度である」
      - 「K_GEN が真の最小次元 K0 である」
      - 「n=75 と 150 の間のどこで切り替わるか」
      - 「実データで K を正しく選べる」

## 確実性

| 主張 | 根拠 | 確実性 |
|---|---|---|
| モデルの同等性 | 導出と数値の同一性 | 高い |
| Q_Z なしでは過大 | 44/44 データ（同じ状態での基準の比較） | 高い |
| n が主要因 | 一要因の比較、各 4 データ × 4 条件 | 中程度 |
| 推定器は C_Q の選択を変えない | 各 2 データ × 4 条件、n=150 だけ | 中程度〜低い |
| 生成器・分布族は主因でない | 多要因の比較、各 2〜4 データ | 低〜中程度 |
| 観測マスクの効果 | 床効果で判別できない | 未確定 |
| Laplace 近似の精度 | IS が退化 | 未解決 |
