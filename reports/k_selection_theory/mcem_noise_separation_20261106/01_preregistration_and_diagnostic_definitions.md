## 2. 診断量の定義（Phase 2）

θ_c, Z_c を checkpoint c の保存状態とする。G = F Fᵀ、rel(a, b) = ‖a − b‖_F / ‖b‖_F。

**A. パラメータの変動（標本を使わない量）**
- D_Q(c) = rel(Q_64, Q_c)、Q ∈ {G, w0, w, η̂_x, η̂_y}。η̂ は Laplace の同時 mode Ẑ(θ)（Z_c から開始）での自然パラメータ：η̂_x = Ẑ Fᵀ、η̂_y = w0 + w ẑ_iᵀẑ_j。θ だけで決まる（初期値依存を除く）。

**B. Monte Carlo 雑音（θ を固定した再サンプリング）**：checkpoint 32・64 で、(θ_c, Z_c) から次の E-step と同じ手順の連鎖（長さ 5）を独立に R=16 本（seed `[7700000, fit_id, c, r]`）。
- 1 ステップ更新の分布：各連鎖のあとに M-step → θ'_r。g_r = rel(G'_r, G_c)。PR #156 の診断量と同じ定義の 1 ステップ値（gram・η_x・η_y）も計算。
- 系統成分と雑音の分解：m = 平均 G'_r、s² = Σ‖G'_r − m‖²/(R−1)、drift² = max(‖m − G_c‖² − s²/R, 0)、drift_share = drift²/(drift² + s²)。w0・w も同様。**系統成分には、揺らいだ状態が中心へ戻る平均回帰も含まれる**（R1b で方向を確認）。
- 1 標本の η の雑音：θ_c を固定し、独立な連鎖の最後の標本どうしで rel(Z_a Fᵀ, Z_b Fᵀ)（8 組）。
- 事後平均の η：η̄_x = Z̄ Fᵀ（80 標本の平均。η_x は z について線形なので E[η_x] の推定）。η̄_y = 標本ごとの w0 + w z_iᵀz_j の平均。**w0 + w z̄_iᵀz̄_j（plug-in）は一般に E[η_y] と一致しない**（E[z_iᵀz_j] = E[z_i]ᵀE[z_j] + tr Cov(z_i, z_j)）。両者の差も記録する。MC 誤差は 8 本ずつの半分割の差の 1/2。
- 評価の雑音：θ_c 固定で C_Q を L=5（16 個）、L=20（4 個）、L=80（1 個）で計算。Q_X・Q_Y・Q_Z も。

**C. 選択基準の安定性**：L=80 の固定 θ の slack S(4→5)（start 平均）、C_Lap の slack、符号、start 間の差。

## 4. Phase 4（技術的 pilot）

- 理由（事前に決定）：Phase 3 は θ を固定するので、**推定中の E-step の L を変えたときに推定値そのもの（MCEM の固定点・slack）が変わるか**には答えられない。
- 設計：L ∈ {20, 50}、条件 A と D、rep 1..4、K_fit 4・5、start 1、PR #156 と同じ model seed、32 反復、checkpoint 8・16・24・32。32 反復時点で、1 ステップ再サンプリング（R=8、fit と同じ L）と評価用連鎖（16 本 × 5、seed `[7710000, fit_id, 32, r]`）。比較対象の L=5 は PR #156 の同じ fit の 32 反復時点（Phase 3 の probe）。
- **(1) 評価用 MC 標本を増やす実験（Phase 3 の L=20/80 評価）と、(2) 推定中の L を変える実験（Phase 4）は区別する。** L を変えると推定アルゴリズムそのものが変わるので、Phase 4 の fit は PR #156 の fit の継続ではない。
- 予算：Phase 4 は 1,024 fit-iteration（L=20：512、L=50：512）。壁時計の上限は全体で 6 時間。ゲートの見積もりで Phase 4 が 4 時間を超える場合は L=20 を落とす。

## 5. 失敗時の扱い

例外・非有限値は FAILED として記録し、リトライも seed の取り直しもしない。Laplace が OK でない checkpoint は、C_Lap と mode に基づく量を INCOMPLETE とし、補完しない。
