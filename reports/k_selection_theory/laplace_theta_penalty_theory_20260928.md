## 1. 罰則をかける対象

**FACT（Phase 9H）**: `C_Lap(K) = −2·laplace_log_observed(K) + d_K log N`。前半は θ̂ を固定した `log p(X,Y|θ̂,K)` の Z についての Laplace 近似。

**DERIVED**: 後半は **θ についての積分の近似**であって Z の罰則ではない。出発点は

```
p(X,Y | K) = ∫ p(X,Y | θ,K) π_K(θ) dθ
```

で、正則な内点最大値 θ̂ では

```
log p(X,Y|K) ≈ ℓ_K(θ̂) + log π_K(θ̂) + (p_K/2) log 2π − ½ log|J_K(θ̂)|,   J_K = −∇²_θ ℓ_K(θ̂)
```

（`ℓ_K(θ) = log p(X,Y|θ,K)`）。`J_K ≈ N · I_K(θ)`（I_K は O(1) で非退化）と書けるときに限って
`−½ log|J_K| = −(p_K/2) log N − ½ log|I_K| ` となり、`−2×` で `p_K log N` が**先頭次**として現れる。
`log π_K`、`(p_K/2) log 2π`、`½ log|I_K|` は **O(1) だが K に依存しうる**項で、BIC はこれらを捨てている。
したがって `d_K log N` は「J_K の成長率が N で p_K 次元すべて同じ」という仮定の下での先頭次近似にすぎない。

## 2. 識別可能な θ の次元

Z を積分した後の連続パラメータ（family 割当 c を固定）:

| block | 次元 | K 依存 |
|---|---|---|
| F（loadings） | 下記 | あり |
| Gaussian-X 分散 | n_gauss(c) | なし（c 固定なら） |
| w0 | 1 | なし |
| w | 1 | なし |
| Gaussian-Y 分散（本条件では Bernoulli-Y なので無し） | 0 | — |

**F の識別可能次元（DERIVED）**:
- 観測モデルは `(Z, F) → (ZR, FR)`（R ∈ O(K)）で不変: X は `F z_i` が不変、Y は `z_iᵀ z_j` が不変、事前 N(0,I) は回転不変。
- O(K) の F への作用 `F ↦ FR` の固定部分群は、F が列フルランク（rank K、したがって K ≤ d）なら自明（`FR = F ⇒ R = I`、F に左逆行列がある）。
  よって軌道の次元は `dim O(K) = K(K−1)/2`、商空間の次元は **`Kd − K(K−1)/2`**。
- 条件（ASSUMPTION）: K ≤ d、F 列フルランク、θ が内点、かつ観測分布が θ を O(K) の作用を除いて**局所的に識別する**こと。
  Gaussian-X のみなら因子分析の識別条件（例: `(d−K)² ≥ d + K`）が必要で、d=12, K≤5 では成り立つ（`(12−5)² = 49 ≥ 17`）。
  mixed X と relational Y を含む本モデルの一般的な識別性は証明していない（UNRESOLVED）。
- **有限の対称性**: 符号反転・座標の置換は O(K) の元であり、連続回転に含まれる。次元は減らさない。
  θ の積分では、尤度は回転の軌道に沿って平坦なので、軌道の体積（O(1)、K に依存）が現れ、`log N` 項は生じない。
  これが `−K(K−1)/2` を引くことの正当化である。
- **rank < K のとき**: F の rank が r < K なら、固定部分群は O(K−r) で非自明になり、その点で局所的な次元が下がる（**特異点**）。
  ただし本モデルでは、F の零空間に対応する潜在座標も Y には効くので、X 側だけ見た特異性とは異なる（§8）。
- **K > d**: F は列フルランクになりえず、上の数え方は成り立たない。本研究の K ≤ 5 < d = 12 では該当しない。

## 3. family 固定 vs family 選択

**A. c を固定して K だけ比較（DERIVED）**: Gaussian 分散の数は K によらないので、K 依存の次元は F の `Kd − K(K−1)/2` だけ。

**B. c が K ごとに変わりうる（実際の pipeline）**:
- 周辺尤度は離散の model index を含めて `p(X,Y|K) = Σ_c π(c|K) p(X,Y|K,c)`。候補の c は有限個（曖昧列 m 個なら 2^m、m ≤ d で n に依存しない）。
- **DERIVED**: `max_c log[π(c|K) p(X,Y|K,c)] ≤ log p(X,Y|K) ≤ max_c log p(X,Y|K,c) + log|C|`。
  model prior π が O(1)（例: 一様）で候補数が n に依存しないなら、**離散の family 選択が生む寄与は O(1) であり `log n` 次の罰則は生じない**。
  support gate は K に依存しない（データだけで決まる）ので、曖昧列の集合と一様な π(c|K) は K 間で共通で、比較では相殺する。
- 連続次元で c に依存するのは Gaussian 分散の数 `n_gauss(c)` だけで、これは既に `d_K` に含めている。Bernoulli と Poisson は同じ loading 次元で、分散パラメータを持たない。
- **UNRESOLVED**: 実装は c を evidence の最大化ではなく candidate score で選んでいる。選んだ c が `argmax_c p(X,Y|K,c)` と一致しない場合の誤差は評価していない。
- 「探索したから罰則を足す」という議論はここでは使っていない。Phase 9K で全 refit が G3/B6/P3 だったことも根拠にしていない。

## 4. block ごとの情報量のスケール（最重要）

**Louis の恒等式（DERIVED）**: `ℓ(θ) = log ∫ p(X,Y,Z|θ) dZ` を 2 回微分すると

```
−∇²ℓ(θ) = E[ −∇²_θ log p(X,Y,Z|θ) | X,Y ] − Var[ ∇_θ log p(X,Y,Z|θ) | X,Y ]
            （期待完全情報）                      （欠測情報 ≥ 0）
```

### F block

- **上界（DERIVED）**: F は `p(X|Z,F)` にしか現れない（`p(Y|Z,w0,w)` は F を含まない）。完全情報は列ごとに `Σ_i z_i z_iᵀ · c_il`
  （Gaussian 列は `c = 1/σ_l²`、Bernoulli/Poisson は曲率）で、`E‖z_i‖² = K` なので **O(n)**。欠測情報は非負なので、観測情報も **O(n) を超えない**。
- **下界（ASSUMPTION が必要; 無条件には導出していない）**: 観測情報が `c·n` 以上になるのは、次の条件が成り立つときである。
  (a) 回転を除いた局所識別性、(b) 内点・F の列フルランク、(c) 観測情報が非退化、(d) F についての欠測情報の割合が 1 に近づかない。
  Y はノードごとに n−1 本のペアを持つので、z_i の事後分散は小さくなり、(d) はもっともらしい（INTERPRETATION）が、証明はしていない。
- **結論**: **DERIVED**: F の完全情報は O(n)、Louis の恒等式から周辺の観測情報は O(n) を超えない（Y が F の情報を n² 次に押し上げることはない）。
  **ASSUMPTION (a)–(d) の下で** 回転を除いた F の方向で `J_F = Θ(n)`。

### Gaussian-X 分散

- 各 Gaussian 列の分散は、その列の n 個の残差から推定される。完全情報は `n/(2σ⁴)` で、観測情報の上界は O(n)（DERIVED）。Θ(n) は F と同じ ASSUMPTION の下でのみ。

### w と w0

- **Z に条件づければ**、どちらもペア数 O(n²) の情報を持つ（Daudin et al. の ICL がペア量に `log n(n−1)/2` を使うのはこのクラス条件付きの状況; LIT）。
- **w（UNRESOLVED）**: **DERIVED** なのは、条件付き尤度 `p(X,Y|Z,θ)` が `(Z, w, F) → (cZ, w/c², F/c)` で厳密に不変であることだけである。
  固定された事前 N(0, I) はこの変換で不変ではないので、Z を積分した後の w 方向の曲率の次数を決めるには追加の導出が必要であり、**w の情報量の次数は UNRESOLVED**。
  **INTERPRETATION**: この尺度の混同を区別するのが n 個の潜在ベクトルの 2 次モーメント（事前）だけだとすれば、w の周辺情報は O(n) である可能性がある。
- **w0（UNRESOLVED）**: w0 の一様なずらしは Z の変換で厳密には吸収できない（平均のずらし μ は `wμᵀ(z_i + z_j)` というノード項を生む）。
  LIT（Bickel, Chen & Levina 2011, Theorem 1 (2.6)）: 交換可能なネットワークでは辺密度の推定が `√n` 速度で、ノードの潜在変数のランダムさが母集団の量の情報を O(n) に抑える。
  一方で本モデルは潜在分布が既知のパラメトリックモデルであり、w0 が O(n) か O(n²) かは導出できていない。
- w0・w とも**全 K で 1 次元ずつ**である。**それぞれの情報量の次数が K に依存しないという仮定（ASSUMPTION）の下では**、その次数が何であれ K 比較の先頭次では相殺し、
  K 依存の先頭次罰則の判断（§6, §12）には影響しない。

## 5. block determinant

**DERIVED**: `J_K = D^{1/2} M_n D^{1/2}`、`D = diag(n^{a_b} I_{p_b})` と書けて、`M_n → M`（非特異）なら

```
log|J_K| = Σ_b a_b p_b log n + log|M| + o(1).
```

- cross-block 項が `O(n^{(a_b+a_c)/2})` 以下なら、M が非特異である限り先頭の指数は変わらない。
- cross-block 項がそれより大きい（ある方向で情報が打ち消される）場合、Schur complement の固有値の次数が下がり、その方向の指数が変わる。
  本モデルで w と Z の尺度が混同されること（条件付き尤度の不変性）は、(θ, Z) の同時 Hessian で見ればこの種の効果の候補であるが、周辺情報での次数は導出していない（UNRESOLVED; §4）。
- **現在の K 依存罰則 `[Kd − K(K−1)/2] log n` に帰着するための仮定**:
  1. F block の指数 `a_F = 1`（§4 で上界は導出、下界は ASSUMPTION）
  2. F 以外の block は、次元も指数も K によらない（c 固定、w0・w・分散の指数が K 非依存; ASSUMPTION）
  3. 回転を除いた `M_K` が非特異（列フルランク、識別性、内点）
  4. `log|M_K|`、`log π_K`、`(p_K/2) log 2π`、回転軌道の体積は K 依存の O(1) 項として捨てる
- 仮定 4 により、**`d_K log n` と真の `log|J_K|` の差には K に依存する O(1) 項が残る**。その大きさは導出していない（UNRESOLVED）。

## 6. N = n の位置づけ

**DERIVED**:
- K 依存の block は F だけで、その情報は O(n) が上界（DERIVED）、ASSUMPTION §4 (a)–(d) の下で `Θ(n)` なので、
  **これらの正則性・非退化の仮定の下で**、先頭次の罰則の sample size として n が支持される（§5 の仮定 1–3 も要する）。
- `n(n−1)/2` を F の罰則に使う根拠は**ない**。F の情報は O(n) が上界なので、`log n²` は先頭次で罰則を 2 倍にすることになり、Laplace 展開と合わない。
- `nd` について: `log(nd) = log n + log d`。d を固定すれば、`d_K log(nd) − d_K log n = d_K log d` は n によらない。
  つまり n と nd は**先頭次（log n の係数）では区別できず**、違いは K 依存の O(1) 項 `Δd_K · log d` に現れる
  （例: K=2→3 で `Δd_K = 10`、`10 · log 12 ≈ 24.8`）。これは §5 の仮定 4 で捨てている他の O(1) 項（`½Δ log|M_K|`、`(Δp_K/2) log 2π ≈ 9.2` など）と**同じ次数**であり、
  先頭次の理論だけでは n と nd のどちらが有限標本で良いかは決まらない。
- w0・w の指数（O(n) か O(n²) か）は、K 間で同じなら先頭次の比較には影響しない。ただし有限標本では、情報の定数や F との cross-block 項が K に依存しうるので、
  「同数だから完全に無視できる」とは言えない（K 依存の O(1) 項として残りうる）。w の次数自体も UNRESOLVED（§4）。
- **一番強く言えること**: 「N = n is supported as the leading scale for the K-dependent F block under these regularity/non-degeneracy assumptions」
  （N = n は、K 依存の F block について、正則性・非退化の仮定の下で先頭次のスケールとして支持される）。
  有限標本の K 依存 O(1) 項（n と nd の違いを含む）は理論で決まっていない。**スカラーの N で全 block を表す書き方は、K 非依存の block を含めると誤解を招く**
  （w・w0 の次数は未解決）が、K 比較の先頭次に関わる F については、上の仮定の下で n で表せる。
- Phase 9K の結果（19/20）は N = n の正当化に使っていない。

## 7. d_K の位置づけ

**DERIVED**: family 固定、K ≤ d、F 列フルランク、内点、O(K) を除いた局所識別性の下で、K 依存の連続次元は `Kd − K(K−1)/2`、
これに c が決める `n_gauss(c)`（K によらない）を足したものが `d_K` である。w0・w は数えないが、全 K で同数なので先頭次の比較には影響しない。
family が K ごとに変わる場合も、離散 index の寄与は O(1) で、連続次元の違いは `n_gauss(c)` を通じて `d_K` に入っている（§3）。
**d_K の定義自体に先頭次の問題は見つからなかった**。残るのは特異点（§8）と O(1) 項（§5）。

## 8. 入れ子性と特異性の再監査

以前の報告（Phase 9G §9）の「K > K_true は因子分析のように特異」をそのままは採用せず、再検討した。

**DERIVED（generic, w ≠ 0）**:
- K+1 モデルでは `η_ij = w0 + w(z_iᵀ z_j + u_i u_j)`、u_i ~ N(0,1) は Z と独立。
  **追加座標だけを単純なパラメータ制約で消す埋め込みは存在しない**。u を消すのは w = 0 だけで、これは既存の K 次元の Y への効果も消す。
- X 側では F の追加列を 0 にすれば u は X に効かないが、**Y には必ず効く**。
- 条件付きの η だけでなく観測分布で考えても、Y の分布は潜在ベクトルの内積の分布を通じて決まり、
  次数関数 `d(z) = E_{z'} g(w0 + w zᵀz')` は `‖z‖²` の分布（K 次元なら χ²_K、K+1 次元なら χ²_{K+1}）に依存する。
  K と K+1 で次数分布の全モーメントを、w0 と w の 2 つのスカラーだけで一致させることは一般にはできないと考えられる（graphon として異なる; INTERPRETATION）。
- ただし、**観測分布のレベルで、別のパラメータ化によって同じ分布を作れないことは、完全な識別性の証明なしには示していない**。
- **結論**: 単純な入れ子の埋め込みは存在せず、generic な w ≠ 0 では **non-nested であることが強く示唆される／識別性の仮定（ASSUMPTION）の下で成り立つ**。
  その場合、真の K_0 に対して K_0+1 モデルは「冗長な特異方向を持つ上位モデル」ではなく「Y について誤指定されたモデル」になる。
  各 K のモデル自体は、O(K) の回転を除けば、列フルランクの内点で**正則でありうる**（ASSUMPTION: 識別性）。
  いずれにせよ、**因子分析型の特異性（入れ子の上位モデルの特異点）を本モデルの K > K_0 に自動的に当てはめることはできない**。

**特殊な場合（分けて扱う）**:
- **w = 0**: Y は Z に依存せず、X は因子分析型になる。K+1 モデルは F の追加列を 0 にして K モデルを含み（入れ子）、その点は**特異**（LIT: Drton & Plummer §1–2, 因子分析は特異）。
- **F が rank 不足**: 固定部分群 O(K−r) が非自明で、その点は特異。ただし w ≠ 0 では、零空間に対応する座標も Y に効く。
- **信号ゼロ・境界**: 内点の仮定が崩れ、Laplace 近似は使えない。

**正則 BIC への含意（INTERPRETATION）**:
- 「特異だから BIC 不可」「非入れ子だから BIC 不可」という結論はとらない。Laplace/BIC は候補ごとの周辺尤度の近似であり、入れ子は必要ない。
- 真の分布が候補の 1 つに含まれ、他の候補が KL で分離されていて、その分離が n とともに（少なくとも n に比例して）増えるなら、
  過小・過大の K は対数尤度の O(n) 以上の不足で排除され、`log n` 次の罰則の正確な形は漸近的には効かない（ASSUMPTION: 分離の速度。本モデルでは導出していない）。
- w ≠ 0 で過大な K が「特異な上位モデル」ではない（識別性の仮定の下）なら、Drton & Plummer が扱う特異 BIC の過剰罰則の問題は、少なくとも w ≠ 0 の generic な状況では主要な論点ではない可能性がある（UNRESOLVED）。

## 8.5 厳密な周辺尤度と、実装の Laplace 周辺尤度

§1–8 の情報量のスケールの議論が直接扱うのは、**厳密な周辺対数尤度** `ℓ(θ) = log p(X,Y|θ,K)` である。
一方、実装の Candidate B が使うのは、その Z についての Laplace 近似 `ℓ_Lap(θ)`（`laplace_log_observed`）である。

したがって、厳密な周辺尤度から導いた先頭次罰則 `d_K log n` を実装の C_Lap に当てはめるには、**追加の仮定（ASSUMPTION）**が必要である:
**Laplace 近似の誤差 `ℓ − ℓ_Lap` とその θ 微分が、θ̂ の近傍で一様に、先頭次の O(n) 情報スケールを変えないこと**
（`∇²_θ ℓ_Lap` が `∇²_θ ℓ` と同じ次数・非退化性を持ち、誤差が K に依存して先頭次の項を作らないこと）。

Phase 9J は θ̂ を固定した点での値の補正を IS で見たものであり、しかも重みが強く退化していた。
**θ 微分のレベルでの一様な精度は検証されていない（UNRESOLVED）**。
この橋渡しは §12 の DECISION でも限定として扱う。

## 9. 近似的な θ̂

**FACT**: 実験の θ̂ は 8 反復の MCEM（L=5、scale_Z あり）の出力である。

**DERIVED**:
- Laplace/BIC の理論は θ̂ を `ℓ_K` の最大化点として扱う。最適化誤差 `δ = θ̂ − θ̃`（θ̃ は最大化点）による対数尤度の損失は `≈ ½ δᵀ J_K δ`。
- 基準の差の誤差を `o_p(1)` にするには `‖δ‖ = o_p(n^{-1/2})`（J = Θ(n) の方向で）が必要。先頭次（`log n` 次）の主張だけなら `O_p(n^{-1/2})` で足りる。
  `‖δ‖` が O(1) なら損失は O(n) になり、罰則を支配する。
- EM の収束速度は、各方向での欠測情報の割合で決まる。§4 の w と Z 尺度の混同の方向では、完全情報が O(n²) であるのに対し、
  観測情報が O(n) である可能性がある（§4 の INTERPRETATION; 次数自体は UNRESOLVED）。もしそうなら**欠測情報の割合が 1 に近く、純粋な EM はこの方向で非常に遅い**。実装の scale_Z は各反復で Z の尺度を固定しており、この方向の動きを変えている可能性がある。
  8 反復・L=5 の出力がこの条件を満たすかは分からない（UNRESOLVED）。
- MCEM の固定点は、近似事後（Laplace サンプル、scale_Z）の下での固定点であり、厳密な MLE と一致する保証はない。

## 10. 原論文との比較

**FACT（原論文 PDF）**:
- Eq.(16) の `L` は `Π_i p(x_i|F, z_i, …) Π_{i≠j} p(y_ij|z_i, z_j, …)^{1/2}` で、**z に条件づけた尤度**である。

- `ln n` の導出はなく、Schwarz [20] を引用して慣用の BIC として使っている。採用理由は「真の次元の推定が目的」「BIC は一致性を持つ」。

  Candidate B の `ln n` の根拠は §4–6 の F の情報量のスケールである。

## 12. 最終判断

## **DECISION: RETAIN_N_EQ_n_QUALIFIED**

- **N = n について**: K 依存の F block の情報量は Louis の恒等式から O(n) が上界（DERIVED）で、正則性・非退化の仮定 §4 (a)–(d) の下で Θ(n)。
  したがって「**N = n is supported as the leading scale for the K-dependent F block under these regularity/non-degeneracy assumptions**」。
  `n(n−1)/2` は先頭次で合わない。n と nd は先頭次では区別できず、K 依存の O(1) 項（`Δd_K log d`）で違う。**有限標本での最適な定数は未決**。
- **d_K について**: `Kd − K(K−1)/2 + n_gauss(c)` は、family 固定・K ≤ d・列フルランク・局所識別性の下での K 依存の連続次元として正しい。
  離散の family 選択は O(1) の寄与しか生まず、`log n` 次の罰則は不要。
- **実装への橋渡し**: 上の導出は厳密な周辺尤度 `ℓ` についてのもので、実装の `ℓ_Lap` に当てはめるには、Laplace 誤差とその θ 微分が先頭次の情報スケールを変えないという追加仮定が要る（§8.5; UNRESOLVED）。
- **w, w0**: 情報量の次数は UNRESOLVED だが、全 K で同数・次数が K 非依存という仮定の下では、K 依存の先頭次罰則の判断に影響しない。
- **Phase 9K の数値**: 事前に固定した working criterion（`d_K log 75`）の結果として**そのまま有効**である。本報告は基準を変更しない。**過去の結果の再計算は不要**。
- **限定**: K 依存の O(1) 項（`log|M_K|`、事前、`(p_K/2) log 2π`、回転軌道の体積、n と nd の差）と、θ̂ が最大化点でないことの影響は評価していない。
  小さな差（例: Phase 9K の最小の差 22）がこれらの O(1) 項で覆るかどうかは UNRESOLVED。

**最大の UNRESOLVED**: θ̂（8 反復 MCEM）が `ℓ_K` の最大化点からどれだけ離れているか、特に w と Z の尺度の混同の方向（EM が遅い方向）で、
その誤差が K に依存する O(1) 以上の損失を生んでいないか。これは罰則の形より先に、C_Lap の値そのものの解釈に効く。

**次の最小ステップ（Human 判断）**: Phase 9K の `fitted_states.json`（100 refit）を使い、EM を回さずに、各 θ̂ で `laplace_log_observed` の θ 勾配
（回転の方向を除く）と、1 回の Newton 更新で得られる改善量を計算する診断。これで θ̂ の最適化誤差が K に依存する O(1) 以上かを確認できる。
P-C の実装はその後に判断する。いずれも新しい frozen protocol と Human Gate が必要。

## 13. CAN SAY / CANNOT SAY

**CAN SAY**
- `d_K log N` は Z ではなく θ の積分の先頭次近似であり、`J_K ≈ N·I_K` のときに限って現れる。
- 列フルランク・K ≤ d・内点・局所識別性の下で、F の識別可能次元は `Kd − K(K−1)/2`（O(K) の商）。
- F の完全情報は O(n) で、周辺の観測情報は O(n) を超えない（Y は F の情報を n² に押し上げない）。
  正則性・非退化の仮定の下で、K 依存の F block の先頭次のスケールとして N = n が支持される。
- n と nd は先頭次で区別できず、違いは K 依存の O(1) 項。`n(n−1)/2` を F の罰則に使う根拠はない。
- 離散の family 選択は O(1) の寄与で、`log n` 次の罰則を要しない。
- w ≠ 0 では、K+1 モデルの追加座標だけを単純なパラメータ制約で消す埋め込みはなく、因子分析型の特異性を自動的には当てはめられない
  （generic な non-nestedness は強く示唆され、識別性の仮定の下で成り立つ）。
- Phase 9K の数値は frozen working criterion の結果として有効で、再計算は不要。

**CANNOT SAY**
- N = n が有限標本で最適であること、K 依存の O(1) 項の大きさ。
- w と w0 の周辺情報量の次数（w の O(n) は INTERPRETATION にとどまる）。
- F の `Θ(n)` を仮定なしに示したこと。
- K と K+1 のモデルが観測分布のレベルで入れ子でないことを、完全な識別性の証明つきで示したこと。
- 厳密な周辺尤度で導いた先頭次罰則が、実装の Laplace 周辺尤度 `ℓ_Lap` にそのまま当てはまること（θ 微分レベルの近似精度は未検証）。
- 本モデル（mixed X, relational Y）の一般的な識別性、KL 分離の速度、一致性。
- θ̂ が最大化点に十分近いこと。
- 選んだ family 割当が evidence の最大化と一致すること。
- 候補の優劣。
