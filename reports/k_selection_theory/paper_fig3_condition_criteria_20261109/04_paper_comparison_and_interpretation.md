## 解釈

### 1. 原論文 Fig. 3 の結果に近づいたか

- **主規則では、近づかなかった。**
  - 試行ごとの選択は、K_GEN が大きいほど過大選択が多くなった（C_Q の正解は K_GEN=9 で 1/10）。
  - 条件付き尤度型の基準は、全試行で過大選択した。
- **副次の参考規則（最小）では、argmin が原論文と一致した。** しかし、次の理由で、この一致を「原論文の成功を再現した」証拠とは扱わない。
  - 1 データ × 1 回の結果である。
  - 余裕が試行間のばらつきより小さい。
  - 曲線の大きさが原論文と違う。

### 2. この条件で何が観測されたか

- **過小選択がないのは、強い信号による**（OBSERVED）。
  - 過小側の余裕は、C_Lap でも 3,488〜9,319 と巨大で、どの基準でも過小選択は 0 件だった。
  - X の信号：$F^\top\Sigma^{-1}F$ の最小固有値は 140〜2,700。
- **過小側のエントロピーの項**（DERIVED + OBSERVED）
  - Δ2H は −1000〜−1800 だった。新しい次元の**事後**精度の幾何平均 ≫ $2\pi e$ で、C_Q は C_Lap より緩い側にあった。PR #163 の理想化と向きが一致する。
  - ただし、余裕全体（3,500〜10,000）に比べれば一部で、**過小選択がないことの理由ではない**（理由は信号の強さ）。
- **過大側の Δ2H の中央値は、K_GEN によって符号が違った**（+147、−33、+130、−79、−70）。
  - PR #164 では、過大側の 5→6 の Δ2H は全セルで大きく正（120〜252）だった。**本研究の負の中央値は、その観測と逆**である。
  - 「余分な次元の事後精度は低い」という理想化とも合わない（過大側の Δlog|H| は 280〜500 で、余分な次元にも事後精度がある）。理由は分からない（UNRESOLVED）。
- **試行間のばらつき**（事後的・探索的。03 §2）
  - K_GEN ≥ 3 では、同じデータ・同じ K の基準の値が、試行だけで SD 240〜480 ばらついた。これは、評価の MC 誤差や基準の間の差より大きい。
  - 試行ごとの過大選択に、このばらつきが関わっている**可能性**がある。
  - ただし、次の 2 つの限界がある。
    - 順位の証拠の大部分は機械的に生じる。
    - 初期値への依存と、MCEM の経路の分散は区別できない。

### 3. 条件付き尤度型の基準は、強信号の条件でも過大選択したか

- **した（全試行、K=8〜10）。** 平均・最小の規則でも同じだった。
- Z の評価点を明示した Eq.(16) 型の基準は、原論文 Fig. 3 と一致しない。
- 原論文の ln L が何だったか（正規化・評価点）は UNRESOLVED である。原論文の BIC は、本研究の 6 基準のどれとも違う量だった可能性がある（HYPOTHESIS）。

### 4. PR #164 との関係（矛盾しない点と、食い違う点）

| 項目 | PR #164（n=75/150 × 弱/強、Poisson/Gaussian-X、80% マスク、L=5・8 反復、rep 4 データ/セル） | 本研究 |
|---|---|---|
| 主な誤り | 過小選択（とくに n=75 の弱信号）。C_Q・C_Lap・C_ELBO の過大選択は 0 件 | **過大選択**（K_GEN+1）。過小選択は 0 件 |
| C_Q と C_Lap | C_Q ≤ C_Lap（57/57）。差の大部分は Δ2H | ほぼ一致（40/44）。C_Q が大きい例外が 1 件 |
| 過小側の Δ2H | 多くが正（C_Q が厳しい） | 大きく負（C_Q が緩い） |
| 過大側の Δ2H | 全セルで正（120〜252） | 符号が混在（負の中央値が 3/5） |

- **矛盾しない点**：過小側の Δ2H の符号が、事後精度で変わること（理論 PR #163 の両側）。
- **食い違う点**
  - 過大側の Δ2H。
  - 誤りの向き（過小 vs 過大）。
  - PR #164 で過大選択がなかったのに、本研究では主な誤りだったこと。
- 両研究は、信号・n・family・マスク・L・反復・生成器・データの数（本研究は各 K_GEN 1 データ）が同時に違う。**どの違いが効いたかは分離していない。**
