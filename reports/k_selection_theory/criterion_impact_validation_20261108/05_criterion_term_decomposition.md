# 05 選択の違いを数式上の項に分解する（Phase D、2026-11-08）

一次表は `entropy_and_r3_decomposition.csv` と `score_by_dataset_k.csv` である。各量は 2 初期値の平均で、Δ は値(K+1) − 値(K)。

## 1. 恒等式の数値確認（DERIVED を実装で確認）

- 各状態で、$C_Q-C_{\rm Lap}=2H(q_{\rm Lap})+\text{termA}+2R_3$ と $C_{\rm ELBO}-C_{\rm Lap}=2R_3$ の残差は、最大 7.3e−12 だった（両 Phase の全状態）。
- 両辺に同じ MC 推定値 $\mathbb E_q\Phi$ が入るので、これは代数的に厳密な一致である。MC 誤差を「考慮して一致した」のではない。
- **MC 誤差の扱い**
  - 個々の termA と R3 には、MC 誤差がある（C_ELBO の MCSE は、n=75 で約 1.6、n=150 で約 4〜5）。
  - しかし、termA + 2R3 の和では打ち消し合う（$\mathbb E_q\Phi$ が相殺する）。そのため、$C_Q-C_{\rm Lap}$ の分解の合計は MC 誤差を持たない。

- **余裕の差の大部分は、Laplace ガウスのエントロピーの増分 Δ2H に対応している**（数値上の分解で、因果の証明ではない）。

  - これは PR #163 の理想化（事後精度が $2\pi e$ を超えると、エントロピーの項の符号が変わる）と**向きが同じ**である。
  - ただし、$2\pi e$ を選択の成功条件としては扱わない。

## 3. 問い A：C_Q が K=4、C_Lap が K=5 のとき、差を生む主な項は何か

C_Q と C_Lap で選択が違った 12 データ（4→5 の組）：

| Pois 弱 150 r4 | 4/5/5 | −89.8 / 79.5 / 68.2 | 172.2 | −14.2 | 11.4 |

**答え（OBSERVED + DERIVED）**
- すべてのデータで、**Δ2H（54〜172）が、C_Q の余裕を負にした最大の項**だった。
- ΔtermA（−35〜+4）と Δ2R3（2〜19）は、Δ2H より小さかった。多くは Δ2H の 1 割程度だが、最大で 3 割程度だった（例：Gauss 強 75 r4 で −18.5 vs 54.0、Pois 弱 75 r4 で −35.2 vs 137.9）。ΔtermA はほとんど負で、Δ2H の一部を打ち消す方向に働いた。
- **Δ2H の内訳**：`scale_Z` のもとで Q_Z は定数なので、$\Delta2H(q_{\rm Lap})=\Delta P_Z-\Delta\log|H|$ である。ΔP_Z は、推定器の約束で決まる固定値（n=75 で 212.8）である。つまり、この最大の項の一部は、推定器の約束に組み込まれている。
- **数式上の意味**：$2H(q_{\rm Lap})=nK(1+\log2\pi)-\log|H|$。K=4→5 の増分は、$n(1+\log2\pi)$（n=75 で 212.8）から、5 次元目の事後精度の log 行列式の増分を引いたものである。
  - C_Q はこの項を含み、C_Lap は含まない。
  - その差が、余裕の差の大部分に対応した。

**限界**
- これは**数値上の分解**である。「C_Q が過小選択した原因は Δ2H である」という因果の主張ではない。
- C_Lap 自体も、6 データで過小選択した（下記）。

## 4. 問い B：C_Lap と C_ELBO の選択が違ったとき、R3 の K 間の差はどれだけ効いたか

- **選択が違ったデータはなかった（Phase C、27/27 で一致）。** したがって、この問いは「選択を変えるほどではなかった」が答えである。
- Δ2R3 は、4→5 で中央値 5.0（範囲 −1.9〜18.5）、5→6 で中央値 31.4（範囲 8.8〜76.6）だった。
- R3 の中央値は、K=1〜5 で 1.1〜8.4 だった。K=6 で 24.1、K=7 で 52.9 と、**真の次元を超えると急に大きくなった**。
  - 過剰な次元で、Φ の 2 次でない部分（Laplace の 2 次近似が捉えない部分）が大きくなることを示す（OBSERVED）。
  - PR #163 の仮説「過剰な次元で、事後分布が非ガウス・多峰になりやすい」と**向きが同じ**である。しかし、機構は確認していない。
- C_ELBO は、過大側（5→6）で C_Lap より 9〜77 だけ厳しかった。過大選択がもともとなかったので、選択は変わらなかった。

## 5. 問い C：条件付き尤度型の基準が過大選択するとき、どの K で当てはまりが増え続けているか

条件付き尤度型の余裕の中央値（`selection_margins.csv`）：

| 基準 | n | slack_45 | slack_56 | slack_67 |
|---|---|---:|---:|---:|
| cond_MC | 75 | 145.6 | 45.9 | 32.3 |
| cond_MC | 150 | 688.3 | 79.3 | 110.7 |
| cond_last | 75 | 133.9 | 42.4 | 31.7 |
| cond_last | 150 | 672.9 | 109.3 | 62.6 |
| cond_mode | 75 | 209.4 | 105.4 | 92.7 |
| cond_mode | 150 | 852.6 | 240.0 | 240.7 |

- **K=5→6 と K=6→7 でも、当てはまりの改善が罰則の増分（43.2・38.9（n=75）、50.1・45.1（n=150））を上回り続けた。** そのため、候補の上限 K=7 が選ばれた。
- **C_Q との差は $P_Z$ だけである**（$C_Q-C_{\rm cond,MC}=P_Z=2.838nK$。1 次元あたり 212.8（n=75）、425.7（n=150））。
- 上の表の slack は、罰則の増分を差し引いた**後**の値である（cond_MC で 32〜111）。差し引く前の当てはまりの改善（slack + ΔP_θ。cond_MC・cond_last）は約 71〜159 で、罰則の増分（約 39〜50）より大きく、$P_Z$ の増分（212.8・425.7）より小さかった。
- **n=150 では、slack_56・slack_67 の改善が n=75 より大きかった**（cond_mode で 240）。PR #163 の仮説（過剰な列が雑音に当てはまり、n とともに大きくなる）と向きは同じである。しかし、この実験は機構を識別しない（04 §4.4 の仮説は未確認）。
- cond_mode（Laplace のモードで評価）が最も強く過大に選ぶ。これは、事前分布で縮小されたモードでも、条件付き尤度 $\ell_{\rm cond}$ は K とともに増え続ける、ということを示す。

## 6. 問い D・E：信号と n による違い（Phase C の中央値）

| 量（4→5） | 75 弱 | 75 強 | 150 弱 | 150 強 |
|---|---|---|---|---|
| Δ2H（Gauss / Pois） | 94.4 / 120.6 | 40.3 / 84.7 | 75.8 / 98.6 | −20.8 / 11.5 |
| ΔlogdetH（Gauss / Pois） | 118.4 / 92.3 | 172.6 / 128.2 | 349.9 / 327.1 | 446.5 / 414.1 |
| slack_CLap（Gauss / Pois） | −16.4 / −21.6 | 56.7 / 32.0 | 234.3 / 215.5 | 551.4 / 614.1 |

- **信号を強めると**：4→5 の Δlog|H| が増え、Δ2H が小さくなった。C_Lap の余裕も増えた。
- **n を 75 から 150 にすると**：
  - Δlog|H| はおよそ 3 倍になった。$P_Z$ の増分も 2 倍（212.8→425.7）になるので、Δ2H は信号ほどは小さくならなかった（弱信号では 94→76、120→99）。
  - 一方で、当てはまりの改善が大きく増えた。そのため、どの基準でも余裕は大きく正になった。
- **5→6 の Δ2H は、n=150 で 2 倍程度に増えた**（235〜260）。過剰な次元の事後精度が低いままなので、$P_Z$ の増分（425.7）の大部分が残る。
- したがって、**C_Q の過大側の余裕は、n とともに大きく負になった**（約 −340）。

**限界**：信号の操作は F と w を同時に変える（多要因）。n ごとに別のデータセットである。4 データ/セルで、検定はしていない。
