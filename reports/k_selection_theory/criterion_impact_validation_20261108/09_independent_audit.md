## 1. 問題なしと確認された点（NOTE の要約）

- **基準の呼称**：条件付き尤度と周辺尤度の区別、B〜D が原論文の再現ではないこと、Poisson-X が指数型分布族への拡張であること。C_Q を Schwarz BIC と呼んでいない。
- **同じ状態**：全基準で、同じ θ・Z の標本・Z_last・マスク・family を使う。C_Lap・C_ELBO・C_cond_mode は同じ $\hat Z$ と H を使う。log 行列式の一致を assert している。
- **正規化定数**：Gaussian の $-\frac12\log2\pi s$、Poisson の $-\log x!$、事前分布の定数が、評価器の間で整合している。
  - id1・id2 の残差が小さいことは、termA と R3 の作り方から代数的に成り立つので、それだけでは定数の整合の証明にならない。整合は、コードの読み取りと `phi_point` のテストで確認した（05 §1 に既に記載）。
- **ELBO の数式**（行ごとに確認）
  - 事前分布の期待値
  - Gaussian-X の $f^\top\Sigma_{ii}f/s$
  - Poisson-X の対数正規の積率
  - $\mathbb E[z_i^\top z_j]$ の einsum
  - エントロピー
  - R3 の定義
  - Cholesky による抽出の向き（$\mathrm{Cov}=H^{-1}$）
  - KL の向き
- **項の分解**：slack と Δ の符号の約束が、プロトコルの PE2 と一致している。
- **MC の予算**：事前の規則どおり M=2048。`MC_UNCERTAIN` の式がプロトコルと一致している（Phase C で 1 件、Phase E で 0 件）。
- **INCOMPLETE**：補完・代替はない。NOT_STATIONARY は 5 + 2 状態。
- **seed チェックの修正（112 vs 448）**：正当。E2 の model seed は x_family と信号を引数に持たない（`run_fair_comparison.stage_fits` L253）。
- **数値の照合**：04〜07 の主要な数値（表・件数・余裕の中央値・項の分解の行）が、CSV と一致した。
- **系列の混在**：0.5 系列の値の混在はない。
