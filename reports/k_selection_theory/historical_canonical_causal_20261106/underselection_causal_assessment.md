# ④ 過小選択の原因：仮説ごとの評価（2026-11-06）

- **位置づけ**：系列 E（prototype）。**本文採用は未決定**。数値の出所は `historical_canonical_causal_20261106/analysis/`（`hypothesis_evidence.csv`、`paired_comparison_summary.csv`、`score_decomposition.csv`）と `existing_reanalysis/`。
- **記号**：K_GEN（生成器が使った次元）、K\*（最小表現次元。canonical Poisson-X では K\* = K_GEN の導出があるが canonical docs では未承認）、K0（一意な次元。Bernoulli-Y では未確認）、K̂（選ばれた次元）。本レポートの「正解」は K̂ = K\* = 5 を指す。
- **判定ラベル**：FACT／DERIVED／OBSERVED／SUPPORTED HYPOTHESIS（この条件で支持）／INCONCLUSIVE／REFUTED／UNRESOLVED。

## 0. まず確定していること（数学）

1. **DERIVED**：C_Q で K→K+1 が選ばれる条件は恒等式で `2ΔQ_X + 2ΔQ_Y > n(1+ln 2π) + (d−K) ln n` と書ける（レポート②）。n=75、d=15 の 4→5 では右辺は 212.8 + 47.5 = 260.3。
2. **DERIVED**：canonical 生成器は行ノルム² の**平均**を 0.5 に固定し、FᵀF = (0.5 d / K) I とする。したがって **K_GEN が大きいほど 1 方向あたりの X 信号は 1/K で弱くなる**（K=3：2.5、K=5：1.5）。Y 側も w² K = 3 を固定するので 1 方向あたり w² = 3/K で弱くなる（K=3：1.0、K=5：0.6）。これは「総信号量をそろえる」設計の帰結である。
3. **DERIVED**：Z 事前コスト n(1+ln 2π) は **K によらず 1 次元あたり一定**である。1 方向あたりの信号が 1/K で減る設計では、K が大きいほど「最後の次元」の利益がこの一定のコストに届きにくくなる。

## 2. 新しく分かったこと（この研究で初めて示したもの）

1. **OBSERVED**：4→5 の C_Q 適合改善を X と Y に分けると、既存の canonical 条件（d=15）では **X の改善 / n は n によらずほぼ一定（約 1.0〜1.3）**で、**Y の改善 / n だけが n とともに増えた**。過小選択が n=150 で解消したのは、Y の改善が増えたことと対応する。d を増やしたときは X の改善が増えた。
2. **OBSERVED（統制介入）**：同じ Z・同じ Y のまま F だけを強めると（B）、**Y の適合改善も増えた**（中央値 +18.8、8/8 で正）。Y のデータは同一なので、これは「X の情報が Z の推定を良くし、それが Y の当てはまりにも効く」ことを示す。**X と Y の寄与は独立に足し合わさる量ではない**。同様に C では X の改善はほぼ変わらなかった（中央値 −2.8（3/8 で正））。
3. **OBSERVED**：F と w を同時に強めると（D）、C_Q の slack の改善（中央値 +129.1）は B（+78.6）と C（+35.3）の和（+113.9）に近く、交互作用の中央値は +6.3（5/8 で正、符号は一定でない）。**n=75 では交互作用ははっきりしなかった**。
4. **OBSERVED**：それでも n=75 の D で C_Q は 3/8 しか K=5 を選ばない（slack の中央値 −12.6）。C_Lap は 7/8。**C_Q の過小選択は、方向あたりの信号を歴史的水準の一部まで上げても n=75 では解消しない**。

## 3. まだ言えないこと

- 「過小選択の統計的原因を特定した」：特定したのは、選択余裕の会計（恒等式）と、F・w を動かしたときの対応差である。未収束 MCEM の影響と有限標本の情報量は分離していない。
- 「F を強くすれば一般に K を選べる」：n=75（と n=150 の B）、K_GEN=5、d=15、8 データ、1 生成器での観察である。
- 「C_Lap は常に良い」：n=50 では両基準とも 0/8（既存）。
- 「K\* = K0」「一致性」：未証明。
