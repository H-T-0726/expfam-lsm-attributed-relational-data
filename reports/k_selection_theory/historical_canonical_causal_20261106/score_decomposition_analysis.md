# ② K 選択スコアの分解：次元追加の利益とコスト（2026-11-06）

- **位置づけ**：系列 E（prototype）。**本文採用は未決定**。C_Q（コード上 `calc_bic_dual`、CSV 列名 `BIC`）は Q-based complete-data / ICL 型の基準で、**Schwarz BIC ではない**（KI-010）。
- **数値の出所**：既存状態の再解析 `existing_reanalysis/`（`tools/research_audit/analyze_k_causal_existing.py`、MCEM 0 件、1,008 状態）と本実験 `analysis/score_decomposition.csv`。
- **記号**：ΔQ_• = Q_•(K+1) − Q_•(K)。「X 改善」= 2ΔQ_X、「Y 改善」= 2ΔQ_Y、「Z 事前コスト」= −2ΔQ_Z、「罰則」= Δp_K ln n。値はすべて 2 start の平均の差（選択規則と同じ平均）。

## 1. C_Q の分解（DERIVED、実装で確認）

実装（`k_criterion_panel.cq_terms`、`eval_utils.calc_Q_dual_strict_exp`）では

```
C_Q(K) = −2 Q_MC(K) + p_K ln n,     p_K = K d − K(K−1)/2   （Poisson-X / Bernoulli-Y では Σ_X・σ_Y の自由度なし）
Q_MC   = Q_X + Q_Y + Q_Z
Q_X = (1/L) Σ_l Σ_{i,l'} [ x_il' η_il' − e^{η_il'} − ln x_il'! ],           η = z_i^(l)ᵀ f_l'
Q_Y = (1/L) Σ_l Σ_{i<j, (i,j)∈train} [ y_ij η_ij − ln(1 + e^{η_ij}) ],       η_ij = w0 + w z_i^(l)ᵀ z_j^(l)
Q_Z = (1/L) Σ_l ln N(Z^(l); 0, var_z I)
```

である。Q_X・Q_Y・Q_Z は保存された E-step 標本 Z^(1..L) と θ̂ だけで決まり、再推定なしに計算できる。

### 1.1 P_Z = n K (1 + ln 2π) が成り立つ範囲（DERIVED）

`scale_Z` は (n, K, L) の全要素について z² の平均を 1 にする**大域的な**スケール変換である（`reproduction/src/model.py:468-`）。したがって

```
(1/L) Σ_l Σ_{i,k} (z_ik^(l))² = n K            （scale_Z の定義から厳密）
−2 Q_Z = n K ln(2π var_z) + n K / var_z
```

が成り立ち、var_z = 1 なら P_Z = −2Q_Z = nK(1 + ln 2π)（1 次元あたり n × 2.8379）。

成立条件は次の 3 つで、**どれかが欠けると成り立たない**。

1. Q を、scale_Z を適用した**同じ L 標本**で評価する（Laplace の q_Lap からの draw や Ẑ 1 点で評価する量には当てはまらない）。
2. 事前分布 N(0, var_z I) を、正規化定数込みで Q に含める。
3. var_z = 1（系列 E では固定。全保存状態で var_z_hat = 1.0 を確認）。var_z ≠ 1 なら上の一般形になる。

数値確認（FACT）：既存の 1,008 状態と本実験の全状態で |P_Z − nK(1+ln 2π)| ≤ 5×10⁻¹³。
歴史的系列（0.5・fixed）の Q_strict も ln p(Z) を定数込みで含み、scale_Z の後で評価している（`expfam/src/utils_expfam.py:315-385, 209, 514`）。したがって同じ形の P_Z を含むが、保存状態がないため数値では確認していない。

### 1.2 1 次元追加の選択余裕（DERIVED、恒等式）

```
S_Q(K→K+1) = C_Q(K) − C_Q(K+1)
           = [ 2ΔQ_X + 2ΔQ_Y ]  −  n(1 + ln 2π)  −  (d − K) ln n
             (データ適合改善)      (Z 事前コスト)    (パラメータ罰則; Δp_K = d − K)
```

ΔQ_• = Q_•(K+1) − Q_•(K) で、選択規則に合わせて 2 start の平均をとる。S_Q > 0 なら K+1 が有利。数値の閉包誤差は既存状態で 8×10⁻¹²。

- K=4→5、d=15 の罰則：n=75 で 11 ln 75 = 47.5、n=150 で 55.1。Z 事前コストは n=75 で 212.8、n=150 で 425.7。**コストの 8 割は Z 事前コストである。**
- これは定義の書き換えであり、「適合改善が小さい」理由は別に調べる必要がある（§2 以降）。

## 2. C_Lap との関係（DERIVED、恒等式と近似の区別）

```
C_Lap = −2 ℓ_Lap + p_K ln n,    ℓ_Lap = Φ(Ẑ) + (nK/2) ln 2π − ½ ln|H|,   Φ = ln p(X, Y, Z | θ̂)
C_Lap = fit_mode + volume + P_θ
  fit_mode = −2 [ℓ_X + ℓ_Y](Ẑ),   volume = ‖Ẑ‖²/var_z + nK ln var_z + ln|H|
2H_Lap := nK(1 + ln 2π) − ln|H|                  （q_Lap = N(Ẑ, H⁻¹) のエントロピーの 2 倍）
C_Q − C_Lap − 2H_Lap = termA + 2R3               （恒等式）
  termA = −2 (Q_MC − Q(q_Lap)),   R3 = ℓ_Lap − Q(q_Lap) − H_Lap
```

最後の式は termA と R3 の定義を代入すれば両辺が −2Q_MC + 2ℓ_Lap − 2H_Lap になる、**代数的な恒等式**である（独立に確認、符号も一致）。内容があるのは「残差 termA + 2R3 が小さいかどうか」で、これは近似の問題であり保証はない。

K→K+1 の差をとると

```
slack_Lap − slack_Q = 2ΔH_Lap + Δresid,     2ΔH_Lap = n(1 + ln 2π) − Δ ln|H|
```

すなわち C_Lap は、C_Q の Z 事前コスト n(1+ln 2π) を「事後分布の鋭さ」Δ ln|H| で割り引いた基準である。Δ ln|H| / n が 2.84 に近づくほど（事後が鋭いほど）2 基準は近づく。

## 3. 信号強度と Fisher 情報（DERIVED、真値での期待値。選択の定理ではない）

真の θ における、ノード i の潜在位置 z_i に関する条件付き Fisher 情報は

```
J_i^X = Σ_l λ_il f_l f_lᵀ,   E[J_i^X] = Σ_l e^{‖f_l‖²/2} f_l f_lᵀ          （Poisson-X、E e^{fᵀz} = e^{‖f‖²/2}）
J_i^Y = w² Σ_{j: (i,j)∈train} p_ij (1 − p_ij) z_j z_jᵀ                       （Bernoulli-Y）
```

- X 側：行ノルム² がほぼ一定 r のとき E[J^X] ≈ e^{r/2} FᵀF。canonical（r̄=0.5、FᵀF = 1.5 I）では 1 方向あたり約 e^{0.25}·1.5 ≈ 1.9、F-strong（r̄=0.9、FᵀF = 2.7 I）では約 e^{0.45}·2.7 ≈ 4.2（約 2.2 倍）。**n によらない**（ノードあたり d 個の観測）。
- Y 側：1 方向あたりおよそ w² · (0.8 n) · E[p(1−p)]。**n に比例して増える**。w を大きくすると w² は増えるが、飽和により E[p(1−p)] は下がる（canonical A：0.155、w-strong C：0.132）。w²·E[p(1−p)] の比は 1.08·0.132 / (0.6·0.155) ≈ 1.53。
- 歴史的 Scenario A（K=3）：FᵀF の固有値の平均 6.4 / 4.4 / 2.7、w² = 2.25、E[p(1−p)] = 0.131。

INTERPRETATION：「X の適合改善 / n は d で決まり n によらない」「Y の適合改善 / n は n とともに増える」という既存状態の観察（§4）は、この Fisher 情報の n 依存と整合する。ただし Fisher 情報は**真値での局所的な量**で、未収束の MCEM が得る適合改善との対応は定理ではない。

- **コスト側は条件によらず同じ**（Z 事前コストと罰則は n・d・K だけで決まる。恒等式）。条件による違いはすべて**適合改善の側**に現れた。
- F を強めると X 改善だけでなく Y 改善も増えた（同じ Y データ）。w を強めると Y 改善だけが増えた。
- 信号を強めると 2ΔH_Lap（C_Q と C_Lap の差の主要部分）が減った。事後分布が鋭くなり、C_Lap の「割引」が Z 事前コストに近づくためである（§2）。

## 6. 「K=5 を選べない」ときの直接のスコア上の理由（Q4 への答え）

n=75・d=15 の baseline では、**4→5 で X と Y の当てはまりが合計 134（X 73 + Y 61）しか改善せず、それが Z 事前コスト 212.8 と罰則 47.5 の合計 260.3 を 126 下回った**。C_Lap では Z 事前コストの代わりに体積項の増分（中央値 162.6）を払うので、余裕は −11.3 まで縮まり、3/8 で K=5 を選んだ。これは恒等式で正確に書ける**会計**であり、「改善が小さい統計的理由」は §3（Fisher 情報）と統制実験（レポート③）で部分的に説明したにとどまる。
