## 1. 明らかになったこと

### 数学（DERIVED、数値で確認）

1. C_Q（コード上 `calc_bic_dual`、CSV 列 `BIC`）の 1 次元追加の選択余裕は、恒等式
   `S_Q = 2ΔQ_X + 2ΔQ_Y − n(1+ln 2π) − (d−K) ln n`
   に分解できる。Z 事前コスト n(1+ln 2π) は、var_z=1・scale_Z 後の同じ L 標本で Q を評価する場合に**厳密**に成り立つ（誤差 ≤ 5×10⁻¹³）。C_Q は Schwarz BIC ではない（KI-010）。
2. `slack_Lap − slack_Q = 2ΔH_Lap + Δresid` は代数的な恒等式である。中身があるのは残差が小さいかどうかで、これは近似の問題である。
3. canonical 生成器は総信号をそろえる設計（FᵀF = 0.5d/K·I、w²K = 3）なので、1 方向あたりの信号は 1/K で減る。一方、Z 事前コストは 1 次元あたり一定である。

### 実験（OBSERVED、系列 E、8 データ、未収束 MCEM）

4. 既存の canonical 状態（MCEM 0 件の再解析、1,008 状態）では、4→5 の X の適合改善 / n は n によらずほぼ一定で、Y の適合改善 / n が n とともに増えた。
5. 同じ Z・Y のまま F だけを強めると、C_Q の 4→5 slack は 8/8 のデータで増えた（n=75、中央値 +78.6）。Y の適合改善も増えた（X と Y の寄与は分離できない）。
6. w だけを強めても slack は増えたが（7/8、+35.3）、F より小さかった。
7. 両方を強めても、n=75 で C_Q が K=5 を選んだのは 3/8 だった。C_Lap は 7/8。
8. C_Q と C_Lap の差の大部分は 2ΔH_Lap で、信号を強めると小さくなった（A 120.6 → D 73.1）。
9. n=150 でも F を強めると C_Q の 4→5 slack は 8/8 で増えた（中央値 +211.1）。n=150 の baseline はすでに C_Q 7/8 で、F-strong では 8/8 になった。

## 2. 既存研究との関係

- Mikawa et al. (2024) の印刷式には 1/2 があり、本研究の採用式（1/2 なし）とは意図的に異なる（KI-001）。原論文の K 選択実験（Experiment 2）は Gaussian-X の paper-type 生成器で、本研究の #139 B も**その再現ではない**。
- ICL と BIC の関係（小さいほど良い形で ICL ≈ BIC + 2 × 事後エントロピー）は Biernacki et al. (2000) 以来知られている。本研究の新規性はその一般論ではなく、**このモデルで「どの項が・どの条件で」選択を決めているかを数値で分解したこと**、および**同じデータ上の信号強度介入で余裕の変化を対応比較したこと**である。

## 3. 一般化の限界

| 限界 | 内容 |
|---|---|
| 推定 | MCEM は未収束（8 反復）。局所解・初期値の影響は 2 start の範囲でしか見ていない |
| 標本 | 各条件 8 データ。n=150 の C・D と、方向あたりの信号を正確にそろえた K=3 対照は未実施（上限 480 fit のため事前に除外） |
| モデル | X=Poisson、Y=Bernoulli、d=15、K_GEN=5（比較用に既存の K_GEN=3）。Gaussian-X・Poisson-Y・混合 X では未検証 |
| 理論 | K < K\* での漸近的な KL ギャップ、Bernoulli-Y での K0 の一意性、一致性はいずれも未証明 |
| 基準 | C_Lap は周辺尤度のラプラス近似で、厳密値との差は未検証（Phase 9J の重点サンプリングは重みが退化） |
| 歴史的比較 | 歴史的条件を canonical モデル上で再現した対照は作っていない。差の一部（K=3、n=150、Z 正規化、マスクなし、単一 start、0.5 系列）は未分離 |
