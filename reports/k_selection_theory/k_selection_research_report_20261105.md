## 2. 従来基準の問題

### 2.1 C_Q は Schwarz BIC ではない（FACT / DERIVED。KI-010）

```
C_Q(K) = −2 Q_strict(K) + p_K ln n  =  D_K + P_Z + P_θ
```

- **Q_strict**：E-step で得た L 個の MC サンプル（scale_Z 後）で平均した、**完全データ**の対数尤度。
- **D_K**：Q_strict のうち X と Y の当てはまりの部分。
- **P_Z = nK(1 + ln 2π)**：Z の事前分布 ln p(Z) の項から生じる、K に比例する量。
  - Z の事前分布は N(0, I) である。scale_Z の後では、サンプル平均した ‖z‖² が 1 次元あたり 1 になる。そのため、この項はほぼ定数になる。
  - n=75 では、1 次元を加えると P_Z は 212.8 増える。
- **P_θ = p_K ln n**：パラメータ数の罰則。p_K = Kd − K(K−1)/2（回転の不定性の分を差し引いた F の自由度）。
  - ほかに、K によらない w0, w がある。

Schwarz BIC は、**観測データの周辺尤度** ln p(X, Y | θ̂) に基づく。

C_Q は、潜在変数 Z を「観測されたかのように」扱う**完全データ型（ICL 型）**の基準である。

ICL と BIC の関係（ICL ≈ BIC + 2 × 事後エントロピー）は、Biernacki et al. (2000) 以来知られている。**この関係自体は本研究の新規性ではない。**

### 2.2 C_Q の選択規則の書き換え（DERIVED、1 ノードあたりの形）

K=4→5 の slack を `slack_Q = C_Q(4) − C_Q(5)` と定義する。正なら K=5 が選ばれる方向である。

```
slack_Q = （D の改善）− ΔP_Z − ΔP_θ
slack_Q / n = （当てはまり改善 / n）− (1 + ln 2π) − ΔP_θ / n
```

つまり C_Q で 1 次元を追加するには、**1 ノードあたりの当てはまり改善**が次の「入場料」を上回る必要がある。

- **2.84 = 1 + ln 2π**：n にも d にもよらない定数。
- **ΔP_θ / n**：d の増加とともに大きくなり、n の増加とともに小さくなる。

入場料の大部分は P_Z（定数 2.84）である。これは、C_Q が完全データ型であることから生じる量である。

**注意**：
- これは C_Q の定義を書き換えた**恒等式**である。「当てはまり改善が入場料より小さいと K=5 は選ばれない」ことは、定義からいえる。
- 一方、**なぜ当てはまり改善が小さいのか**（有限標本での情報量、推定誤差、MC 誤差のどれによるのか）は、この式からは分からない。統計的な原因として特定したものではない。
- また「当てはまり改善」には、MCEM の推定誤差と MC 誤差が含まれる。

## 5. 数式から分かること

### 5.1 C_Lap の構造（DERIVED）

```
C_Lap(K) = −2 ℓ_Lap + p_K ln n
ℓ_Lap    = Φ(Ẑ) + (nK/2) ln 2π − ½ ln|H|
```

- **Ẑ**：Z の同時事後モード。
- **H**：nK×nK の同時負 Hessian（X・Y・事前分布の曲率をすべて含む）。
- −2ℓ_Lap は、次の 2 つに分けられる。
  - **当てはまり**（fit_mode）
  - **volume** = ‖Ẑ‖² + ln|H| −（定数）

C_Lap は観測データの周辺尤度のラプラス近似であり、**厳密な周辺尤度ではない**。Phase 9J では、重点サンプリングによる厳密値の検証は重みが退化して失敗している。

### 5.2 事後エントロピーとの関係：恒等式と近似を区別する（DERIVED）

θ を固定すると、任意の q について、次の変分恒等式が成り立つ。

```
ln p(X,Y|θ) = E_q ln p(X,Y,Z|θ) + H(q) + KL(q ‖ p(Z|X,Y,θ))
```

q_Lap = N(Ẑ, H⁻¹) とおき、H_Lap = (nK/2)(1 + ln 2π) − ½ ln|H| とする。すると、次が**代数的に厳密に**成り立つ。

```
C_Q − C_Lap − 2H_Lap = termA + 2R3
  termA = −2 (Q_MC − Q(q_Lap))         … E-step の L 個のサンプルと q_Lap の違い、および MC 誤差
  R3    = Φ(Ẑ) − nK/2 − E_{q_Lap} Φ     … Φ が Z について 2 次式でない部分
```

- この恒等式は、全 fit で閉包誤差 10⁻¹¹ 以下であることを数値で確認した。
- 一方、**C_Q − C_Lap ≈ 2H_Lap は近似である。**
  - 残差 termA + 2R3 は、K とともに大きくなる 2 つの項がほぼ打ち消し合った結果である。termA は負で、K=7 では条件により −46〜−113。R3 は正である。
  - 打ち消し合いを保証する理論はない。

### 5.3 slack の分解（DERIVED、恒等式）

```
slack_Q = slack_Lap − 2ΔH_Lap − Δ残差
2ΔH_Lap = n(1 + ln 2π) − Δln|H|
2ΔH_Lap / n = 2.84 − Δln|H| / n
```

ここから次のことが分かる。

- 恒等式から、K → K+1 の組について、**slack_Q < slack_Lap（C_Q のほうが K+1 を選びにくい）となるのは 2ΔH_Lap + Δ残差 > 0 のときであり、そのときに限る。** 2ΔH_Lap > 0 は Δln|H| / n < 2.84 と同値である。ただし、残差の項があるため、2ΔH_Lap > 0 だけでは十分ではない。この条件が常に成り立つことは、理論的には保証されていない。
- 実際の比較（OBSERVED。d-sweep・R1・R2 の fit。start 2 つの平均。Laplace が OK の組だけ）：

  | 比較した候補 K の組 | slack_Q < slack_Lap となった件数 |
  |---|---|
  | 4→5 | 127/127（L=5・16 反復の補助条件を含む。2ΔH_Lap の最小値は 15.1） |
  | 5→6、6→7 | 120/120 |
  | 3→4 | 118/119 |
  | 2→3 | 111/119 |
  | 1→2 | 104/120 |

  - 例外は、K の小さい組でだけ起きた。原因は 2 つあった。
    - 2ΔH_Lap ≤ 0 になった場合（最初の数次元は事後分布が鋭く決まり、Δln|H| / n が 2.84 を超える）。
    - 2ΔH_Lap は正だったが、残差の差がそれを上回った場合。
  - 選ばれた K の比較では、両方の基準が完了した延べ 126 件のすべてで K̂_Q ≤ K̂_Lap だった。そのうち 53 件は K̂_Q < K̂_Lap だった。
  - したがって、「C_Q は C_Lap より厳しい」と書けるのは、**今回の条件のうち K=4 以上の組と、選ばれた K については**という限定付きである。
- 事後分布が鋭くなる（情報が増える）と Δln|H| / n が大きくなり、2 つの基準は近づく。
  - d を増やすと、主に事前分布＋X の部分が増えた（d-sweep）。
  - n を増やすと、主に Y の部分が増えた（R2）。
- 実験で観察したこと（OBSERVED）：
  - 2ΔH_Lap は、slack_Q と slack_Lap の差の大部分を占めた。残差の差の絶対値の中央値は 2〜15 だった。
  - 残差を除いたときに C_Q の選択が変わったのは、延べ 126 件のうち 4 件だった。そのうち 3 件は、選択余裕が 2.0 以下だった。
  - **つまり残差は小さいが、境界付近では順位を変えうる大きさである。**

### 5.4 「真の K」の扱い

| 記号 | 意味 |
|---|---|
| K_GEN | 生成器が使った次元 |
| 𝒦(P\*) | {K : ある θ_K で P\* を表現できる} |
| K\* | min 𝒦(P\*)（最小表現次元） |
| K0 | 𝒦(P\*) = {K0} となる場合の一意な次元 |
| K̂ | 有限標本で選ばれた次元 |

**DERIVED**（独立レビューで誤りは見つからなかったが、canonical docs では未承認）：

canonical Poisson-X（バイアスなし、clip なし、rank F = K_GEN、d ≥ K_GEN）では、K\* = K_GEN である。理由は次のとおり。

- E X_l = exp(‖f_l‖²/2)、E[X_l X_m] = exp(‖f_l + f_m‖²/2)（l ≠ m）である。
- そのため、FFᵀ は 1 ノード分の X の分布で決まる。
- したがって、P\* ∈ M_K ならば K ≥ rank F\* = K_GEN である。この議論は Y や w によらない。

限定：

- **rate 上限ゲートの扱い**：生成時の rate 上限ゲートで条件付けた分布は、厳密にはどの M_K にも入らない。
  - そこで K\* は、条件付けない canonical 分布について定義する。
  - 両者の差は、ゲートに掛かる確率の上界（union bound）で抑える。
  - 今回のデータセットでは、その値は最大でも 7.7×10⁻³³ だった（R1/R2 の data_provenance.csv。d-sweep 単独では 1.77×10⁻³³）。
- **KL ギャップ**：K < K\* で漸近的に負けることは、未証明である。
- **K0 の一意性**（K > K\* を排除できること）は、**Bernoulli-Y では未確認**である。証明案は別途提示されているが、**まだ検証中**であり、本報告では成立したものとして扱わない。`KNOWN_ISSUES.md` の制限と Human Gate は維持する。
  - M_K と M_{K+1} は w=0 の部分で交わる。そのため、「互いに素なモデル」とは書かない。
- **実験の読み方**：本研究の実験は、すべて「K\* = 5 を目標とする限定的な評価」として読む。
- **KNOWN_ISSUES.md の制限**：「K_TRUE = K\* と一般に主張しない」という制限は解除していない。
- **原論文型の生成器 B**：X を標本で標準化しているので、P\* はどの M_K にも入らず、K\* は定義されない。B は K_GEN の回復としてだけ扱う。

### 5.5 Gaussian-X の閾値は一般のモデルに移せない（DERIVED）

次の特殊な場合を考える。
- Gaussian-X だけを使う。
- Y は Z に依存しない。
- 事後分布は厳密に Gaussian で、Σ は既知である。

このとき、白色化した信号の固有値を λ とすると、次の 2 つの点が出てくる。
- **λ > 2.84**：C_Q がその次元を採用する条件。
- **1 + λ = 2πe**：エントロピー項の符号が変わる点。**選択の閾値ではない。**

Poisson-X / Bernoulli-Y では、この閾値は定理として成り立たない。実際、d=60 では Δln|H| / n = 2.23 < 2.84 だったが、C_Q は 5/8 で正解した。

## 6. 研究として明らかになったこと

### 確定した事実・導出（FACT / DERIVED）

1. C_Q は完全データ型（ICL 型）の基準で、Schwarz BIC ではない。1 次元を加えるには、1 ノードあたり 2.84 + ΔP_θ/n の入場料が必要である。
2. C_Q − C_Lap − 2H_Lap = termA + 2R3 は恒等式である（数値で 10⁻¹¹ 以下を確認）。slack の分解も恒等式である。
3. canonical Poisson-X では K\* = K_GEN である（導出。canonical docs では未承認）。

### 限定付きの結論（OBSERVED。n ≤ 150、d ≤ 60、8 データセット、系列 E、未収束の MCEM）

4. **C_Q の入場料（2.84 + ΔP_θ/n）は d と n でほぼ決まる値をとった。過小選択から正解への変化に対応して動いたのは、主に「1 ノードあたりの当てはまり改善」の側だった。**
   - 過小選択が解消したのは、d を増やしたとき（n=75、d=60）と、n を増やしたとき（d=15 で n=150、d=30 で n≥100）である。どちらの場合も、当てはまり改善の中央値が入場料を超えていた。
   - 選ばれるかどうかが大小関係で決まること自体は、恒等式からいえる（§2.2）。**当てはまり改善が小さい統計的な原因**（情報量、推定誤差、MC 誤差）は分離していない。
5. **C_Q と C_Lap の slack の差は 2ΔH_Lap + Δ残差 である。** 今回の条件の K=4 以上の組では、この値は全件で正だった（C_Q のほうが厳しい）。K の小さい組では例外があった（§5.3）。
   - 例：n=100 では、C_Lap は d=15 と d=30 のどちらでも 8/8 だった。C_Q は 1/8 と 4/8 だった。
   - 4→5 の 2ΔH_Lap / n の中央値は、事後分布が鋭くなるにつれて小さくなった。
6. この傾向は、検証した L（5・10）と反復数（8〜40）の範囲で保たれた。
7. d-sweep・R1・R2 のすべての条件で、過大選択は C_Q でも C_Lap でも 0 件だった。

### 仮説（HYPOTHESIS）

8. n とともに 2ΔH_Lap / n が小さくなるのは、Y 由来の事後曲率がノードあたりで増えるためである。
   - 分割の上では整合する。しかし、推定誤差やデータセットの違いと分離できていない。

## 10. 解説（初学者向け）

### 10.1 何を選んでいるのか

各ノード i には、見えない K 次元の位置 z_i がある。
- 関係 y_ij：「位置の内積が大きいほどつながりやすい」として生成される。
- 属性 x_il：「位置と属性ごとの方向 f_l の内積」で強さが決まる。

K は、位置を何次元で表すかである。
- K が小さすぎる：データの構造を表しきれない。
- K が大きすぎる：無駄なパラメータでノイズに合わせてしまう。

モデル選択の基準は、「当てはまりの良さ − 複雑さの罰則」の形で、この 2 つのバランスをとる。

### 10.2 C_Q はなぜ厳しいのか

C_Q は、E-step で推定した位置 Z を「観測されたかのように」扱って尤度を計算する。そのため、尤度に**位置そのものの事前確率** ln p(Z) が含まれる。

1 次元を加えると、各ノードの位置の座標が 1 つ増える。すると、−2 ln p(Z) は 1 ノードあたり約 1 + ln 2π ≈ 2.84 ずつ大きくなる。

これは「パラメータの数え方」とは別の、**潜在変数の数に比例する罰則**である。n=75 なら、1 次元あたり 213 になる。これは、F の自由度の罰則（d=15 で 47）よりずっと大きい。

だから C_Q は、新しい次元が 1 ノードあたり 2.84（＋パラメータ罰則の分）を超える当てはまり改善を生まない限り、その次元を採用しない。これは C_Q の定義から出てくる性質である。なぜ当てはまり改善が小さくなるのかは、別の問題である。

### 10.3 C_Lap は何が違うのか

C_Lap は位置 Z を**積分して消す**（周辺化する）。ラプラス近似で積分すると、罰則は ln p(Z) ではなく次の量になる。

```
‖Ẑ‖² + ln|H|   （「事後分布がどれだけ鋭いか」の量）
```

ここで ln|H| は、データが位置をどれだけ精度よく決めるかを表す。今回の実験では、K=4 以上で次元を 1 つ加えるときは常に、C_Lap のほうが C_Q より次元を加えやすかった。ただし、最初の数次元（K の小さい組）では逆になる例もあった。

2 つの基準の差は、ちょうど**事後分布のエントロピーの 2 倍**（2H_Lap）に、小さな残差を加えたものになる。これが恒等式 `C_Q − C_Lap − 2H_Lap = termA + 2R3` の意味である。

### 10.4 実験で何をしたのか

**d-sweep**
- 同じ位置 Z・同じ関係 Y のまま、属性の列だけを 15→30→60 と増やした。
- 属性が増えると、1 ノードあたりの当てはまり改善が大きくなる。
- その結果、C_Q でも正しい K=5 が選ばれるようになった。

**R1**
- MC サンプル数を 5→10、EM の反復数を 8→16 に増やしても、この傾向は変わらなかった。

**R2**
- 属性の数を固定してノード数を 50→150 と増やした。
- 1 ノードあたりの当てはまり改善が大きくなり、C_Q の過小選択が解消した。関係のペアの数が n² に比例して増えることと整合する。
- ただし、n を変えるとほかの要因（推定誤差、データセット）も同時に変わる。そのため、「関係データの情報が増えたから」とは断定していない。

### 10.5 一言でまとめると

**C_Q で次元を 1 つ増やすには、「潜在変数の事前分布から来る、1 ノードあたり約 2.84 の入場料」を、当てはまりの改善が上回る必要がある（定義からいえること）。**

今回の小さいデータでは、当てはまりの改善が入場料に届かず、過小選択になった。属性を増やすかノードを増やして当てはまりの改善が大きくなると、過小選択は解消した（観察）。当てはまりの改善が小さい統計的な原因は、まだ分離していない。

周辺化した基準 C_Lap と C_Q の差は、事後エントロピー 2H_Lap と小さな残差の和である。今回の K=4 以上の組では、この差によって C_Lap のほうが次元を加えやすかった。
