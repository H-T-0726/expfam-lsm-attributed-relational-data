# 07 指導教員向け要約：原論文型の尤度でも過小選択は起きるのか（2026-11-06）

新しい推定は行わず、保存してある推定結果（約 3,900 個）を 5 つの基準で採点し直した。系列 E は prototype（本文採用は未決定）。C_Q は Schwarz BIC ではなく、C_Lap は厳密な周辺尤度ではない。

## 結論

**原論文型の条件付き尤度（p(Z) を含まない）を使うと、過小選択は起きない。その代わり、ほぼすべての条件で過大選択（K を大きく選びすぎる）が起きる。** 過小選択は、現在の C_Q に含まれる p(Z) の項（Q_Z）による、C_Q 特有の現象である。ただし Q_Z を外せば正しく選べるわけではない。

## 分かったこと

1. **Q_Z は定数の罰則として働いている。** 現在の正規化では −2Q_Z = nK(1 + ln 2π) が全推定結果で厳密に成り立ち（誤差 1e−12）、1 次元増やすごとに 2.84 n の罰則が追加される（n=75 で 212.8）。
2. **基準条件（n=75、K_GEN=5）では、C_Q の K=4→5 の差（中央値 −128.7）は、Q_Z を除くと +84.2 になる。** 予測どおりで、どのデータでも 212.8 ずつずれた。
3. **しかし Q_Z を除くと、5→6、6→7 も「大きい K のほうが良い」になり、8 データすべてで K=6 か 7 が選ばれる。** 原論文型の plug-in（最後の標本で評価、Laplace のモードで評価）も同じだった。
4. **過大選択は、簡単な条件でも起きる。** K_GEN=1 や 3、n=150、そして C_Q が 25/25 で正解した論文型（Gaussian-X）のデータでも、Q_Z を除いた基準と plug-in の基準は全件で過大選択した。
5. **C_Lap は過大選択を一度もしなかった。** 過小選択は n ≤ 75 に残る（n=75 で 3/8 正解、n=100・150 で 8/8 正解）。
6. **データ数 n が増えるほど、原論文型の基準は過大選択に傾く。** Z の値（n × K 個）を当てはめているのに、罰則がその分を数えないためである。C_Q の Q_Z は、たまたま n に比例する罰則としてこれを抑えていた。

## 修士論文での説明の仕方（案）

- 原論文 Eq.(26) の ln L は Z を固定した条件付き尤度で、現在の C_Q は p(Z) を含む Q 関数を使う。この違いは、本研究の正規化では「1 次元あたり 2.84 n の追加罰則があるかないか」になる。
- 既存の推定結果で確かめると、原論文型は過大選択、C_Q は n が小さいと過小選択、C_Lap はその中間で過大選択がない。**どの基準も観測データの周辺尤度に基づく標準的な BIC ではなく、結果は基準の選び方に強く依存する。**
- 原論文の Fig. 3 で正しい次元が選べた理由は、まだ説明できない（原論文の計算方法が特定できないため）。

## まだ言えないこと

- 原論文 Fig. 3 の基準の正体。
- 長い推定・厳密な事後分布で評価した場合も同じになるか（今回の状態は 8〜64 反復、近似的な E-step）。
- C_Lap に残る過小選択が、近似の偏りによるものか、情報量の不足によるものか。
