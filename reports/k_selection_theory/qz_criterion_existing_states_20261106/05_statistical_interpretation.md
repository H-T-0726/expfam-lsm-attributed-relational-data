# 05 統計的な解釈（2026-11-06）

系列 E（prototype）。結果は既存の推定状態の再採点だけによる。C_Q は Schwarz BIC ではなく、C_Lap は厳密な周辺尤度ではない。B〜D は原論文の BIC ではない。

## 1. 観測の要約（OBSERVED）

- Q_Z は全状態で厳密に −nK(1 + ln 2π)/2 の定数で、C_Q の中では 1 次元あたり 2.84 n の追加罰則になっている（03）。
- Q_Z を除いた B と、Eq.(16) 型の plug-in（C：最後の標本、D：結合モード）は、canonical でも paper-type でも**系統的に過大選択**する。K_GEN=1, 3 の簡単な条件、C_Q が 25/25 で正解した paper-type 条件、n=150 の条件でも全件が過大選択だった（04）。
- ただし B が多数で正解する条件もある：d=30・n=50（8/8）、d=60・n=75（d-sweep と R1 の 8・16 反復で各 8/8）。いずれも 1 次元あたりの当てはまりの改善が小さい側で、同じ d=30 でも n が増えると過大選択に変わる。D も d=60 では 7/8〜8/8 が正解。
- C_Lap は過大選択を一度もしない。過小選択は n ≤ 75 に残る。

## 2. なぜ Q1 型は過大選択するか（INTERPRETATION / HYPOTHESIS。厳密な証明ではない）

- Q1(Z) = ln p(X, Y | Z, θ) は、Z を n × K 個の自由な値として当てはめた尤度である。K を 1 増やすと、当てはめられる値が n 個増える。罰則 p_K ln n は θ（F など）だけを数え、この n 個を数えない。
- K が真の値を超えても、新しい列 z_{·,K+1} は X・Y のノイズに当てはまり、当てはまりの改善は概ね n に比例すると考えられる（自由度 n 個のノイズへの当てはめ）。ただし B・C は Q1 を最大化した Z ではなく事後標本で、D は Q2 の結合モードで評価しているので、この議論は発見的なものにとどまる。一方、罰則の増分は (d − K) ln n で n に対してゆっくりしか増えない。**したがって n が大きいほど Q1 型の基準は過大選択に傾き、一致性を持たないと予想される**（HYPOTHESIS。観測と整合：B の過大選択は n=50 で 5/8、n ≥ 75 で 8/8。ただし 3 つの n × 8 データ、短い MCEM の状態だけの観測）。
- C_Q の Q_Z（1 次元 2.84 n）は、この n 個の潜在座標に対する「入場料」として、たまたま n に比例する罰則になっている。ICL 型の基準が過大選択しにくい理由はこれだと考えられる（INTERPRETATION）。ただし入場料の大きさは `scale_Z` と σ_z² = 1 の固定から機械的に決まる定数で、真の K の識別に必要な大きさから導かれたものではない。canonical の n=75 では入場料（212.8）が真の次元の当てはまりの改善を上回り、過小選択になる。
- C_Lap（Q3 のラプラス近似）は、Z を積分する代わりに事後分布の体積（−½ ln|H| と ‖Ẑ‖²）を引く。不要な次元では事後分布が事前分布とほぼ同じになり、体積の項がその次元の当てはまりの改善をほぼ打ち消す。そのため過大選択しにくい。ただし Laplace 近似の精度（特に Y の結合と n が小さい場合）は保証されていない。

## 3. 研究上の問いへの答え

**Q1. C_Q の過小選択のどれだけが Q_Z で説明できるか。**
canonical n=75 の 4→5 の余裕 −128.7 のうち、Q_Z の寄与は −212.8 で、Q_Z がなければ余裕は +84.2 になる。この意味で、**4→5 の局所的な余裕の符号を負にしているのは Q_Z の項である**（数値は OBSERVED、代数的に厳密。「原因」という解釈は INTERPRETATION：同じ余裕には罰則の増分 47.5 も入っている）。ただし、Q_Z を除くと 5→6・6→7 も正になり、K̂ は 5 ではなく 6〜7 になる。Q_Z は「過小選択の原因」であると同時に「過大選択を防いでいる唯一の項」でもある。

**Q2. Q_Z を除くと過大選択になるか。**
なる。canonical の大部分の条件と paper-type の全件で過大選択（K̂ はほぼ候補の最大値）。

**Q3. 原論文の Eq.(16) 型の基準は canonical データで何を選ぶか。**
Z の評価点を最後の標本（C）にしても結合モード（D）にしても、canonical の n ≥ 75 では K̂ = 6〜7 の過大選択になる。D（結合モード）は C よりさらに過大選択しやすい（d=30 で n=50〜100 は 8/8、n=150 は完了した 7/7 が過大）。**現在の canonical データ（n ≥ 75、d=15）では、Eq.(16) 型の基準を使うと過小選択は起きないが、代わりに過大選択が起きる。** Q1 型と比べた C_Q の過小選択は Q_Z による。ただし過小選択は C_Q だけのものではなく、C_Lap にも n ≤ 75 で残る（n=50 で 8/8、n=75 で 5/8）。

**Q4. Z の評価方法によって結果は変わるか。**
変わる。同じ状態で、MC 平均（B）・最後の標本（C）・結合モード（D）は d=30・n=75 で 3/0/5、4/0/4、0/0/8 と違う。D はモードで評価するので当てはまりが最も良く、過大選択が最も強い。ただし、3 つとも「K を増やすと有利」という向きは同じである。

**Q5. 原論文の BIC と C_Q の違いを修士論文でどう説明するか。**
- 原論文の Eq.(26) の ln L は Eq.(16) の条件付き尤度で、p(Z) を含まない。C_Q は Q 関数（p(Z) を含む完全データ対数尤度の事後期待値）を使う。**同じ状態・同じ Z の標本で比べた場合（A と B）**、両者の差は本研究の正規化（`scale_Z`、σ_z²=1）のもとで nK(1 + ln 2π) という K に比例する項になる。原論文の BIC と C_Q の差はこれだけではない：Z の評価点（不明）、罰則の定数 d ln n、Y の学習用マスク、生成器と ln L の正規化（不明）も違う。
- 既存の推定状態で確かめると、Eq.(16) 型（Z の評価点を明示した版）は過大選択し、C_Q は n が小さいと過小選択する。どちらも観測データの周辺尤度（Q3）に基づく Schwarz BIC ではない。
- 原論文の Fig. 3 で K\* が選べた理由は、本研究からは説明できない（原論文の評価点・生成器・正規化が不明。PR #158）。「原論文の基準を再現した」とは書かない。

**Q6. 本来どの基準が妥当か。理論的な制約。**
- 潜在変数モデルの次元選択で BIC の理論的な根拠があるのは、観測データの周辺尤度 ln p(X, Y | θ̂_K) を使う場合である（Z を積分する）。Q1（Z を固定）は Z の n K 個の値を当てはめた量で、罰則が θ だけを数えると一致性がない。Q2（ICL 型、C_Q）は分類型の潜在変数（混合モデル）では ICL として知られるが、連続潜在変数では ln p(Z) の値が Z の尺度（ここでは `scale_Z`）に依存し、罰則としての大きさに統計的な根拠がない。
- C_Lap は Q3 のラプラス近似で方向としては妥当だが、(i) 近似の精度、(ii) 罰則に使う「N」（n かペア数か）、(iii) 回転の不定性の扱い（p_K の k(k−1)/2）、(iv) θ が短い MCEM の推定値であること、に理論的な未解決点がある。
- 「Q_Z を除いたら正しく選べた」データセットがあっても（d=30・n=50 など）、それは新しい基準の正しさを示さない。同じ基準が n を増やすと過大選択に変わるからである。
