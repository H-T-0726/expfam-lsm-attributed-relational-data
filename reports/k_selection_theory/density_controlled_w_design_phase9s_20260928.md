## 1. 問題

Phase 9P では w0 = −1 を固定して w だけを変えたため、関係の自然パラメータの広がりと同時に、平均 edge 確率・実現した edge 密度・確率の飽和も変わった。
本 Phase は、**母集団の平均 Bernoulli edge 確率**を w によらず揃える w0 を条件ごとに 1 つ決め、将来の実験（Phase 9T）の protocol を凍結することを目指した。

推定対象（estimand）:

```
S = z_iᵀ z_j,  z_i, z_j iid N(0, I_K),  K = K_true = 3
p̄(b, w) = E[ σ(b + w S) ]
p_target = p̄(−1, 1)
w0(w): p̄(w0(w), w) = p_target,   w ∈ {1/√2, 1, √2}
```

観察された Y、Phase 9P の実現 edge 密度、replicate ごとの Z は target にも w0 にも使わない。

## 2. 数学的な監査

**FACT**（定義・前提）: z_i, z_j は独立に N(0, I_K)。σ(x) = 1/(1+e^{−x}) は滑らかで 0 < σ < 1、σ'(x) = σ(x)(1−σ(x)) ∈ (0, 1/4]。

**DERIVED**

1. `E[S] = Σ_k E[z_ik] E[z_jk] = 0`。
   `Var(S) = E[S²] = Σ_k Σ_l E[z_ik z_il] E[z_jk z_jl] = Σ_k 1 = K`（独立性と E[z_ik z_il] = δ_kl）。
2. z_i を与えると S | z_i ~ N(0, ‖z_i‖²)。T = ‖z_i‖²/2 とおくと ‖z_i‖² ~ χ²_K より T ~ Gamma(K/2, scale 1)。
   G ~ N(0,1) を T と独立にとると S は `√(2T)·G` と同じ分布をもつ。よって `p̄(b, w) = E_{T,G}[σ(b + w√(2T) G)]`。
3. 固定した有限の w について、b ↦ p̄(b, w) は連続で狭義単調増加:
   被積分関数は b について滑らかで、その導関数 σ'(b + wS) は 1/4 で押さえられるため、優収束定理により微分と期待値を交換でき、
   `∂_b p̄ = E[σ'(b + wS)] > 0`（σ' > 0 がすべての点で成り立つ）。
4. 0 < σ < 1 で押さえられるので、優収束定理より b → −∞ で p̄ → 0、b → +∞ で p̄ → 1。
5. 3 と 4 と中間値の定理から、任意の p_target ∈ (0,1) について `p̄(b, w) = p_target` の解 b は**存在して一意**である。
6. S の分布は 0 について対称なので `p̄(0, w) = 1/2`、また p̄(b, w) = p̄(b, −w)。p_target = p̄(−1, 1) < p̄(0, 1) = 1/2 なので、どの w でも w0(w) < 0。
7. w = 1 では b = −1 が定義により解であり、一意性から w0(1) = −1。

weak では w0 > −1、strong では w0 < −1 になることは一般的には導出していない（σ は負の側で凸だが全体では凸でない）。以下の数値で確認したことにとどめる。

## 3. 数値較正の方法（結果を見る前に固定）

- **積分**: T について一般化 Gauss–Laguerre（α = K/2 − 1 = 1/2、Γ(3/2) で正規化）、G について Gauss–Hermite（正規分布の重み）のテンソル積。σ は `scipy.special.expit`。
- **根**: brentq（xtol 1e-15、rtol 4ε）、bracket は [−1, 1] から決定的に倍々に広げる。
- **解像度**: (n_T, n_G) = (16, 32), (32, 64), (64, 128), (128, 256)。
- **本番の解像度を選ぶ規則**: 次に細かい解像度との差が、p_target と 3 つの w0 のすべてで絶対値 1e-12 以下になる最小の解像度。該当しなければ固定しない（NEEDS_REVISION）。
- **独立の cross-check**: 固定 seed（20260928）の潜在事前分布からの Monte Carlo 1e7 サンプル。本番の較正値が得られた場合だけ実行する流れにしていた。

## 4. 結果（NUMERICAL）

### 解像度ごとの値

| (n_T, n_G) | p_target | w0 weak (w=1/√2) | w0 baseline (w=1) | w0 strong (w=√2) |
|---|---|---|---|---|
| (16, 32) | 0.331406235554 | −0.878099194820 | −1 | −1.189112456855 |
| (32, 64) | 0.331406185653 | −0.878099587640 | −1 | −1.189059059914 |
| (64, 128) | 0.331406211988 | −0.878099441346 | −1 | −1.189064676208 |
| (128, 256) | 0.331406212132 | −0.878099440539 | −1 | −1.189064812862 |

### 隣り合う解像度の差（絶対値）

| 比較 | p_target | w0 weak | w0 strong |
|---|---|---|---|
| (16,32) → (32,64) | 5.0e-8 | 3.9e-7 | 5.3e-5 |
| (32,64) → (64,128) | 2.6e-8 | 1.5e-7 | 5.6e-6 |
| (64,128) → (128,256) | 1.4e-10 | 8.1e-10 | 1.4e-7 |

- **baseline の復元誤差**: どの解像度でも 0（w0(1) = −1 が浮動小数点で厳密に得られた）。
  ただしこれは target を同じ積分で定義しているため構成上ほぼ自明であり、積分自体の正確さの証拠ではない。
- **target への残差** `|p̄(w0, w) − p_target|`: どの解像度・条件でも ≤ 5.6e-17。これも各解像度の中での根の精度であり、積分の正確さの証拠ではない。
- 重みの和はどの解像度でも 1 との差 ≤ 5e-16。
- **本番の解像度: なし**。最も細かい比較でも差は p_target 1.4e-10、w0 weak 8.1e-10、w0 strong 1.4e-7 で、事前に決めた 1e-12 を満たさなかった。
  差は解像度とともに一貫して小さくなっており（strong: 5.3e-5 → 5.6e-6 → 1.4e-7）、数値の破綻（重みの和、残差、根の失敗）の兆候はない。収束が遅いだけである。
- 独立の cross-check と Phase 9T の protocol の凍結は、事前の流れのとおり**実行していない**（本番の較正値が決まらなかったため）。

### 暫定値（固定していない）

最も細かい解像度の値は p_target ≈ 0.3314062121、w0 weak ≈ −0.8780994405、w0 strong ≈ −1.18906481 である。
解像度間の差から見て、weak は約 1e-9、strong は約 1e-7 の桁まで安定しているように見えるが、これは本番の値として凍結したものではない。

## 5. 収束が遅い理由（解釈、未検証）

T が大きいとき、G の関数として σ(b + w√(2T) G) の傾きは w√(2T) に比例して急になり、ステップ関数に近づく。
ロジスティック関数の極は実軸から π/(w√(2T)) の距離にあるため、固定した点数の Gauss–Hermite では T が大きい領域の近似が悪くなり、指数的に速い収束が期待できない。
w が大きい strong で差が最も大きいこともこれと整合する。これは標準的な求積理論からの解釈であり、本 Phase では検証していない。

## 6. DECISION

## **DECISION: DENSITY_CONTROLLED_W_DESIGN_NEEDS_REVISION**

推定対象は数学的によく定義されており（一意な w0(w) が存在する）、baseline は w0 = −1 を復元した。
しかし、事前に決めた数値の安定性の規則（隣り合う解像度の差 ≤ 1e-12）を満たす解像度がなく、weak / strong の w0 を本番の値として凍結できなかった。
そのため Phase 9T の protocol は凍結していない。この判定は K 選択の結果によらない（K 選択は行っていない）。

## 7. CAN SAY / CANNOT SAY

**CAN SAY**

- 暫定的な数値では、w0 は weak で約 −0.878、strong で約 −1.189 であり、baseline の −1 をはさむ（NUMERICAL、未凍結）。
- 事前に決めた 1e-12 の規則のもとでは、今回の求積の解像度では較正値を固定できなかった。

**CANNOT SAY**

- 純粋な信号の強さの効果の分離（仮に較正が凍結されても、揃うのは母集団の平均 edge 確率だけで、確率の分散・飽和・分布の形・有限標本での実現密度は揃わない）。
