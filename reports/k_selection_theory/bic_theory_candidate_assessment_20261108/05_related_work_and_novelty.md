## 2. 主要な文献と本研究の対応

### 2.1 本研究の C_Q と ICL

- 恒等式 $\mathbb E_\pi\log p(X,Y,Z)=\ell_{\rm marg}-H(\pi)$（03 §3.2）は、**ICL の文献で知られている関係の、連続版**である。新しい恒等式ではない。
- 本研究が明確にしたのは、この関係を C_Q に当てはめた結果である。
  - (a) 連続の潜在変数では $H(\pi)$ が微分エントロピーで、ノードごとの事後精度 $a_i$ と $2\pi e$ の大小で符号が変わる（03 §3.4）。
  - (b) Q_Z が定数になるのは、`scale_Z` の作為ではなく、最尤点の性質である（03 §4.2）。
  - (c) Y の関係データでは、n が増えると $a_i$ が増えるので、C_Q の追加の罰則が n とともに小さくなり、符号が変わりうる。
- (a)〜(c) は、既存の理論を本研究のモデルに適用して整理したものであり、**新しい基準ではない**。

### 2.2 ELBO（Zhang & Yang 2024）

- **[本文] から確認した仮定**
  - 単位は i.i.d. で、各単位に局所的な潜在変数を持つ。
  - パラメータの次元は固定。
  - Fisher 情報が正則（「非特異なモデルだけを考える」と明記）。
  - 過小なモデルには KL のギャップの条件がある。
- **[本文] から確認した結論**
  - ELBO(M) ≈ log p(Xⁿ|M) − C\*(M)。C\*(M) は平均場の近似による定数である。
  - −½BIC との差は、漸近的にモデルに依存する定数になる。
  - 「BIC が要求する有効次元の計算が難しいモデル（ベイズ因子モデル・HMM）でも、ELBO は副産物として計算できる」と述べている。
- **本研究への適用**
  - 本研究では、ノードは Y で結合されており、i.i.d. の単位ではない。
  - K > K0 で特異になる。
  - したがって、**この論文の理論は、本研究の ELBO 型の基準をそのまま正当化しない**。
  - 「ELBO 型の基準を使う」ことは既存手法の適用であり、新規性ではない。

### 2.3 Laplace（C_Lap）

- θ を固定して Z を Laplace で積分し、θ に BIC 型の罰則を加える構成は、GLLVM や GLMM で標準的な考え方である（Laplace による周辺尤度 + 情報量基準）。
- **新しい手法ではない**。本研究の C_Lap も、過去の研究と同じく「既存の手法を本モデルに実装したもの」として位置づける。

### 2.4 sBIC（Drton & Plummer 2017）

- **[本文] から確認したこと**
  - Watanabe の結果 $\log L(M_i)=\log P(Y_n\mid\pi_0)-\lambda_i(\pi_0)\log n+(m_i-1)\log\log n+O_p(1)$ を、すべての部分モデルについての近似の重み付き平均として定義する。
  - 学習係数（$\lambda_{ij}$）と多重度（$m_{ij}$）の表が必要である。
  - 例は、縮小ランク回帰、因子分析、二項混合、ガウス混合、潜在クラス分析。
  - 因子分析の学習係数は「進行中の研究」の値を使っている。
- **本研究に適用するのに必要なもの**
  - (i) 本モデル（X：指数型分布族、Y：Bernoulli の双線形）の学習係数。
  - (ii) 入れ子の構造。
  - (iii) 単位の i.i.d. 性。
  - (i) は未知で、(ii) は Gaussian-Y では成り立たない。
- **修士研究で学習係数を導出するのは、過大な理論課題である**（INTERPRETATION）。

### 2.5 JIC（Chen & Li 2022）

- **[本文]**
  - 因子を固定のパラメータとする同時尤度で、K ≥ K\*+1 では $2(\hat l_K-\hat l_{K-1})=O_p(N\vee J)$ になる。
  - したがって、過大選択を避けるには、罰則 $u$ が $N\vee J=o(u)$ を満たす必要がある。
  - 過小選択を避けるには、$u=o(\sigma^2_{K^\ast}(M^\ast))$（因子の強さ）が必要である。
  - 「因子の強さが雑音の水準より強いときだけ、一致性が保証される」。
- **本研究への示唆（DERIVED + INTERPRETATION）**
  - (a) Q1 型（Eq.(16) 型）の基準は、Z の数に比例する罰則がない限り過大選択しうる。これは文献の理論と整合する。
  - (b) C_Q の Q_Z は「1 次元あたり 2.84 n」という、**n に比例する定数の罰則**として働く。これは JIC の $(N\vee J)\cdot h$ の形に似ている。ただし、JIC が一致性のために要求する「ゆっくり発散する h」ではなく、h は 2.84 という定数である。
  - 参考：JIC の推奨罰則は、N ≫ J のとき 1 次元あたり $N\log J$ で、d=15 なら $\log15=2.71$ である。C_Q の 2.84 と**数値的に近いのは偶然**で（d に依存する）、C_Q を正当化しない。
  - (c) JIC の理論は、「弱い因子は選べない」ことを一致性の条件として明示している。これは、C_Q の弱信号での過小選択が、**Q1/Q2 型の点推定・同時尤度の枠組みに内在する限界**である可能性を示す（HYPOTHESIS。C_Q は点推定ではなく事後標本で評価するので、JIC の定理はそのまま当てはまらない）。

## 3. 新規性の評価

### 3.1 既存手法と数学的に同等なもの

| 本研究で扱う候補 | 既存手法 | 判定 |
|---|---|---|
| C_Lap | Laplace による周辺尤度 + BIC 型の罰則 | **既存手法の適用** |
| C_ELBO（明示的な q） | 変分ベイズによるモデル選択（ELBO） | **既存手法の適用** |
| $C_{\rm ELBO}(q_{\rm Lap})=C_{\rm Lap}+2R_3$ | Laplace のガウスを q とした ELBO（Laplace-variational） | **既存手法の組み合わせ** |
| C_Q の解釈（$C_{\rm marg}+2H$） | ICL のエントロピーの関係 | **既知の関係の連続版** |
| 「K に依存する罰則に log n（ノード数）を使い、ペアの数は K によらない部分だけに使う」 | SBM の ICL のブロックごとの速さ | **既存の考え方と同じ** |

### 3.2 本研究に固有の、小さな理論的整理（新規性として主張できるかは未確認）

1. **連続潜在の完全データ型基準の符号の閾値 $2\pi e$**：事後精度による、周辺尤度型の基準との大小関係（03 §3.4）。
2. **スケール方向の恒等式**（命題 C-1）とその系：最尤点で Q_Z が定数になることと、`scale_Z` の位置づけ。
   - パラメータの冗長性（PX-EM）の理論からの簡単な帰結で、因子分析などで既に知られている可能性が高い（文献で確認していない）。
3. **Y 側が入れ子にならないことの、選択理論への含意**（02 §4.3、命題 B-1）：Gaussian-Y の過大側の候補は「特異」ではなく「誤指定」になる。そのため、sBIC の入れ子の前提が合わない。
   - 命題 B-1 自体は初等的（互いに素な dyad の独立性 + データ処理不等式）である。
4. **過剰な次元での対称性と、残差行列による鞍点の発見的な条件**（04 §4.4）。
   - これは低ランクの行列推定の相転移（スパイク模型）との類比で、厳密な結果ではない。

**これらは「既存の理論を、指数型分布族・関係データの潜在構造モデルに適用したときに現れる性質の整理」である。** 文献調査は網羅的ではないので、どれも「新しい」とは断定しない。とくに、2 と 3 は既知である可能性がある。

### 3.3 新しい BIC 型の基準を提案する余地

- **現時点では、既存手法では原理的に解決できない問題は見つかっていない**（06・08）。
- 残っている問題は次の 3 つで、いずれも既存手法の既知の未解決問題である。
  - (i) 高次元・交差構造での Laplace の精度
  - (ii) 特異性・入れ子でないことの下での漸近理論
  - (iii) θ の最適化の不足
- 新しい罰則を作る根拠にはならない。
- 「指数型分布族に対応している」こと、「X と Y が共通の Z を持つ」ことは、それだけでは新しい基準の必要性を示さない（指示の 6）。
