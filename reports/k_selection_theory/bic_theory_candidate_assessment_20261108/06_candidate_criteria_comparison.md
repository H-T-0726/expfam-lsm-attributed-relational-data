# 06 選択基準の候補の比較（Phase F・G、2026-11-08）

**前提**
- 点数による評価はしない。各項目に根拠を付けて、定性的に比較する。
- 過去の数値実験の成否は、候補を選ぶ理由にしない（指示の 7）。過去の観測は 08 で、理論と照合するためだけに使う。

## 1. 候補の定義

| 候補 | 定義 | 由来 |
|---|---|---|
| **A** C_Q（現行）とその理論的な整理 | $C_Q=-2Q_{MC}+p_K\ln n$。理想化すると $C_{\rm marg}+2H(\pi)$ | 03 |
| A′ C_Q − P_Z、または Q_Z の係数を変えたもの | $C_Q-\alpha P_Z$ | **経験的な変更で、理論的な改善ではない**（指示の 3）。比較のためだけに載せる |
| **B** ELBO 型 | $C_{\rm ELBO}(K)=-2\mathcal L_K(q,\hat\theta_K)+p_K\ln n$。$q$ は明示的で正規化されたもの：$q_{\rm Lap}=\mathcal N(\hat Z,H^{-1})$、またはブロック対角の $q_{\rm MF}=\prod_i\mathcal N(m_i,A_i^{-1})$ | 04 §1〜§3、07 |
| **C** Laplace 型（既存の C_Lap） | $C_{\rm Lap}=-2\ell_{\rm Lap}(\hat\theta)+p_K\ln n$ | 04 §3・§5 |
| C+ Laplace + θ の Laplace | $-2\ell_{\rm Lap}(\hat\theta)+\log|J_\theta|-2\log\pi(\hat\theta)+\dots$ | 02 §5.4 |
| **D** 特異モデルの基準 | sBIC（学習係数が必要）、WBIC（θ と Z の焼き戻した事後分布のサンプリングが必要） | 05 §1・§2.4 |
| **E** 本研究のモデルの構造を使うもの | E1：ブロックごとの速さの罰則。E2：X と Y の分離・重み付け。E3：AIS やブリッジで周辺尤度を直接推定する（基準というより検証）。E4：held-out 予測（目標 G3、比較対象） | 02 §5、04 §5.2 |

## 3. 候補 E の各案

| 案 | 判定 | 理由 |
|---|---|---|
| E1（ブロックごとの速さ） | **新しい基準にはならない** | K に依存するのは F だけなので、罰則は $(d-K)\log n$ のままである。w0・w に $\log\binom n2$ を使っても、選択は変わらない（02 §5.1）。**これは否定的な結論として重要**である |
| E2（X と Y の重み付け） | **理論的な根拠がない** | 尤度に重みを掛けると、もはや確率モデルの evidence ではなくなる。後付けの罰則になる（指示の「新規性を作るための後付けの罰則は提案しない」）。提案しない |
| E3（AIS・ブリッジ・熱力学的積分） | **基準ではなく、C_Lap・C_ELBO の近似精度を検証する道具** | 小さい n で $\ell_{\rm marg}$ を高精度に推定し、Laplace と ELBO の誤差の K 依存性を測る。次の Human Gate の候補 |
| E4（held-out 予測） | **目標が違う比較対象（G3）** | K0 の一致性とは別の目標。既存の実装がある |

## 4. 結論（Phase G）

### 選んだ結論：**B**（既存手法を本研究の指数型分布族モデルに適切に適用すること自体に研究上の価値がある）。ただし、D の要素を限定として付ける。

**理由**
1. **A（既存の方法をそのまま使えば十分）ではない。** 現行の C_Q は、理想化しても周辺尤度から $2H(\pi)$ ずれる（03 §3）。その符号と大きさは、事後精度と $2\pi e$ の大小という、K0 とは無関係な量で決まる。したがって、K0 を選ぶ（目標 G2）基準として C_Q をそのまま使う理論的な根拠はない。Eq.(26) 型（Q1 型）は、n に比例する罰則がない限り過大選択に偏る理由がある（03 §7、05 JIC）。
2. **C（既存手法では解決できない明確な問題がある）ではない。** 周辺尤度を目標とする既存の枠組み（Laplace、ELBO、AIS など）は、原理的には本モデルにも適用できる。残る問題は、既存手法に共通する未解決問題（高次元の Laplace の精度、特異性、θ の最適化）で、新しい罰則の必要性を示すものではない。
3. **D の要素（限定として残すもの）**
   - どの基準についても一致性は証明されていない（U6）。
   - Bernoulli-Y の識別可能性・入れ子でないこと（U2・U5）は未解決である。
   - したがって、「この基準が理論的に正しい」と言える基準は、現時点では存在しない。
   - ただし、「基準を選ぶべきではない」ほどの不確かさではない。**目標とする量（周辺尤度）を明確にし、その近似の質を評価できる候補**に絞ることはできる。

**Phase H で導出する候補（最大 2 つ）**
- **候補 C：C_Lap**（周辺尤度の Laplace 近似 + $p_K\ln n$）。目標とする量が正しく、実装済みである。
- **候補 B：$C_{\rm ELBO}(q_{\rm Lap})=C_{\rm Lap}+2R_3$**。C_Lap と同じ部品で、**厳密な下界**を与える。C_Lap の近似の向きを検証する相方として使う。

どちらも既存手法であり、「新しい BIC」とは呼ばない。

**選ばなかった候補と理由**
- A′：経験的な変更。
- D：学習係数が未知（sBIC）で、サンプラーの実装が過大（WBIC）。
- E1・E2：E1 は否定的な結論で、E2 は後付け。
- E3：検証の道具として、次の Human Gate の候補に回す。
