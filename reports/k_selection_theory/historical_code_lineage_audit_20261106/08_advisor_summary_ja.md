# 08 指導教員向け要約：昔は K=9 まで選べたのに、なぜ今は K=5 を選べないのか（2026-11-06）

既存のコード・CSV・原論文の再解析だけで、新しい推定は行っていない。系列 E は prototype（本文採用は未決定）。C_Q は Q ベースの complete-data / ICL 型の基準で Schwarz BIC ではなく、C_Lap はラプラス近似で厳密な周辺尤度ではない。

## 結論（短く）

**「昔」と「今」は、同じモデルの同じ実験ではない。** データの作り方（X・Y の信号の強さとデータ数 n）が大きく違う。昔の Python 再現・初期 ExpFam の条件では「正しい次元を加えたときの当てはまりの改善」が罰則よりはるかに大きく、どの推定器・どの基準でも正しく選べた（ただし原論文 Fig. 3 そのものの余裕は小さい。下の 1）。今の canonical 条件（n=75）では、その改善が C_Q の罰則と同じ大きさまで小さくなっている。

## 分かったこと

1. **原論文の Fig. 3**（図のベクターデータから読み取り）：K\*=1〜9 のすべてで最小値は正しい位置にある。ただし差は小さい。K\*=9 では K=8 との差が 57、K\*=3 では K=4 との差が 4 しかない。曲線は K\* ごとに 1 本で、10 試行をどう集計したかは書かれていない。
2. **研究室の MATLAB コード**には、Experiment 2（K を変えて BIC を比べる）を実行する部分がない。残っているバッチスクリプトは、ループで k=1..10 と回しているが、実際には毎回 K=3 のモデルを推定している。E-step には、勾配に w が欠けている、Newton の刻みが 0.01 と小さい、などの問題がある。ただし Fig. 3 を作ったコードではないので、論文の結果への影響は分からない。
3. **論文本文と MATLAB のデータ生成は違う。** 本文は「F の各成分 ~ N(0, 10)」だが、MATLAB と Python 再現は F の各行の長さを √0.9 にそろえ、Z と X を標準化している。
4. **Python 再現の 5/5** は、K\* ごとに 1 つのデータについて、p(Z) を含む当てはまりの最良反復で BIC を計算した結果である。論文の式（Eq.16：p(Z) を含まない）とは違い、値も Fig. 3 より 1〜2 桁大きい。なお、Newton の刻みを選択結果を見てから 0.01→0.5 に変えたという記述が再現報告書にあるが、その実行の CSV は残っておらず確認できない（未確認）。
5. **同じデータなら、推定器や基準を替えても結果は変わらなかった。** Python 再現と同じ 5 データを現在の推定器（系列 E）で推定し直すと、C_Q でも C_Lap でも正しい K が選ばれ、余裕は 1,500〜3,500 あった。
6. **Poisson-X/Bernoulli-Y という組み合わせ自体が問題なのではない。** 初期の ExpFam 実験では、同じ組み合わせで K\*=1〜9 の 25/25 が正解だった（n=150、昔の生成方法）。
7. **信号の量とデータ数が大きく違う。** 真のパラメータで計算した 1 ノード・1 方向あたりの情報量（K=5）は、今の条件（n=75、Y は 80% のペア、新しい seed での計算）で約 7、初期 ExpFam の条件で約 36、MATLAB/Python 型で約 130。量の差は Y 側（w² と n）が大きい。ただし、今の条件で 1 つずつ変えた比較では、n を 75→150 にすると C_Q の正解率は 0/8→7/8、F だけを強めると 3/8、w だけを強めると 2/8 で、**F と w の効果は同程度だった。「Y 側が主因」とはまだ言えない。**
