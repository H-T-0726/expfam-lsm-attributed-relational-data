## 4. この節の答え（Q3）

- MATLAB 型の生成器（F の行ノルム固定、σ²=0.1 の Gaussian-X、|w| が大きいことが多い 3·randn）で作った、**k\* ごとに 1 つのデータ**について、

示していないこと：論文 Fig. 3 の値の再現、論文本文の生成器での成功、MATLAB の実行経路の再現、試行間のばらつき（データが 1 つ）、Eq.(16) どおりの基準での成功。
