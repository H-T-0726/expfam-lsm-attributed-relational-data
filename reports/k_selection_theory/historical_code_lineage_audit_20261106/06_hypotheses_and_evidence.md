## 2. 最も重要な比較：同時に変化している条件

歴史的に成功した最も近い条件は、初期 ExpFam Scenario A（**同じ Poisson-X/Bernoulli-Y**、K\*=5、n=150）である。canonical の失敗（K_GEN=5、n=75）との違いは 04 §4 の 8 点で、いずれも一要因ではない。既存の結果から言えるのは次のとおり（OBSERVED → INTERPRETATION）。

1. **n**：canonical のまま n を 75→150 にすると、C_Q は 0/8 → 7/8。単独で最大の効果。
2. **信号**：n=75 のまま、F のエネルギーだけを 1.8 倍（PR #155 B）で C_Q 3/8・C_Lap 6/8、w² だけを 1.8 倍（C）で 2/8・4/8、両方（D）で 3/8・7/8。**F と w の効果は同程度で、情報量の差の大きさ（Y 側が大）から予想される順位とは一致しない。** D でも w² = 1.08 で、歴史的な 2.25 の半分以下である。
3. **基準**：canonical では C_Lap のほうが C_Q より成功する（n=75：3/8 と 0/8）。C_Q の「入場料」（1 次元あたり 2.84n）が、canonical の小さな余裕と同じ大きさだからである。
4. **推定器・試行の扱い・正規化**：歴史的データでは結果を変えなかった。canonical での効果は未検証。

## 3. 「信号強度だけで説明できるか」（Q6）

- **「信号強度」を「X 側の F の強さ」の意味で使うなら、説明できない。** K=9 の歴史的条件は、F のエネルギーが canonical の K=5 と同じでも成功している。
- 既存の観測は「1 ノードあたりの余裕 C(K\*−1) − C(K\*) の符号」で整理できる（INTERPRETATION）。余裕は「当てはまりの改善 − 入場料 2.84n − 罰則」なので、すでに入場料と罰則を差し引いた量である。歴史的条件の Q2 型スコアでは +1.6〜+222（中央値）で正、canonical の n=75 の C_Q では −1.7 で負。分かれ目は、当てはまりの改善が入場料と罰則を超えるかどうかである。
- 当てはまりの改善を決めるのは X と Y の信号と n の組み合わせで、F だけ・w だけを強めた一要因比較では、どちらも同程度に効いた。「Y 側の信号が主因」とは言えない。
- ただし、これは同時に変化する条件を分けた結果ではない。Y の信号・X の信号・n・基準のそれぞれの寄与の大きさは、07 の E3・E5 なしには確定しない。

## 4. 確定したことと仮説（Q8）

**確定（FACT / OBSERVED）**

- リポジトリの MATLAB には Experiment 2 を実行する経路がない。バッチスクリプトは K=3 だけを推定している。
- 論文本文の生成器と MATLAB/Python の生成器は違う（F の分布と行ノルムの固定、Z・X の z-score）。
- Python 再現の BIC は p(Z) を含む plug-in の Q2 で、論文 Eq.(16) の ln L とは違う。値は Fig. 3 より 1〜2 桁大きい。
- 歴史的なデータ（Gaussian-X、Poisson-X とも、n=150）では、推定器と基準を替えても正しい K が選ばれ、余裕は大きい（K\*=9 の過小側の余裕の中央値：0.5 系列 calc_bic_dual 236〔Scenario A〕、Python plug-in 1,846、系列 E の C_Q 1,734〔最小 1,618〕）。
- 同じ Poisson-X/Bernoulli-Y でも、歴史的な生成器なら成功する。
- canonical で n を 75→150 にすると、C_Q の正解率は 0/8 → 7/8 になる。

**仮説・未確定**

- 論文 Fig. 3 の ln L が何で、どの生成器で作られたか（UNRESOLVED）。
- canonical の n=75 の失敗に対する Y 信号・X 信号・Z の正規化・推定器の寄与の大きさ。一要因比較では n の効果が最大で、F と w は同程度（各 1.8 倍の範囲）。それ以上の順位は未確定。
- MATLAB の E-step の欠陥が論文の結果に影響したか（UNRESOLVED）。
- Python 再現で α=0.01 だと k=1 が選ばれたという報告書の記述（UNRESOLVED、CSV なし）。
