# 07 最小の対照実験の設計（事前登録案、未実行、2026-11-06）

**この文書は案である。どの実験も実行していない。** 実行するかどうか、どれを先にするかは研究者が決める（Human Gate）。機械可読版：`proposed_controlled_experiments.csv`。

## 0. 共通の約束

- 主要指標は正解率ではなく **4→5 の余裕 S = C(4) − C(5)**（2 start の平均）とその 1 ノードあたりの値。正解率は副次的な指標にする。
- 「一要因だけ変えた実験」と呼んでよいのは、生成法則・推定器・基準のうち 1 つだけが違う場合に限る。それ以外は「条件群の比較」と書く。
- 系列 E、L=5、8 反復、2 start、K_GEN=5、n=75（必要なら 150）。seed の規則・停止規則・INCOMPLETE の扱いは PR #155 と同じにする（fail fast、seed の救済なし）。
- 実行は 1 プロセス、BLAS スレッド 1。fit ごとに永続保存する（PR #157 の addendum v2 の方式）。

## E1 同じ状態、基準だけを変える（新しい fit なし）

- 対象：canonical の保存状態（PR #155 A/B/C/D、PR #156 の 64 反復の状態）と、#139 の保存状態。
- スコア：(a) 論文 Eq.(16) 型の plug-in Q1（p(Z) なし、最後の標本、罰則 (k+1)d − k(k−1)/2 または kd − k(k−1)/2）、(b) Python 再現型（p(Z) を含む plug-in の最良反復）、(c) C_Q、(d) C_Lap。
- 問い：**canonical の過小選択は、論文の式どおりの基準でも起きるか。** p(Z) の入場料がない Q1 では、逆に過大選択になるか。
- 予算：fit 0。保存状態の読み込みと評価だけ（数分〜数十分）。
- 注意：(b) の「最良反復」には反復ごとの状態が必要で、保存されている checkpoint（8, 16, …）の範囲でしか再現できない。

## E2 同じデータ、推定器だけを変える

- canonical A（n=75）の 8 データを、0.5 系列（`model_dual_expfam.py`）、fixed 系列、系列 E で推定し、同じ C_Q（同じ評価コード）で採点する。
- 注意：系列の間では 1/2 だけでなく、数値処理やリトライも違う。**「推定器系列の比較」であって 1/2 の効果ではない。**
- 予算：8 データ × K 3..7 × 2 start × 3 系列 = 240 fit（K を 1..7 にするなら 336）。

## E3 同じ推定器、生成器だけを変える（条件群の比較）

- 系列 E で、(i) 初期 ExpFam Scenario A の生成器（F の行ノルム √0.9、Z の z-score、w=1.5）、(ii) canonical を、n=75 と 150 で比べる。
- 注意：生成器の間では F の法則・w・Z の正規化・Poisson の rate が同時に変わる。
- 予算：2 生成器 × 2 n × 8 データ × K 3..7 × 2 start = 320 fit。

## E4 Gaussian-X/Bernoulli-Y で K=5 と K=9 を比べる

- 系列 E で、canonical 型の生成器（Z を正規化しない、F の特異値を等しくする）を Gaussian-X にし、σ² を「1 方向あたりの X の情報が歴史的条件の K=5（27.0）または K=9（15.0）と同じ」になるように選ぶ。w は w²K を固定する。
- 問い：同じ情報量なら、K=9 は K=5 より難しいか。
- 予算：2 K_GEN × 8 データ × 5 候補 K × 2 start = 160 fit（K=9 の fit は重い）。

## E5 canonical 生成器の上での 2×2×2 の要因実験（推奨する最初の新規実験）

- 要因：w（0.775 か 1.5）、F の平均行ノルム²（0.5 か 0.9）、観測マスク（0.8 か 1.0）。K_GEN=5、n=75。
- 各セルで生成器は canonical-clean-v1 のままで、パラメータだけが違う。**それぞれの主効果は一要因の比較になる。**
- 予算：8 セル × 8 データ × K 4..6 × 2 start = 384 fit。
- 事前登録では方向を決め打ちしない。既存の一要因比較（PR #155 B・C、各 1.8 倍）では F と w の効果は同程度で、情報量の差（Y 側が大）から予想される順位と一致しなかった。主効果と交互作用の大きさを余裕で推定する。

## 推奨する順序（判断は研究者）

1. **E1**（fit 0）：基準の役割を確定する。論文の式どおりの基準が canonical でどう振る舞うかは、修士論文で歴史的研究と比べるときに必要になる。
2. **E5**：同時に変化している条件の寄与の順位を、一要因の主効果として決める。
3. E3・E2 は、E5 で説明しきれない部分が残った場合だけ行う。E4 は「K が大きいほど難しいか」という別の問いで、優先度は低い。

各 fit の時間は、PR #156 の Phase 4 の実測（L=20、32 反復、約 160 秒/fit）から、L=5・8 反復なら 1 fit あたり数十秒と見込む。ただし事前の gate で実測すること。
