# 04 C_Q・C_Lap の checkpoint 比較と信号強度効果の維持（2026-11-06）

- **位置づけ**：系列 E（prototype）。C_Q（`calc_bic_dual`、列 `BIC`）は Q-based complete-data / ICL 型で **Schwarz BIC ではない**。C_Lap は周辺尤度のラプラス近似で **厳密な周辺尤度ではない**。
- 比較はすべて **4→5 の局所比較**（S = C(4) − C(5)、2 start の平均）で、K=1..7 からの K̂ ではない。B/C/D の全候補 K は予算外のため評価していない（`analysis/full_k_selection.csv` に NOT_PRODUCED と記録）。
- 一次資料：`analysis/paired_slack_changes.csv`、`analysis/checkpoint_q_decomposition.csv`、`analysis/local_k4_k5_comparison.csv`、図 2・3・5。

## 1. 主要結果：信号強度の効果は維持されたか（事前登録の主判定 = C_Q、64 反復）

規則：MAINTAINED = 対応差の中央値 > 0 かつ 6/8 以上が正。

| 対比 | 8 反復 中央値 [CI]（正の件数） | 64 反復 中央値 [CI]（正の件数） | 判定（64） |
|---|---|---|---|
| B − A（F 強） | +78.6 [51.4, 107.9]（8/8） | **+65.2** [42.8, 98.1]（8/8） | **MAINTAINED** |
| C − A（w 強） | +35.3 [8.4, 73.7]（7/8） | **+39.0** [3.3, 50.6]（7/8） | **MAINTAINED** |
| D − A（両方） | +129.1 [76.0, 173.3]（8/8） | **+114.5** [73.0, 165.3]（8/8） | **MAINTAINED** |

- CI は順序統計量による中央値の区間（x(2), x(7)、被覆率 0.930）。Wilcoxon の正確 p（記述用）は 64 反復で B−A 0.008、C−A 0.039、D−A 0.008。
- 16・24・32・48 反復でも、3 対比すべてが同じ規則で MAINTAINED（`paired_slack_changes.csv`）。中央値の範囲：B−A 56.8〜78.6、C−A 32.5〜42.3、D−A 109.8〜129.1。
- **C−A の 64 反復の CI 下限は 3.3** で、8 反復（8.4）より 0 に近い。C の効果は 3 対比の中で最も弱く、replicate 単位では負になるのは常に rep1 だけで（C_Q：8・24・32・64 反復、64 反復で −25.3。16・48 反復は 8/8 が正）、C_Lap と C_Q_eval でも rep1 は全 checkpoint で負。

## 3. Q の分解（中央値、2ΔQ の単位）

| 条件 | 2ΔQ_X 8 → 64 | 2ΔQ_Y 8 → 64 | 2ΔH_Lap 8 → 64 |
|---|---|---|---|
| A | 73.2 → 66.2 | 60.8 → 70.2 | 120.6 → 115.3 |
| B | 110.7 → 114.7 | 83.9 → 80.5 | 98.7 → 99.0 |
| C | 68.7 → 63.7 | 98.7 → 114.5 | 84.1 → 88.7 |
| D | 121.5 → 115.2 | 126.2 → 125.3 | 73.1 → 73.9 |

（Z 事前コスト n(1+ln 2π) = 212.84、罰則 (d−K) ln n = 47.49 は全条件で同じ。）

- 8 反復で見えた構造は 64 反復でも残る：F 強（B）は X 側の利得を、w 強（C）は Y 側の利得を増やし、D は両方を増やす。
- C_Q と C_Lap の slack の差の主因は 2ΔH_Lap（= n(1+ln 2π) − Δln|H|）で、信号が強いほど小さい（A 約 115〜121、D 約 73〜74）。この関係も反復で変わらない。

## 4. 言えること・言えないこと

- 言える（OBSERVED）：4→5 の局所 slack に対する F・w の効果（B−A、C−A、D−A）は、同じ fit を 64 反復まで続けても、事前登録の規則で維持された。中央値は 8 反復の値から最大で約 22（B−A の 16 反復）しか動かない。
- 言えない：効果の維持は「推定が安定した」ことを意味しない（03 のとおり、全 fit が事前登録の安定性規則を満たさない）。維持されたのは**条件間の差**であり、個々のデータセットの slack は ±20〜40 程度揺らぐ。また、全候補 K での K̂ の変化、n=150 での継続、64 反復を超える挙動は調べていない。
