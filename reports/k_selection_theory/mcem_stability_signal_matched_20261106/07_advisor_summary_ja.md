# 07 指導教員向け要約（2026-11-06）

- 系列 E（prototype）の結果で、修士論文への採用は未決定です。PR #155（未マージ）の上に積み重ねた Draft PR の内容です。
- C_Q は Q 関数に基づく complete-data / ICL 型の基準で、Schwarz BIC ではありません。C_Lap はラプラス近似で、厳密な周辺尤度ではありません。

## 問い：8 反復で観察された信号強度の効果は、反復継続後も維持されたか。それは数値的に安定した推定結果と言えるか。

**効果は維持されました。しかし、推定が数値的に安定したとは言えません。**

- PR #155 と同じ 128 fit（n=75、K_GEN=5、d=15、条件 A/B/C/D × 8 rep × K=4,5 × start 2）を、同じ seed で 64 反復まで続けました。8 反復時点の状態は 128/128 で以前の結果とビット単位で一致しました。
- C_Q の 4→5 の選択余裕（slack）の条件間の差（64 反復、中央値）は、F 強 − 基準 **+65.2**（8/8 で正）、w 強 − 基準 **+39.0**（7/8）、両方 − 基準 **+114.5**（8/8）でした。8 反復の値（+78.6、+35.3、+129.1）とほぼ同じで、事前登録の規則で 3 つとも「維持」です。C_Lap と、推定とは別の乱数で計算し直した C_Q でも同じでした。
- 一方、事前に決めた安定性の規則（直近 8 反復の相対変化 ≤ 0.01）を満たした fit は **0/128** でした。変化量は 5 反復目以降ほぼ一定（F の Gram 行列で約 0.1、線形予測子で約 0.5）で、減りも増えもしません。fit 自身の C_Q で計算した slack も反復ごとに ±20〜40 揺らぎます。ただし、別の乱数で評価し直した slack は 48→64 反復で 32 件中 31 件が MC 誤差内で、揺らぎの多くは C_Q を計算する 5 標本の MC 雑音と考えられます（事前登録外の追加確認）。
- 変化量の下限は MC 雑音によるものと考えられます。特に線形予測子の変化は 1 つの事後標本で測っているため、事後分布の広がりを含み、標本数 L を増やしても小さくならない可能性が高いです。0.01 という閾値はこの設定では満たせない値でした（事前登録時の見落とし。閾値は事後に変えていません）。

## その他の結果

1. **64 反復まで増やしても、基準条件 A の C_Q による過小選択（4 vs 5 の局所比較）は解消しません。** A で C_Q が K=5 を選ぶのは 64 反復でも 0/8 です（C_Lap では 3/8）。「8 反復で打ち切ったから K を小さく選んだ」という説明は、L=5・64 反復までの範囲では支持されません。
2. **FᵀF の固有値（2.5）と w（=1）をそろえた比較**では、K_GEN=5 の 4→5 の余裕は K_GEN=3 の 2→3 より小さい傾向でした（対応差の中央値 −59.5、6/8 で負、規則上「K=5 のほうが選びにくい」）。ただし 中央値の区間（被覆率 93%）[−127.7, +13.8] が 0 をまたぎ、2 件は逆向きで、強い結論ではありません。なお、この信号強度では K_GEN=5 でも C_Q は 7/8 で K=5 を K=4 より良いとしました。また、固有値と w をそろえても、平均辺密度をそろえる切片の違いで、ペアあたりの Bernoulli の Fisher 情報は K_GEN=5 のほうが約 14% 小さく、情報量そのものはそろっていません。
3. 計算の整合性（C_Q の分解、Laplace の恒等式）は誤差 1e-12 程度で確認しました。Laplace の非停留が 1 件あり、その点は欠測として扱いました。

## まだ言えないこと

- 「推定が収束した」「反復数は結論に影響しない」とは言えません。
- 4 vs 5 の局所比較だけで、K=1..7 からの選択結果（K̂）は B/C/D で調べていません（予算外）。
- K=3 と K=5 の比較は、生成分布が違うので完全に対応したデータではありません。

## ご相談したいこと

1. 安定性の判定を、事後平均や反復平均を使う診断量（必要なら標本数 L の増加も）で定義し直して、改めて事前登録するか。
2. 信号を強めた条件で、全候補 K の選択（K̂）まで確認するか（計算量は今回の約 1.3 倍）。
3. 「K が大きいと 1 方向あたりの利得が小さくなる」機構を調べる実験を行うか、rep を増やして確認するか。
