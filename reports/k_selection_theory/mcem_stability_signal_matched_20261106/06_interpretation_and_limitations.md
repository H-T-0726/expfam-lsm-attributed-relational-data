## 2. 新しく分かったこと

1. **効果の維持と fit の不安定性は両立する**（OBSERVED）。fit 自身の C_Q で計算した slack は反復ごとに ±20〜40 揺らぎ、start の違いでも同程度に変わる。それでも、同じデータ・同じ seed で条件だけを変えた**対応差**は 8→64 反復でほぼ一定だった。fit 自身の slack の揺らぎの多くは、その時点の 5 標本による Q の MC 雑音と考えられる（独立評価の slack は 48→64 で 31/32 が MC 誤差内。HYPOTHESIS）。
2. **64 反復まで増やしても、canonical A の C_Q による局所的な過小選択は解消しない**（OBSERVED）。A の C_Q で（4 vs 5 で）K=5 を選ぶのは 64 反復でも 0/8、slack の中央値は −123。EMC（40 反復）と整合し、「8 反復で打ち切ったせい」という説明は、L=5・64 反復までの範囲では支持されない。C_Lap では 3/8 が K=5 を選ぶ。全 fit が事前登録の安定性規則を満たしていない点にも注意。
3. **C_Lap の slack は反復に対してほとんど動かない**（OBSERVED）。C_Q の slack より checkpoint 間の変化がずっと小さい（例：B の中央値 29.6→26.1）。
4. **事前登録した安定性規則（0.01）は L=5 の MCEM では満たせない**（実装の事実 + OBSERVED。下限の原因の帰属は HYPOTHESIS）。η の診断量は最後の 1 標本 Z で計算されるので事後分布の広がりを含み、L を増やしても下がらないと考えられる。gram は 5 標本からの F の MC 雑音を含み、L を増やせば下がりうる。観測された下限は gram 約 0.1、η 約 0.5 で、反復を続けても下がらない。L を変えた測定はしていない。
5. **FᵀF の固有値 2.5・w=1 では、K_GEN=5 でも局所的には K=5 が選ばれる**（OBSERVED、C_Q 7/8）。ただし 2→3 より 4→5 の余裕が小さい傾向がある（RQ2）。Y 側の利得の差は、ペアあたりの Fisher 情報の差（約 14%）とほぼ同じ比で、情報量の差で説明できる可能性がある（HYPOTHESIS）。

## 3. 結論を誤らせうる点（検討した反論）

| 反論 | 検討 |
|---|---|
| 64 反復も同じ乱数の続きなので、8 反復の偶然を引きずっているだけでは | 独立 MC 評価（別の乱数）でも同じ大きさの効果。ただし推定経路そのものは各 fit 1 本で、MCEM の乱数を変えた反復はしていない（seed 間の頑健性は 2 start でしか見ていない） |
| 効果が A の不調だけで生じているのでは | A の 8〜32 反復の状態は EMC（別の実験）とビット単位で一致し、slack も EMC の値と整合する。A だけが異常という証拠はない。ただし B/C/D どうしの対比は事前登録しておらず、判定していない |
| 安定しない fit の差を比べても意味がないのでは | 差が維持されたことは観察事実だが、「収束後の基準値の差」とは言えない。ここが最大の限界 |
| C_Q の改善は K̂ の改善を意味するか | しない。4→5 の局所比較だけで、K=6 以上や K=3 以下との比較は B/C/D でしていない |
| RQ2 の K_HARDER は rep を選べば変わるのでは | 規則・rep は事前固定。ただし 8 rep で 2 件が逆向き、CI が 0 をまたぐので、判定は脆い |
| 恒等式の誤差が 1e-12 だから正しいのでは | 計算の整合性を示すだけで、基準の妥当性・一致性は示さない |

## 4. 主張してはいけないこと

- C_Q を Schwarz BIC と呼ぶこと。C_Lap を厳密な周辺尤度と呼ぶこと。
- 「64 反復で推定が収束した」「推定の影響はない」。全 fit が事前登録の安定性規則を満たしていない。
- 「信号を強めれば K̂ = K_GEN になる」。全候補 K での選択は B/C/D で未評価。B でも C_Q が K=5 を選ぶのは 3/8 にとどまる。
- 「K が大きいこと自体が過小選択の原因」。RQ2 は境界的で、canonical A と信号構造も違う。
- K_GEN（生成）、K*（真値の定義）、K0、K̂（推定）を混同すること。今回の「K=5 を選ぶ」は 4 vs 5 の局所選択であり K̂ ではない。
- 結果を prototype 以外（正式手法・manuscript evidence）として扱うこと。

## 5. 未解決（UNRESOLVED）と次に人間が判断すること

- 安定性の診断量を、Z の事後平均や複数反復の平均（η 側）、L を増やした推定（gram 側）で定義し直すと、判定はどう変わるか。η を 1 標本で測る限り、L を増やしても規則は満たせない可能性が高い。**安定性規則の再定義は新しい事前登録が必要**。
- B/C/D の全候補 K（K=1..7）を 64 反復で評価するか（15,360 fit-iteration、今回の予算外）。
- RQ2 を rep を増やして確認するか、K_GEN=5 の利得低下の機構（Y 内積の分散、Poisson の非線形性、推定誤差）を分離する実験をするか。
- これらは新しい実験で、開始は研究者の判断（Human Gate）。
