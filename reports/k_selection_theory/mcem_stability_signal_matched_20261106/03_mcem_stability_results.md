# 03 MCEM の安定性：結果（2026-11-06）

- **位置づけ**：系列 E（prototype）。RQ1 の 128 fit（A/B/C/D × rep 1..8 × K_fit 4,5 × start 1,2、n=75、K_GEN=5、d=15、L=5、64 反復）。
- 一次資料：`analysis/stability_diagnostics.csv`、`analysis/iteration_trajectories.csv`、`analysis/local_k4_k5_comparison.csv`、図 1・4・6・7。
- 「STABLE」は事前登録した**数値的安定性のラベル**であり、収束・一致性の主張ではない。L=5 の確率的 MCEM は、決定論的 EM の意味では収束しない。

## 1. fit 単位の安定性ラベル（事前登録の規則。OBSERVED）

規則：直近 8 反復の gram_rel_change・eta_x_rel_change・eta_y_rel_change の最大がすべて ≤ 0.01 なら STABLE。

| 量（64 反復時点の直近 8 反復の最大） | 最小 | 中央値 | 最大 |
|---|---:|---:|---:|
| gram_rel_change | 0.073 | 0.102 | 0.145 |
| eta_x_rel_change | 0.39 | 0.48 | 0.62 |
| eta_y_rel_change | 0.48 | 0.58 | 0.71 |

- **128/128 fit が NOT_STABLE**。どの checkpoint でも STABLE になった fit はない（first_stable_checkpoint は全件なし）。閾値は緩めない。
- 図 4 では、3 つの量の中央値は 5 反復前後で下がり止まり、その後 64 反復まで**ほぼ一定の水準**（gram 約 0.08〜0.11、eta_x 約 0.42〜0.55、eta_y 約 0.51〜0.65）にとどまる。減り続ける傾向は見えない。条件の順序は D ≤ B < C ≤ A（信号が強いほど少し小さい）。

### なぜ 0.01 に届かないのか（DERIVED：実装から）

- `em_runner_instrumented.py` の診断量は、E-step で引いた **最後の 1 標本 Z**（`Z_samples[:, :, -1]`）から η を計算している。したがって eta_x・eta_y の変化には、反復ごとの**事後標本の揺らぎ**がそのまま含まれる。
- F（gram）は 5 標本から M-step で推定するので、反復ごとの MC 雑音を持つ。L を固定した MCEM では、この雑音は反復を続けても小さくならない。
- **解釈（HYPOTHESIS）**：0.01 という閾値は、L=5 の MCEM の雑音の下限（gram 約 0.1、η 約 0.5）より 1〜2 桁小さく、この設定では**推移（drift）と MC 雑音を区別できない規則だった**。これは事前登録時の設計上の見落としで、結果を見たあとで閾値を変えることはしない。NOT_STABLE は「値が動き続けている」ことを意味するが、「系統的にずれ続けている」ことを意味しない。

## 2. データセット単位の安定性（OBSERVED）

| ラベル | 定義 | 件数（32 データセット） |
|---|---|---:|
| SIGN_STABLE（C_Q） | S_Q(4→5) の符号が 32・48・64 で同じ | **30/32**（例外：C rep3、D rep5） |
| 8→64 で C_Q slack の符号が変わる | — | 1/32（C rep3） |
| SLACK_STABLE（C_Q） | \|S_Q(64) − S_Q(48)\| ≤ 2 × 独立評価による S の MC 標準誤差（約 12） | **15/32**（A 3、B 5、C 5、D 2） |
| 8→64 で C_Lap slack の符号が変わる | — | 0/32 |
| sign(S_Q) ≠ sign(S_Lap) | 8 反復 / 64 反復 | 12/32 / 13/32 |

- \|S_Q(64) − S_Q(8)\| の中央値（最大）：A 11.4（25.2）、B 13.7（28.0）、C 18.4（25.7）、D 5.1（37.0）。\|S_Q(64) − S_Q(48)\| は最大 46.7（B rep5）。
- **独立評価の MC 標準誤差（約 6）より大きく動く**データセットが半分ある。これは評価の雑音ではなく、**fit の状態そのものが反復ごとにさまよっている**ことを示す（図 1 の細線）。ただし、さまよいは一定の水準のまわりの揺らぎで、条件の中央値（太線）は 8 反復以降ほぼ水平である。

## 3. 局所的な選択（4 vs 5）の変化（OBSERVED）

| 条件 | C_Q で K=5（8 → 64） | C_Lap で K=5（8 → 64） | C_Q slack 中央値（8 → 64） | C_Lap slack 中央値（8 → 64） |
|---|---|---|---|---|
| A | 0 → 0 | 3 → 3 | −128.7 → −123.1 | −11.3 → −11.4 |
| B | 3 → 3 | 6 → 6 | −66.3 → −68.2 | +29.6 → +26.1 |
| C | 2 → 1 | 4 → 4 | −81.8 → −86.3 | +8.4 → +5.4 |
| D | 3 → 3 | 7 → 7 | −12.6 → −27.8 | +49.4 → +49.7 |

- 64 反復まで続けても、**条件 A で C_Q が K=5 を選ぶようにはならなかった**（0/8 のまま）。EMC の 40 反復の結果（A のみ）と整合する。
- C_Lap の slack は checkpoint 間でほとんど動かない（Laplace は推定状態から joint mode を取り直すため、MC の揺らぎを受けにくいと考えられる。HYPOTHESIS）。
- start 間の差（K=5 の C_Q）は中央値で 4〜25 程度。start の違いも slack と同程度の大きさのばらつきを生む（図 6）。

## 4. 言えること・言えないこと

- 言える（OBSERVED）：8→64 反復で、条件ごとの slack の中央値と局所選択の件数はほぼ変わらない。fit の状態は一定水準のまわりを揺らぎ続ける。
- 言えない：事前登録の意味で「数値的に安定した」fit は 1 件もない。したがって「推定が収束した」「反復を続けても結論は変わらない」と一般化はできない。64 反復を超える挙動、L を増やしたときの挙動は調べていない。
