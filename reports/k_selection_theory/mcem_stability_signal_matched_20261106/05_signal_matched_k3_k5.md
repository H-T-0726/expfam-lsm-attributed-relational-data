# 05 方向あたりの信号をそろえた K_GEN=3 と K_GEN=5 の比較（RQ2、2026-11-06）

- **位置づけ**：系列 E（prototype）。n=75、d=15、Poisson-X / Bernoulli-Y、L=5、32 反復、rep 1..8、K_fit ∈ {K_GEN−1, K_GEN, K_GEN+1} × start 2。
- 設計（01 §4）：rep ごとに Z5・F5 を作り、K_GEN=3 は Z5・F5 の最初の 3 列を使う。FᵀF の固有値はすべて 2.5、w = 1、w0 は母集団の平均辺密度を canonical A に合わせて較正。X3・Y3 は X5・Y5 からの厳密なカップリング、マスクは共有。
- **K=3 と K=5 の観測データは同一ではない**（生成分布が違う）。共有するのは潜在方向・乱数・マスクで、「完全に対応したデータ」ではない。総信号量は K=5 が K=3 の 5/3 倍。
- 一次資料：`analysis/signal_matched_k3_k5.csv`、図 8。

Δ = S_Q(4→5 \| K_GEN=5) − S_Q(2→3 \| K_GEN=3)。K_HARDER = 中央値 Δ < 0 かつ 6/8 以上が負。

| **C_Q（主）** | **−59.5** [−127.7, +13.8] | 6/8 | 0.04 | **K_HARDER** |

| C_Q_eval（副） | −47.0 [−125.3, +6.9] | 6/8 | 0.05 | K_HARDER |

- 他の checkpoint（記述用）：C_Q の中央値 Δ は 8・16・24 反復で −35.0（7/8 負）、−55.9（8/8）、−72.7（6/8）。すべて同じ規則で K_HARDER。
- **主判定の CI は 0 をまたぐ**（上限 +13.8）。2 件（rep2 +13.8、rep5 +21.0）は逆向きで、効果の大きさは replicate によって −161〜+21 と大きくばらつく。判定は規則どおり K_HARDER だが、8 rep での根拠は強くない（INCONCLUSIVE に近い境界的な結果として扱う）。

## 3. 解釈（HYPOTHESIS）

- 方向あたりの FᵀF と w² をそろえても、「既に K−1 方向がある状態で最後の 1 方向を加える」利得は K が大きいほど小さい可能性がある。候補となる機構は、(1) Y の内積 w z_iᵀz_j の分散が K に比例して増え、密度を合わせる w0 の較正と Bernoulli の飽和で 1 方向あたりの情報が減る、(2) Poisson-X の η の総分散が K とともに増え、rate の非線形性で方向ごとの寄与が変わる、(3) 推定する方向が増えるほど MCEM の推定誤差が利得を削る。**今回の実験はこれらを区別していない**（UNRESOLVED）。
- 「K_GEN=5 の過小選択（PR #155 の canonical A）は、K が大きいこと自体による」とは言えない。canonical A と RQ2 は信号強度も F の構造も違う。

## 4. 言えないこと

- K=3 と K=5 を「同じデータ」で比べたとは言えない（生成分布が違う）。
- 8 rep で CI が 0 をまたぐので、K_HARDER を強い結論として扱えない。
- 全候補 K からの K̂ は評価していない（局所比較だけ）。他の n・d・信号強度への一般化はできない。
