# 05 FᵀF の固有値と w をそろえた K_GEN=3 と K_GEN=5 の比較（RQ2、2026-11-06）

- **名称の注意**：事前登録では「signal-matched」と呼んだが、そろえたのは **FᵀF の固有値（2.5）と w（=1）**であり、ペアや観測あたりの情報量はそろっていない（§3）。以下では「信号をそろえた」を、この意味に限って使う。

- **位置づけ**：系列 E（prototype）。n=75、d=15、Poisson-X / Bernoulli-Y、L=5、32 反復、rep 1..8、K_fit ∈ {K_GEN−1, K_GEN, K_GEN+1} × start 2。
- 設計（01 §4）：rep ごとに Z5・F5 を作り、K_GEN=3 は Z5・F5 の最初の 3 列を使う。FᵀF の固有値はすべて 2.5、w = 1、w0 は母集団の平均辺密度を canonical A に合わせて較正。X3・Y3 は X5・Y5 からの厳密なカップリング、マスクは共有。
- **K=3 と K=5 の観測データは同一ではない**（生成分布が違う）。共有するのは潜在方向・乱数・マスクで、「完全に対応したデータ」ではない。総信号量は K=5 が K=3 の 5/3 倍。
- 一次資料：`analysis/signal_matched_k3_k5.csv`、図 8。

## 3. データの違い（FACT：`gates/rq2_dataset_provenance.csv`、集計は `expfam/results/k_selection/mcem_stability_signal_matched_20261106/review_followup/`（`tools/research_audit/review_followup_mcem_stability.py`、事前登録外） の `e3_rq2_data_statistics.csv`）

| 量（8 rep の中央値 [範囲]） | K_GEN=3 | K_GEN=5 |
|---|---|---|
| w0（密度較正後） | −0.979 | −1.143 |
| Bernoulli の Fisher 情報 平均 p(1−p) | 0.155 [0.150, 0.160] | 0.133 [0.127, 0.141] |
| X の平均 | 1.34 [1.26, 1.39] | 1.62 [1.42, 1.75] |
| F の行ノルム² の平均 | 0.500 | 0.833 |
| 真の Poisson rate の最大 | 20.0 [13.8, 39.9] | 35.9 [15.6, 147.9] |

- FᵀF の固有値と w はそろっているが、K=5 では内積 w z_iᵀz_j の分散が大きく、平均辺密度をそろえる w0 がより負になる。その結果、**ペアあたりの Bernoulli の Fisher 情報が約 14% 小さい**（0.133 / 0.155 = 0.86）。
- Y 側の利得の比（K_GEN=5 の 150.9 / K_GEN=3 の 178.0 = 0.85）はこの比とほぼ同じで、**Y 側の差はこの情報量の差で説明できる可能性がある**（HYPOTHESIS。照合は中央値どうしの比較だけ）。X 側は rate の分布も違う（K=5 のほうが平均・最大とも大きい）。

## 4. 解釈（HYPOTHESIS）

- 方向あたりの FᵀF と w² をそろえても、「既に K−1 方向がある状態で最後の 1 方向を加える」利得は K が大きいほど小さい可能性がある。候補となる機構は、(1) Y の内積 w z_iᵀz_j の分散が K に比例して増え、密度を合わせる w0 の較正と Bernoulli の飽和で 1 方向あたりの情報が減る、(2) Poisson-X の η の総分散が K とともに増え、rate の非線形性で方向ごとの寄与が変わる、(3) 推定する方向が増えるほど MCEM の推定誤差が利得を削る。**今回の実験はこれらを区別していない**（UNRESOLVED）。
- 「K_GEN=5 の過小選択（PR #155 の canonical A）は、K が大きいこと自体による」とは言えない。canonical A と RQ2 は信号強度も F の構造も違う。

## 5. 言えないこと

- K=3 と K=5 を「同じデータ」で比べたとは言えない（生成分布が違う）。
- 「信号量をそろえても K_GEN=5 は選びにくい」とは言えない。そろえたのは FᵀF の固有値と w で、ペアあたりの情報量は K_GEN=5 のほうが小さい（§3）。
- 8 rep で CI が 0 をまたぐので、K_HARDER を強い結論として扱えない。
- 全候補 K からの K̂ は評価していない（局所比較だけ）。他の n・d・信号強度への一般化はできない。
