# 10 指導教員向けの要約（2026-11-06）

**問い**：「旧 Python 推定器は、K 選択が失敗する n=75 でも正しい K を選べるのか」。

**最初に注意**：本研究で事前登録した n=75 の条件（PR #160 E1 と同じ生成器 G_canon。X の雑音分散 0.1、X の SNR 9）では、**どちらの推定器でも K 選択は失敗しなかった**。

- そのため、「失敗が起きる条件で旧推定器だけが成功するか」という本来の問いには、**この実験では答えられていない**。
- PR #160 で失敗した n=75 の条件は、X の SNR が 0.7〜1.6 の E2 で、本研究の条件とは違う。

**実験**：新しい fit は 320 件で、すべて正常に終了した。
- 旧推定器（OLD、0.5 系列）と系列 E（prototype）を比べた。
- 同じデータ、同じ初期状態（ハッシュで確認）、同じ seed、同じ予算、推定器から独立した共通の基準を使った。

**前提**
- 系列 E は prototype なので、結果は manuscript evidence ではない。
- OLD の結果には、「Newton 方向が全体として正しいとは断定できない」（KI-001）が付く。
- C_Q は Schwarz BIC ではなく、C_Lap は厳密な周辺尤度ではない。
- 「正解」は K_HAT = K_GEN（生成に使った次元）を指す。K_GEN = K0（母集団の最小次元）は仮定しない。

## 最終問への答え

1. **n=75 で OLD は正しい K を選べたか**
   - 本研究の n=75 の条件では選べた。C_Q で 6/6 データ（G_canon 4、G_old 2）。
   - ただし、この条件は失敗条件ではない。
2. **同じデータで系列 E は正しい K を選べたか**
   - 選べた。6/6 で、C_Q の K_HAT は OLD と全データで一致した。C_Lap も、完全なデータ 5/5 で一致した。
3. **違いがあった場合、何が違ったか**
   - C_Q・C_Lap による K の選択では違いはなかった。
   - Q_Z を含まない基準 B・C では一致しなかった（1/6・0/6）。系列 E は常に過大で、OLD はばらついた。
   - 推定量の違い
     - OLD の ŵ は小さめ（G_canon で 1.00〜1.07、真値 1.16。E は 1.11〜1.19）。
     - OLD の E-step の事後共分散は大きい。
     - η_Y の回復は E がわずかに良い。
4. **同じ結果になったことで何が分かったか**
   - n=75 だけでは失敗は起きないこと。つまり、n=75 は失敗の十分条件ではない。
   - この条件では、推定器の違いが C_Q・C_Lap の選択を左右しないこと。
   - 一方、PR #160 E2 では、同じ生成規則のまま n=75→150 で C_Q の正解が 0/4→3/4（弱い信号）・2/4→4/4（強い信号）に増えている。**n は原因から除外されない**。
   - 失敗には、「小さい n」と「弱い信号」の**両方**が必要だった（PR #160 と本研究を合わせた観察。多要因）。
5. **1/2 による E-step の違いは n=75 でも現れたか**
   - 現れた。G_canon では n=75 で共分散の比が 1.14〜1.15 倍、n=150 では 1.25 倍。
   - 違いの大きさは、ノードの精度に占める Y の割合とともに大きくなる。その割合は n と |w| とともに大きくなる。G_old の n=75 rep 2（|ŵ|≈3）では 1.29 倍。
   - 1/2 だけの因果効果は断定しない。
6. **選択が失敗した条件で、推定精度も低下していたか**
   - 本研究には失敗したセルがなく、直接は答えられない。
   - PR #160 の失敗条件では、K=5 を与えても潜在構造の回復が低かった（ZZᵀ の相関 0.76〜0.84。本研究の n=75 では 0.96）。
7. **全ペア観測と部分観測でどう変わったか**
   - 選択は変わらなかった（4/4 と 4/4）。
   - C_Q の余裕は 4 データ中 3 つで小さくなった（中央値 −32）。回復もわずかに悪化した。
   - 境界に近い条件での効果は未確定。
8. **n=150 で成功し n=75 で失敗する理由をどこまで実証できたか**
   - **実証できたこと**：
     - n=75 は失敗の十分条件ではない（X の信号が強ければ n=75 で成功する）。
     - PR #160 では、弱い信号のもとで n が効いていた（一要因の比較）。
   - **反証されたこと**：「X の信号対雑音比だけで決まる」という仮説。E2 の弱い信号では、X の SNR は n=75 と n=150 で同じ 0.68 だが、結果は 0/4 と 3/4。
   - **仮説（事後的・未検証）**：1 ノードあたりの総情報量（X ＋ Y。Y は n とともに増える）で成否が分かれる。総情報量（中央値）と結果は次のとおりで、並びは合う。ただし、事前登録しておらず、多要因の比較である。

     | 条件 | 総情報量 | C_Q の正解 |
     |---|---:|---|
     | E2 n=75 弱 | 40 | 0/4 |
     | E2 n=75 強 | 66 | 2/4 |
     | E2 n=150 弱 | 66 | 3/4 |
     | E2 n=150 強 | 105 | 4/4 |
     | 本研究 n=75 | 196 | 4/4 |
9. **以前の Python 再現の成功の理由**
   - 新しい証拠：旧推定器と系列 E は、検証した条件で同じ K を選ぶ。旧生成器（G_old）の n=75 でも成功した。
   - 「旧推定器だから成功した」という説明は、検証した条件では支持されない。
   - 成功に効いた条件の候補は 3 つあるが、どれが必要かは切り分けられていない：
     - n=150（弱い信号でも 3/4）
     - 強い信号（n=75 でも 4/4）
     - 全ペア観測（80% でも 4/4 なので、必要条件ではない）
   - Figure 3 の手順は不明のまま（UNRESOLVED）。
10. **何を修正すべきか**
    - モデル：原論文と同等で、修正の根拠はない。
    - K の選択基準：C_Q・C_Lap は検証したすべてのセルで正解し、Q_Z を除いた基準と plug-in 基準は過大だった。C_Q・C_Lap を使い続ける根拠はある。
    - 推定器：**失敗条件で OLD を実行していないので、失敗の原因かどうかは判定できない**。
    - データ条件：失敗は「小さい n かつ弱い信号」で起きた。「n=75 で失敗する」とまとめず、n と信号の強さの組み合わせによる**条件の限界として報告し、その境界を示す**のが妥当（提案）。

## A. 確定したこと（導出・数値検証・公平な比較）

- 原論文のモデルと ExpFam（Gaussian-X/Bernoulli-Y）は、μ_x=0・σ_z²=1 で同等。
- OLD は、Y を ½ 倍した自身の目標を正しく微分している（有限差分で 3e−10）。採用式は、無向ペアを 1 回ずつ数える完全な条件付き分布の微分と一致する。印刷式の正誤は判定しない。
- 同じ n=75 データ・同じ初期状態で、OLD と E の C_Q による K_HAT は 6/6 一致し、すべて K_GEN だった。
- Q_Z を除いた基準と plug-in 基準は、系列 E の状態では、本研究の n=75 でも完全なデータがすべて過大選択になった。

## B. 条件付きで分かったこと

- **条件**：n=75、d=15、X の雑音分散 0.1（SNR 9）、F の行ノルム² 0.9、w=1.16、K_GEN=5。
- **分かったこと**
  - この条件では C_Q・C_Lap が K_GEN を選ぶ。80% マスクでも同じ。
  - G_old の n=75（2 データ）でも同じ。
  - E-step の共分散の差は、Y の割合（n と |w|）とともに大きくなる。
- **組み合わせの条件**（PR #160 との組み合わせ）：失敗は、弱い X の信号のもとで、小さい n のときに起きた。
