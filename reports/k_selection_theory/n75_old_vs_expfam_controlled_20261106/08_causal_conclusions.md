## 2. n=150 と n=75（Q7・最終問 8）

- G_canon（rep 1・2 の入れ子の部分集合、F・w・w0 は同じ）では、n=75 でも n=150 でも、両推定器とも C_Q と C_Lap で K=5 を選んだ。
  - n=150 → 75 で、C_Q の過小側の余裕は 1750〜2084 から 485〜771 に下がる。
  - 余裕は n にほぼ比例して小さくなるが、0 には遠い（OBSERVED、ONE_FACTOR に近い設計）。
- **したがって、本研究の条件（X の SNR 9）では、「n=150 なら成功し、n=75 なら失敗する」という現象は起きなかった。**
- PR #160 E2（X の SNR 0.7〜1.6）では、同じ生成規則のまま n=75→150 で成功が増えた。この効果は一要因の比較で確かめられており、本研究でも否定されない。
- **実証できたこと**：n=75 だけでは失敗は起きない。つまり、n=75 は失敗の十分条件ではない。
- **言えないこと**：「n は原因ではない」とは言えない。PR #160 E2 では n が効いていた。
- **仮説（事後的）**：成否を分けるのは、n と信号の強さを合わせた 1 ノードあたりの総情報量である（N3）。X の SNR だけでは説明できない。

## 3. 以前の Python 再現の成功（最終問 9）

- 新しい証拠
  1. 旧推定器と系列 E は、n=75・150 の全ペア観測・強い X 信号の条件で、同じ K を選ぶ。
  2. 旧生成器（G_old）でも、n=75 で K=5 を選べた。
- したがって、「旧推定器だから成功した」という説明は、検証した条件では支持されない。
- 成功の条件として次の 3 つが候補になるが、どれが必要かは切り分けられていない（INTERPRETATION）。
  - n=150：PR #160 では弱い信号でも 3/4。
  - 強い X の信号：本研究では n=75 でも 4/4。
  - 全ペア観測：80% でも 4/4 なので、必要条件ではない。
- ただし、原論文 Figure 3 の生成と集計の手順は不明で、**Figure 3 を再現したとは言わない**（UNRESOLVED）。

## 5. 限界

1. データ数：B は 4、C は 2。過小選択が 1 件もないので、「OLD は失敗条件でも成功するか」は、**失敗が起きる条件では検証していない**。
2. 失敗条件（PR #160 E2 型：X の雑音分散 exp(−‖f‖²/2)、80% マスク）で OLD と E を比べるには、OLD をマスク付きで実行する必要がある。OLD はマスクに対応しておらず、コードを変えないという制約がある。全ペアなら比べられる（次の実験の候補）。
3. N3 は、真のパラメータからの記述にすぎない。X の雑音だけを変える一要因の比較は行っていない。
4. Laplace の精度は UNRESOLVED のまま（PR #160 の IS は退化）。
5. OLD は 0.5 系列（KI-001）、E は prototype。K_GEN = K0 は仮定していない。Bernoulli-Y を含む識別可能性は UNRESOLVED。
6. G_old の n=75 rep 2 は真の w が −8.06 と極端で、ŵ は両推定器とも約 −3 に飽和した。
