## 3. データ（fit の前に決定）

**G_canon n=75**
- PR #160 の E1 G_canon n=150 のデータ（seed 7610000+500+rep）の、**最初の 75 ノード**を使う。X と Z は先頭 75 行、Y は 75×75 のブロック。
- ノードは F が与えられれば独立なので、canonical モデルの n=75 の正確な標本になる。しかも F・w0・w は n=150 のデータと同じ。
- rep 1・2 は PR #160 の n=150 の fit と対になる。n の比較を一要因の比較にできるだけ近づけるために、この設計にした。
- 照合済み：部分集合が n=150 のデータと一致すること（precheck）。

**G_old n=75**
- `set_true_params(n=75, seed=1980+500+1000(rep−1))`。
- Z と X を 75 ノードで z-score するので、n=150 の部分集合にはできない。乱数の流れが n に依存するので、F と w も n=150 とは違う。
- 真の w：rep 1 は 0.58、rep 2 は −8.06（生成器の w = 3·randn による。結果を見て変えない）。

**マスク（Phase D）**
- `default_rng([data_seed, 650000])` で上三角ペアの 80% を選ぶ。
- 除外した 555 ペアは、**80% 条件の held-out としてだけ**使う（全ペア条件では学習に使ったペアなので）。

## 5. 指標

- **基準**
  - 共通評価器（`fair_common_evaluator.py`）で次を計算する：A C_Q、B C_Q − P_Z、C 最後の標本での plug-in、D 結合モードでの plug-in、E C_Lap。
  - OLD には、参考として Python 型の規則（各 start で最良反復の plug-in ＋ Eq.(26) の罰則。集計は 2 start の平均）を加える。**A〜E とは混ぜない。**
- **選択**：2 start の平均、全候補 K の最小、同点なら小さい K。全候補で 2 start が揃わない場合は INCOMPLETE（D・E は Laplace の成功も条件）。最良の start や最良の反復だけを後から使うことはしない。
- **主要指標**
  - K_HAT
  - 正解・過小・過大
  - C(4) − C(5)（正なら正しい向き）
  - C(5) − C(6)（負なら正しい向き）
  - 同じデータでの OLD と E の K_HAT の一致
- **副次指標**
  - ZZᵀ の相関
  - 部分空間の回復（Ẑ と Z の正準相関の二乗和 ÷ K_GEN）
  - FFᵀ の相対誤差（G_canon だけ）
  - η_Y の相対 RMSE
  - 雑音のない ZFᵀ に対する R²
  - 母集団の Y 対数スコア：真のペア確率のもとでの期待対数スコア。観測 Y を使わないので、全条件で漏洩なく比べられる
  - held-out の Y 対数スコア（D の 80% 条件だけ）
- **E-step の比較（Phase F、fit なし）**：同じ θ・Z・X・Y で、各実装の目標分布の対数密度・勾配・負の Hessian と有限差分の一致、条件付きモード、共分散のトレース比、X 側と Y 側の精度への寄与、保存された MC 標本の分散を、n=75 と n=150 で比べる。**1/2 だけの因果効果は主張しない**（他の実装の違いもあるため。1/2 だけを変える ablation は、別の新しい実験になる）。
- **n=150 との比較**：PR #160 の E1 の状態を読み取り専用で再採点する。PR #160 の `criterion_scores.csv` と 1e−6 以内で一致することを確かめる。

## 6. 停止条件

停止するのは次の場合だけ：
- 数式の不一致
- 漏洩
- seed の規則違反
- CSV の破損
- 生成器の暗黙のクリッピング
- **同じ seed で初期状態が一致しない**
- 条件を固定できない
- 状態を安全に扱えない
- 主目的を解釈できなくする技術的な欠陥

K 選択の失敗、OLD と E の不一致、精度の悪化、警告、MC の変動では停止しない。
